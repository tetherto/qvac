## Bundling

Compose bundles only the plugins its pipeline uses, through the same mechanism as [`qvac bundle sdk`](/cli#qvac-bundle-sdk).

## Models

Pipelines reference registry models by constant, so the application downloads each model once and shares it between pipelines.
