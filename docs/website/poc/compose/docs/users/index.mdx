## Overview

Compose lets you describe a pipeline of AI capabilities — transcribe, translate, summarize, speak — in one declaration, and runs it on the device with the [QVAC SDK](/sdk) underneath. Each step names a capability and a model; Compose loads the models, streams each step's output into the next, and releases the models when the pipeline ends.

## What you can build

- A meeting assistant that transcribes audio, translates it, and writes a summary.
- A voice interface that turns speech into a command and answers with speech.
- A document flow that reads a scan with OCR and indexes it for retrieval.
