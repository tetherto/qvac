## Overview

This collection holds the material that helps you build with QVAC without documenting a release of it. Nothing here is versioned: a tutorial on packaging an Electron app and a fix for a missing system library do not expire with a patch, so they live here in one copy rather than in each documentation line.

It holds the tutorials for building on a specific platform, the troubleshooting guide for when something does not start, and the procedure a coding agent follows to read the documentation matching the release a project has installed. It also indexes what lives outside this site: recipes published on the main website, and sample projects published as source code.
