---
title: KV cache
description: 'Use kvCache: true to speed up follow-up turns in a conversation.'
---

Use `kvCache: true` in [`completion()`](/sdk/api/completion) to cache and reuse the model's key/value attention state so follow-up turns in a conversation are faster.

<Steps>

<Step title="Load the model">
Call [`loadModel()`](/sdk/api/loadModel) with your LLM model and config as usual.

</Step>

<Step title="First turn with cache enabled">
Call [`completion()`](/sdk/api/completion) with `history` (e.g. one user message), `stream: true`, and `kvCache: true`. Consume `tokenStream` and save the assistant reply for the next turn.

<Step title="Follow-up turn reusing cache">
Append the previous assistant reply to `history` and add the new user message. Call [`completion()`](/sdk/api/completion) again with `kvCache: true`; the SDK reuses the cached state for the prefix and only runs the new turn.
