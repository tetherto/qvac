Let the model emit structured tool calls; define tools with Zod schemas, pass them to [`completion()`](/sdk/api/completion), and consume `toolCallStream` events.

## 1. Define tools with Zod schemas

Create Zod schemas for each tool's parameters and a `tools` array with `name`, `description`, and `parameters` (the schema). The same schemas can be used later to validate [`toolCall.arguments`](/sdk/api/completion#tool-call-events).

## 3. Run completion with tools

Pass the `tools` array to [`completion()`](/sdk/api/completion). Use `stream: true` and consume both `result.tokenStream` and [`result.toolCallStream`](/sdk/api/completion#toolcallstream).

## 4. Handle tool calls and continue

Await `result.toolCalls` for the parsed tool calls, validate arguments with your Zod schemas, run your handlers, then append assistant and tool messages to `history` and call [`completion()`](/sdk/api/completion) again for the follow-up response.
