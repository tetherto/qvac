Attach an MCP client to [`completion()`](/sdk/api/completion) so the model can use external tools (e.g. web search). You create and connect the MCP client, then pass it via the `mcp` option.

<Steps>

<Step title="Install and create the MCP client">
Install and import [`@modelcontextprotocol/sdk`](https://github.com/modelcontextprotocol/sdk), then create a [`Client`](https://github.com/modelcontextprotocol/sdk/blob/main/packages/sdk/client/index.ts) and connect it to your MCP server(s) (e.g. via `StdioClientTransport` for a subprocess server).

<Step title="Run completion with the MCP client">
Pass the MCP client to [`completion()`](/sdk/api/completion) via the `mcp` option. The model can then call tools provided by the server; tool invocations are routed to the MCP client.
