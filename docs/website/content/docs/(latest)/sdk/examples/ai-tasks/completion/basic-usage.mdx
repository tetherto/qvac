Basic completion: download (or use cached) model, load it, run streaming completion, then unload.

## 1. Download the model (optional)

Use [`downloadAsset()`](/sdk/api/downloadAsset) to fetch the model to the cache first; you can skip this and let [`loadModel()`](/sdk/api/loadModel) download on demand.

## 2. Load the model

Call [`loadModel()`](/sdk/api/loadModel) with a model constant (e.g. `LLAMA_3_2_1B_INST_Q4_0`), `modelType: "llm"`, and any [`modelConfig`](/sdk/api/loadModel#modelconfig-varies-by-model-type) (e.g. `device`, `ctx_size`, `verbosity`) to load it from cache.

## 5. Unload the model

Call [`unloadModel({ modelId })`](/sdk/api/unloadModel) when done. Use `clearStorage: true` only if you want to remove cached files from disk.
