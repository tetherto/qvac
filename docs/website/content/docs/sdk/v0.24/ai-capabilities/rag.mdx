## Overview

RAG (retrieval-augmented generation) uses [text embeddings](/sdk/ai-capabilities/text-embeddings): you embed (vectorize) documents, persist them in a vector store, and later retrieve the most relevant chunks for a query using similarity search.

Compared to generating text embeddings only, the key differences are:

- You must **persist embeddings** (vectors) alongside the original text (and optional metadata) in a vector store.
- At query time, you **embed the query** and run **top‑K** vector search to fetch the most relevant documents/chunks.
- You _typically_ pass the retrieved text to [`completion()`](/sdk/reference/api#completion) as context to ground the model's answer (this retrieval step is what makes it RAG).

## Functions

1. [`loadModel()`](/sdk/reference/api#loadmodel) (with `modelType: "embeddings"`)
2. [`embed()`](/sdk/reference/api#embed) — generate vectors
3. Use any combination of the RAG functions below as needed:
   - [`ragChunk()`](/sdk/reference/api#ragchunk) — chunk documents
   - [`ragIngest()`](/sdk/reference/api#ragingest) — embed and store (requires model)
   - [`ragSaveEmbeddings()`](/sdk/reference/api#ragsaveembeddings) — save pre-computed vectors
   - [`ragSearch()`](/sdk/reference/api#ragsearch) — query similar documents (requires model)
   - [`ragReindex()`](/sdk/reference/api#ragreindex) — optimize search index
   - [`ragDeleteEmbeddings()`](/sdk/reference/api#ragdeleteembeddings) — remove documents
   - [`ragListWorkspaces()`](/sdk/reference/api#raglistworkspaces) — list workspaces
   - [`ragCloseWorkspace()`](/sdk/reference/api#ragcloseworkspace) — release resources
   - [`ragDeleteWorkspace()`](/sdk/reference/api#ragdeleteworkspace) — delete workspace and data
   - [`createVectorIndex()`](/sdk/reference/api#createvectorindex) — build a TurboVec index over your own documents
   - [`loadVectorIndex()`](/sdk/reference/api#loadvectorindex) — reopen a saved TurboVec index
4. [`unloadModel()`](/sdk/reference/api#unloadmodel)

For how to use each function, see [SDK — API reference](/sdk/reference/api/).

## Pipeline

Create your RAG pipeline using [text embeddings](/sdk/ai-capabilities/text-embeddings), the functions above, and [completion](/sdk/ai-capabilities/text-generation).

Regarding vector storage, you may use:

- **External vector DB:** use [`embed()`](/sdk/reference/api#embed) to generate vectors and store them wherever you want (e.g., MongoDB, LanceDB, ChromaDB, SQLite-Vector). Choose this when you need custom persistence, filtering, or integration with an existing database.
- **Built-in TurboVec index with your own document store:** use [`embed()`](/sdk/reference/api#embed) for vectors and [`createVectorIndex()`](/sdk/reference/api#createvectorindex) for on-device nearest-neighbour search. QVAC indexes the vectors; your documents stay in whatever store you already have, and results come back as the ids you assigned. Snapshots can be saved and reopened with [`loadVectorIndex()`](/sdk/reference/api#loadvectorindex).
- **Built-in vector store:** use the RAG workspace functions ([`ragIngest()`](/sdk/reference/api#ragingest), [`ragSearch()`](/sdk/reference/api#ragsearch), etc.). QVAC persists the vectors for you, so this is the simplest path.

<Callout type="warn">
  **Built-in vector store is not production grade** and is intended for
  prototypes only. For production workloads, use one of the external vector DB
  paths shown below (MongoDB, SQLite, LanceDB, Chroma, etc.).
</Callout>

<Callout type="info">
  **Important:** when using an external vector DB, make sure its schema matches
  the embedding dimensionality produced by your model (e.g., GTE Large
  embeddings used in the example are 1024‑dimensional).
</Callout>

"""Python port of packages/sdk/examples/rag/rag-hyperdb/ingest.ts.

Ingest documents into a built-in RAG workspace and query them with similarity
search, without setting up an external vector DB.

`rag` is a generated request-reply method covering every RAG operation: it
takes a `RagRequest` discriminated by `operation` and returns a `RagResponse`
(there are no flat `rag_ingest()` / `rag_search()` wrappers like the JS SDK's).
Both models are re-exported from the flat surface, and each is a union, so the
operation's own payload sits on the response's `.root`.

RUN: python examples/rag_managed.py [query]
"""

from __future__ import annotations

import asyncio
import sys

from tetherto.qvac_sdk import Client, RagRequest, load_model, rag, unload_model
from tetherto.qvac_sdk.models import GTE_LARGE_FP16


def print_progress(p) -> None:
    """Print model download progress; pass as `on_progress=` to `load_model`."""
    line = (
        f"▸ Downloading {p.percentage:.0f}% "
        f"({p.downloaded / 1e6:.1f}/{p.total / 1e6:.1f} MB)"
    )
    print(line, end="\r" if sys.stderr.isatty() else "\n", file=sys.stderr)
    if p.percentage >= 100:
        print(file=sys.stderr)


async def main() -> int:
    async with Client() as client:
        t = client.transport
        try:
            # Get query from command line or use default
            query = sys.argv[1] if len(sys.argv) > 1 else "machine learning algorithms"
            workspace = "ingest-example"

            print(f'▸ Query: "{query}"')
            model_id = await load_model(
                t, model_src=GTE_LARGE_FP16, on_progress=print_progress
            )

            samples = [
                "Machine learning is a subset of artificial intelligence that focuses on algorithms that can learn and make predictions from data without being explicitly programmed for every task.",
                "Deep learning uses neural networks with multiple layers to process and learn from complex data patterns, enabling breakthroughs in image recognition and natural language processing.",
                "Natural language processing combines computational linguistics with machine learning to help computers understand, interpret, and generate human language in a meaningful way.",
                "Computer vision enables machines to interpret and understand visual information from the world, using techniques like image classification, object detection, and facial recognition.",
                "Quantum computing leverages quantum mechanical phenomena to process information in fundamentally different ways than classical computers, potentially solving certain problems exponentially faster.",
                "Blockchain technology creates decentralized, immutable ledgers that enable secure peer-to-peer transactions without requiring a central authority or intermediary.",
                "Cloud computing delivers computing services over the internet, allowing users to access resources like storage, processing power, and applications on-demand from anywhere.",
                "Cybersecurity protects digital systems, networks, and data from malicious attacks, unauthorized access, and various forms of cyber threats through multiple layers of defense.",
            ]

            print("▸ Ingesting documents...")
            ingest = await rag(
                t,
                RagRequest.model_validate(
                    {
                        "type": "rag",
                        "operation": "ingest",
                        "modelId": model_id,
                        "workspace": workspace,
                        "documents": samples,
                        "chunk": False,
                    }
                ),
            )
            if not ingest.root.success:
                raise RuntimeError(ingest.root.error)
            print(f"▸ Ingested {len(ingest.root.processed)} documents")

            print("▸ Searching for similar documents...")
            search = await rag(
                t,
                RagRequest.model_validate(
                    {
                        "type": "rag",
                        "operation": "search",
                        "modelId": model_id,
                        "workspace": workspace,
                        "query": query,
                        "topK": 3,
                    }
                ),
            )
            if not search.root.success:
                raise RuntimeError(search.root.error)

            print("▸ Top 3 most similar documents:")
            for index, result in enumerate(search.root.results, start=1):
                print(f"{index}. (Score: {result.score})")
                print(f"   {result.content}")
                print()

            # Cleanup: close and delete workspace
            close = await rag(
                t,
                RagRequest.model_validate(
                    {
                        "type": "rag",
                        "operation": "closeWorkspace",
                        "workspace": workspace,
                        "deleteOnClose": True,
                    }
                ),
            )
            if not close.root.success:
                raise RuntimeError(close.root.error)
            print(f"▸ Deleted '{workspace}' workspace")

            await unload_model(t, model_id)
        except Exception as error:
            print(f"✖ {error}", file=sys.stderr)
            return 1
    return 0


if __name__ == "__main__":
    sys.exit(asyncio.run(main()))

// Kotlin port of packages/sdk/examples/rag/rag-hyperdb/ingest.ts.
//
// Ingest documents into a built-in RAG workspace and query them with similarity
// search, without setting up an external vector DB.
//
// `client.retrieval.execute()` covers every RAG operation. `RagRequest` and
// `RagResponse` are sealed classes with one variant per operation, so each
// request names its operation in the type (`RagRequest.Ingest(...)`) and each
// response is read off the matching variant (`as RagResponse.Ingest`), where
// the JS SDK has flat `ragIngest()` / `ragSearch()` wrappers.
//
// RUN: ./gradlew -p examples run -Pexample=RagManaged --args="[query]"

private val SAMPLES = listOf(
    "Machine learning is a subset of artificial intelligence that focuses on algorithms that can learn and " +
        "make predictions from data without being explicitly programmed for every task.",
    "Deep learning uses neural networks with multiple layers to process and learn from complex data patterns, " +
        "enabling breakthroughs in image recognition and natural language processing.",
    "Natural language processing combines computational linguistics with machine learning to help computers " +
        "understand, interpret, and generate human language in a meaningful way.",
    "Computer vision enables machines to interpret and understand visual information from the world, using " +
        "techniques like image classification, object detection, and facial recognition.",
    "Quantum computing leverages quantum mechanical phenomena to process information in fundamentally different " +
        "ways than classical computers, potentially solving certain problems exponentially faster.",
    "Blockchain technology creates decentralized, immutable ledgers that enable secure peer-to-peer transactions " +
        "without requiring a central authority or intermediary.",
    "Cloud computing delivers computing services over the internet, allowing users to access resources like " +
        "storage, processing power, and applications on-demand from anywhere.",
    "Cybersecurity protects digital systems, networks, and data from malicious attacks, unauthorized access, and " +
        "various forms of cyber threats through multiple layers of defense.",
)

fun main(args: Array<String>): Unit = runBlocking {
    // Get query from command line or use default
    val query = args.getOrNull(0) ?: "machine learning algorithms"
    val workspace = "ingest-example"

    val client = QvacClient(JvmBareKitTransport.connect())
    try {
        println("▸ Query: \"$query\"")
        val modelId = client.loadWithProgress(Models.GTE_LARGE_FP16)

        println("▸ Ingesting documents...")
        val ingest = client.retrieval.execute(
            RagRequest.Ingest(
                RagRequestIngest(
                    modelId = modelId,
                    workspace = workspace,
                    documents = RagRequestIngestDocuments.Variant2(SAMPLES),
                    chunk = false,
                ),
            ),
        ) as RagResponse.Ingest
        if (!ingest.value.success) error(ingest.value.error ?: "RAG ingest failed")
        println("▸ Ingested ${ingest.value.processed.size} documents")

        println("▸ Searching for similar documents...")
        val search = client.retrieval.execute(
            RagRequest.Search(
                RagRequestSearch(
                    modelId = modelId,
                    workspace = workspace,
                    query = query,
                    topK = 3.0,
                ),
            ),
        ) as RagResponse.Search
        if (!search.value.success) error(search.value.error ?: "RAG search failed")

        println("▸ Top 3 most similar documents:")
        search.value.results.forEachIndexed { index, result ->
            println("${index + 1}. (Score: ${result.score})")
            println("   ${result.content}")
            println()
        }

        // Cleanup: close and delete workspace
        val close = client.retrieval.execute(
            RagRequest.CloseWorkspace(RagRequestCloseWorkspace(workspace = workspace, deleteOnClose = true)),
        ) as RagResponse.CloseWorkspace
        if (!close.value.success) error(close.value.error ?: "RAG closeWorkspace failed")
        println("▸ Deleted '$workspace' workspace")

        client.models.unload(modelId)
    } finally {
        client.close()
    }
}

/** Load [model], printing download progress, and return its model id. */
private suspend fun QvacClient.loadWithProgress(model: ModelConstant): String {
    var result: LoadModelResponse? = null
    models.loadWithProgress(model.src, model.engine, model.name).collect { event ->
        when (event) {
            is QvacProgressEvent.Progress -> printProgress(event.value)
            is QvacProgressEvent.Result -> result = event.value
        }
    }
    val loaded = checkNotNull(result) { "loadModel ended without a result" }
    return loaded.modelId ?: error(loaded.error ?: "loadModel failed")
}

private fun printProgress(p: ModelProgressResponse) {
    val line = "▸ Downloading %.0f%% (%.1f/%.1f MB)".format(p.percentage, p.downloaded / 1e6, p.total / 1e6)
    if (System.console() != null) System.err.print("\r$line") else System.err.println(line)
    if (p.percentage >= 100) System.err.println()
}

<Callout type="info">
  TurboVec quantises vectors (`VectorIndexStorage.TURBOVEC_Q4` by default,
  `TURBOVEC_Q2` for half the memory) and needs a dimension divisible by 8 and no
  greater than 16,384. `GTE_LARGE_FP16` produces 1024-dimensional vectors and
  fits. Search uses dot products, so L2-normalise vectors when you need cosine
  similarity. The index lives in the SDK worker; after a worker restart, reopen
  it from the snapshot.
</Callout>

A fresh TurboVec index attempts TQ+ calibration before encoding its first successful nonempty `add()` batch when that batch has at least 1,000 vectors. A smaller first batch leaves it uncalibrated, and later adds do not calibrate it. `index.calibrated` reports the state after creation, loading, or the last successful add. Calibration improves recall when the fit succeeds and persists in snapshots.

Staged search is off for every new or loaded index. Use `await index.setStagedSearch({ enabled: true })` to trade recall for faster queries, or pass `false` to score every vector. On supported hosts, staged search applies at 32,768 or more vectors and a dimension divisible by 32. Other dimensions and indexes loaded from v3 snapshots retain the setting but search every vector. `index.stagedSearch` reports the setting, which is not saved in snapshots. Generic `F32`, `Q8`, and `Q4` storage reject staged search controls.

External index providers may omit these controls. Their `calibrated` and `stagedSearch` properties report `undefined`, and `setStagedSearch()` rejects with `VectorIndexFailedError` when unsupported.

#### SQLite

This example needs the vector extension for SQLite, which arrives differently per language. JavaScript and TypeScript use a SQLite WASM build that has the extension compiled in; Python uses the standard library's `sqlite3` module and loads the extension from a prebuilt binary. Install the one for the language you are using:

```bash
# JavaScript and TypeScript
npm i "@sqliteai/sqlite-wasm@3.50.4-sync.0.8.30-vector.0.9.23"

# Python
pip install "sqliteai-vector>=1.1"
```

Those are the versions these docs are tested against. Loading an extension also needs a Python configured with `--enable-loadable-sqlite-extensions`. Most distribution and python.org builds are; `pyenv`'s default build is not, and no package you install changes that — pass `-p` to `virtualenv` (or `--python` to `uv venv`) to base the environment on an interpreter that qualifies. The example checks before it starts and tells you if yours does not. The database is in-memory, so there is nothing else to set up.

In Kotlin, the [examples build](/sdk/kotlin-sdk#quickstart) adds the SQLite JDBC driver, `org.xerial:sqlite-jdbc:3.53.4.0`, to this example only. The driver always supports loadable extensions, but the vector extension itself is a prebuilt binary: download the one for your platform from the [sqlite-vector releases](https://github.com/sqliteai/sqlite-vector/releases) and point `SQLITE_VECTOR_EXTENSION` at it:

```bash
SQLITE_VECTOR_EXTENSION=/path/to/vector ./gradlew -p examples run -Pexample=RagSqlite
```
