`@qvac/sdk` is the JS/TS entry point to QVAC: a type-safe interface over every capability, running on Node.js, Bare, and Expo. It is also the worker the other clients speak to.

[Repository](https://github.com/tetherto/qvac/tree/main/packages/sdk) · [npm](https://www.npmjs.com/package/@qvac/sdk) · [Product documentation](/sdk)
