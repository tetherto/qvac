## Overview

The provider is a local HTTP server that exposes an [OpenAI-compatible API](https://developers.openai.com/api/reference/overview) over QVAC. Any tool that already speaks that API can point at it and run against models on your own machine, with no code change. It ships in the `@qvac/cli` npm package.

This line began as the `0.13` pages. The provider was documented as a single set until `0.13`, so nothing was written separately for `0.12`, and rather than publish nothing for a release people still run, these pages were carried back and corrected where they said something untrue of it. Where a page here differs from the current line, the difference is deliberate; where it does not, `0.12` and `0.13` behave the same.
