## Overview

The provider is a local HTTP server that exposes an [OpenAI-compatible API](https://developers.openai.com/api/reference/overview) over QVAC. Any tool that already speaks that API can point at it and run against models on your own machine, with no code change. It ships in the `@qvac/cli` npm package.
