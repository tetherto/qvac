## Overview

The inventory documents the packages QVAC publishes. A product collection — [SDK](/sdk), [CLI](/cli) — documents what a product is for and how to build with it, and reads as one thing however many packages deliver it. An inventory entry documents one distributable: what it is, how to install it, and what its surface is, as its own maintainers describe it.

Each entry is a package's `README.md`, published as it stood at the release it documents. Nothing is written for it and nothing is summarized from it, so what you read here is what ships with the package. For product guidance, follow the links back into the collections.

## How versions work here

A package entry is entered at its own path, and every version — the newest included — sits at a versioned one. So `/ecosystem/inventory/cli/` always serves the package index and never a release, and a URL never changes what it serves when a release happens.

That is the opposite of a product collection, where the current line answers at the version-less path and the switcher moves between lines. The inventory publishes no current line and offers no switcher: pick a version from the package's index.
