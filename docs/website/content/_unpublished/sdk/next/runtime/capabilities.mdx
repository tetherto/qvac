## Overview

An app built and released separately from the runtime it talks to cannot assume which operations that runtime serves: the runtime may have been assembled with a reduced plugin set, or with plugins from another vendor. [`getRuntimeCapabilities()`](/sdk/reference/api#getruntimecapabilities) lists the capability contracts the runtime's registered plugins declare, so the app can check for the contracts it needs before it loads a model.

Each entry names a contract and its major version:

```ts
{
  id: string                  // for example 'transcription'
  version: number             // major version, from 1
  operations: string[]        // every plugin that provides the contract implements these
  partialOperations: string[] // only some of those plugins implement these
}
```

The list is sorted by `id` and then `version`. A session handle has the same method and gets the same list. An empty list means the request succeeded and no registered plugin declares a contract. A runtime released before `getRuntimeCapabilities` rejects the request with an error instead, so treat an error as "capabilities unknown", not as "nothing available".

## Contracts

A contract groups the operations whose schemas share a core. QVAC defines these contracts, all at major 1:

| ID | Operations | Optional operations |
| --- | --- | --- |
| `completion` | `completionStream` | `batchCompletionStream`, `calcTokens` |
| `fine-tuning` | `finetune` | |
| `translation` | `translate` | |
| `embedding` | `embed`, `embedBatch` | |
| `reranking` | `rerank` | |
| `decision` | `decide` | |
| `classification` | `classify` | |
| `transcription` | `transcribe` | `transcribeStream` |
| `bci-transcription` | `bciTranscribe` | `bciTranscribeStream` |
| `text-to-speech` | `textToSpeech` | `textToSpeechStream` |
| `ocr` | `ocrStream` | |
| `stereo-depth-estimation` | `estimateDisparity` | |
| `image-generation` | `diffusionStream` | |
| `image-upscaling` | `upscaleStream` | |
| `video-generation` | `videoStream` | |
| `world-simulation` | `worldStepStream`, `worldSceneStream` | |
| `audio-generation` | `audioGenStream` | `audioEditStream` |
| `audio-understanding` | `audioUnderstand` | |
| `vision-language-action` | `vlaRun`, `vlaHparams`, `vlaSetEmbodiment` | |

A contract with a dotted ID, such as `acme.diarization`, is defined by a third-party plugin rather than by QVAC. A third-party plugin can also provide a QVAC contract.

An optional operation appears in `operations` when every plugin that provides the contract implements it, and in `partialOperations` when only some do. With the default plugin set, `transcribeStream` is in `partialOperations`: Whisper and Parakeet stream, MOSS does not. A call goes to the plugin of the model it names, so `transcribeStream` on a MOSS model still fails.

A contract names operations, not the inputs a provider accepts. `embedding@1` is provided by both a text embedding plugin and an image embedding plugin, so the model you load decides whether text or images work.

## Versions

Match on `id` and `version` together. A contract's major increases only on a change that breaks callers, such as removing an operation or changing a field's type. New optional fields and new optional operations do not change the major, and neither do SDK or addon releases.

An entry means that a registered plugin declares that major. The runtime checks that the plugin has a handler for each required operation, called the way the contract calls it, but not what the handler returns. When two majors of one contract are listed, each is a separate declaration: a call reaches the major that the plugin of the selected model serves.

## Limits

The list comes from plugin registration only. It loads no model, and it does not check:

- that a plugin's native addon loads on this device;
- that model files exist, or that the device has the memory to load them;
- which operations a particular model supports. A diffusion model, for example, still refuses `videoStream` although its plugin provides `video-generation`.

A call can therefore still fail with an error such as `ModelOperationNotSupportedError`.

A plugin that declares no contracts is not listed, and its operations can still be called as before.
