## Overview

Text embeddings use [`qvac-fabric-llm.cpp`](https://github.com/tetherto/qvac-fabric-llm.cpp) as the inference engine. Load a supported model using `modelType: "embeddings"`. Call `embed({ modelId, input: "query" })` for one text string, or `embedBatch({ modelId, inputs: ["first", "second"] })` for a batch.

`embed()` returns `embedding: number[]`. `embedBatch()` returns `embedding: number[][]`, with one vector per input in order, including one-item batches. `embed({ text: "query" })` still works. `embed({ text: ["first", "second"] })` and `embed({ inputs })` keep their original return shapes, but they are deprecated and log a warning. Use `embedBatch()` instead.

<Callout type="info">
For image and audio inputs with EmbeddingGemma 2, see [Multimodal embeddings](/sdk/ai-capabilities/multimodal-embeddings).
</Callout>

`modelConfig.pooling` accepts `"none"`, `"mean"`, `"cls"`, or `"last"`. Omit it to use the model default. `"rank"` fails validation, including in `deviceDefaults` in [`qvac.config.*`](/sdk/configuration): it produces reranker scores, not embeddings, and `embed()` does not support reranker models; use [reranking](/sdk/ai-capabilities/reranking) for those.

## Functions

Use the following sequence of function calls:
1. [`loadModel()`](/sdk/reference/api#loadmodel)
2. [`embed()`](/sdk/reference/api#embed) or [`embedBatch()`](/sdk/reference/api#embedbatch)
3. [`unloadModel()`](/sdk/reference/api#unloadmodel)

For how to use each function, see [SDK — API reference](/sdk/reference/api/).

## Models

You can load any [`llama.cpp`](https://github.com/ggml-org/llama.cpp)-compatible embeddings model. Model file format: `*.gguf`.

- If the model is sharded across multiple files (a multi-file bundle), see [Sharded models](/sdk/models/sharded-models).
- For models available as constants, see [SDK — Models](/sdk#models).
