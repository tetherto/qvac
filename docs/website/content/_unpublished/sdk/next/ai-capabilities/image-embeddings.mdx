## Overview

Image embeddings use a GGML inference engine through [`@qvac/classification-ggml`](https://github.com/tetherto/qvac/tree/main/packages/classification-ggml). Load MegaLoc with `modelType: "ggml-image-embedding"` and an explicit `modelSrc` pointing to a converted GGUF URL or local file.

Pass one JPEG or PNG as `image: Uint8Array` to [`embedImage()`](/sdk/reference/api#embedimage). For packed RGB bytes, also supply `width`, `height`, and `channels: 3`. Both dimensions must be integers from 1 to 16384, and the buffer must contain exactly `width * height * 3` bytes. Omit all three fields for encoded images. The addon converts the image to RGB and resizes it to 322 by 322 pixels without cropping or padding.

The result contains `embedding: number[]`, an L2-normalized descriptor with 8448 values, and optional `stats`. A dot product between two descriptors gives their cosine similarity. Use these descriptors to compare images of places or build an image retrieval index. Text embeddings and class labels use their own models and APIs.

## Functions

Use the following sequence of function calls:

1. [`loadModel()`](/sdk/reference/api#loadmodel)
2. [`embedImage()`](/sdk/reference/api#embedimage)
3. [`unloadModel()`](/sdk/reference/api#unloadmodel)

For how to use each function, see [SDK API reference](/sdk/reference/api/).

## Models

MegaLoc requires one converted GGUF file. The supported formats are F16 weights, or an F16 body with a Q6_K final projection. Weights are not bundled with the addon. While registry registration is pending, replace the example's `https://models.example.com/megaloc-f16.gguf` placeholder with the converted model's direct HTTPS URL or a local file path.

The original safetensors checkpoint cannot be loaded directly. See the addon's [MegaLoc conversion guide](https://github.com/tetherto/qvac/blob/main/packages/classification-ggml/docs/megaloc.md) for conversion and model provenance.

## Features

Choose a device with `modelConfig.backend`, using its exact GGML name, such as `CPU`, `CUDA0`, `Vulkan0`, or `MTL0`. `Metal` and `Metal0` are aliases. If omitted, the addon selects a GPU, then CPU. An explicitly requested device must be available. `modelConfig.threads` accepts integers from 1 to 1024. `modelConfig.backendsDir` optionally selects a directory of GGML backend modules.

`stats` exposes `totalTime` in milliseconds, `weightBytes`, `cpuFallbackNodes`, and `backendId`. Backend IDs are CPU=0, Metal=1, CUDA=2, Vulkan=3, OpenCL=4, and other=99. GPU support depends on the installed Fabric build.

When bundling a plugin subset, include `@qvac/sdk/ggml-image-embedding/plugin` or `PLUGIN_IMAGE_EMBEDDING`. The default SDK worker includes it. The `ggml-classification` plugin continues to load MobileNet classifiers.

## Cancellation

Calls queue FIFO per model, with one active call and at most 64 waiting. Different models run independently. The returned promise exposes `requestId` immediately. Use [`cancel({ requestId })`](/sdk/reference/api#cancel) to cancel that call, or `cancel({ modelId, kind: "imageEmbedding" })` for all matching calls.

Cancelling a queued call prevents native inference from starting. Cancelling an active call discards its result after native inference finishes and rejects with `InferenceCancelledError`. The next call waits until that work finishes. MegaLoc does not expose a public method to interrupt native computation.
