## Overview

Fine-tuning trains a [LoRA](https://arxiv.org/abs/2106.09685) (Low-Rank Adaptation) adapter on top of an LLM base model, to be used at inference time with [completion](/sdk/ai-capabilities/text-generation).

Load any supported LLM using `modelType: "llm"`. Then call `finetune()` with the dataset and training settings. Training can be done in two modes:

- [SFT](#sft): chat-based; enable with `assistantLossOnly: true`.
- [Causal](#causal): raw text; default (`assistantLossOnly: false`).

The output is a small `.gguf` adapter file that you can pass to `completion()` via `modelConfig.lora`.

## Functions

Use the following sequence of function calls:
1. [`loadModel()`](/sdk/reference/api#loadmodel)
2. [`finetune()`](/sdk/reference/api#finetune)
3. [`unloadModel()`](/sdk/reference/api#unloadmodel)

For how to use each function, see [SDK — API reference](/sdk/reference/api/).

## Models

You can load any `llama.cpp`-compatible [text-generation/chat](/sdk/ai-capabilities/text-generation) model that meets the following criteria:
- **File format:** `*.gguf` (or use constants)
- **Architecture:** `qwen3`, `qwen35` (Qwen3.5, Qwen3.6, and Qwen3.8 dense), `qwen35moe` (Qwen3.6-35B-A3B), `gemma3`, `gemma4`, or `bitnet`
- **Quantization:** `F32`, `F16`, `Q4_0`, `Q8_0`, `TQ1_0`, or `TQ2_0`

<Callout type="info">

In QVAC, not every model compatible with text generation/chat is also compatible with fine-tuning. Only those that meet all the criteria above are. `finetune()` checks the quantization first and the architecture second, and reports only the first failure: a model that fails both shows the architecture error only after you fix the quantization.

</Callout>

For models available as constants, see [SDK — Models](/sdk#models). Most LLM constants are `Q4_K_M`, `Q6_K`, or `UD` (`*_K_XL`) quantizations and can't be fine-tuned as shipped. The fine-tunable constants are:
- `QWEN3_600M_INST_Q4`, `QWEN3_1_7B_INST_Q4`, `QWEN3_1_7B_INST_Q4_SHARD`, and `QWEN3_4B_INST_Q4_SHARD` (`Q4_0`)
- `QWEN3_5_0_8B_MULTIMODAL_Q8_0`, `QWEN3_5_2B_MULTIMODAL_Q8_0`, and `GEMMA4_2B_MULTIMODAL_Q8_0` (`Q8_0`)
- `BITNET_0_7B_BASE_TQ2_0`, `BITNET_1B_BASE_TQ2_0`, and `BITNET_B1_58_3B_BASE_TQ2_0` (`TQ2_0`)

To fine-tune another model, pass a local `Q4_0` or `Q8_0` GGUF of a supported architecture as `modelSrc` (for example, the `Q4_0` file from `unsloth/Qwen3.5-9B-GGUF`). The quantization check reads `general.file_type` from the GGUF header, not the file name: for example, `QWEN3_8_27B_MULTIMODAL_UD_Q8_K_XL` is rejected despite `Q8` in its name. Check a model's quantization with [`getModelInfo()`](/sdk/reference/api#getmodelinfo) before training.

## Training

### Context length

`finetune()` trains at `options.contextLength` tokens per sequence (default: `128`), not at the `ctx_size` you set in `loadModel()`. Training reloads the model with this context length; the original `loadModel()` context size does not cap it. Set it to fit your longest training row:
- **SFT:** rows longer than `contextLength` are skipped without a warning. If every row is skipped, training can't start.
- **Causal:** the dataset must contain at least `contextLength + 1 + max(contextLength / 2, 1)` tokens, using integer division. With the default `contextLength` of `128`, the minimum is `193` tokens.

### SFT

Supervised fine-tuning (SFT) teaches the model how to respond to prompts. Use it for chat tuning, instruction following, or any task where you want to shape assistant responses.

**Dataset format:** JSONL where each line is a JSON object with a `messages` array. Supported roles: `system`, `user`, `assistant`, and `tool`. Example:

```jsonl
{"messages":[{"role":"system","content":"You are a helpful assistant."},{"role":"user","content":"What is 2+2?"},{"role":"assistant","content":"2+2 equals 4."}]}
{"messages":[{"role":"user","content":"What is the capital of France?"},{"role":"assistant","content":"The capital of France is Paris."}]}
```

### Causal

Causal fine-tuning adapts the model to a domain by training on raw text. Use it for domain adaptation, style transfer, or tasks where you want the model to better reflect specialized vocabulary, patterns, or tone.

**Dataset format:** plain text file. Example:

```
This is sample training text.
Another paragraph of content.
```
