# QVAC ONNX Addon v0.14.0 Release Notes

This release upgrades the shared ONNX Runtime layer used by QVAC addons from 1.22.0 to 1.24.2. It keeps the existing addon API intact while moving the package onto the newer custom vcpkg baseline that will be published to npm with this release.

## Changes

### Upgrade shared ONNX Runtime baseline to 1.24.2

The addon now resolves ONNX Runtime 1.24.2 from the QVAC vcpkg registry baseline instead of the older 1.22.0 toolchain. This keeps desktop and mobile builds aligned on the newer runtime and refreshes the platform-specific DirectML, CoreML, and NNAPI support shipped with the addon.

## Compatibility Notes

### XNNPack disabled in the default release build

The release build for `v0.14.0` does not enable XNNPack by default while the ONNX Runtime 1.24.2 migration is validated against the current upstream XNNPACK API. Core ONNX Runtime support and the existing JavaScript and C++ addon APIs remain available, but builds produced from the default package pipeline should not assume `XnnpackExecutionProvider` is present.

## Backward Compatibility

No JavaScript or C++ API changes are intended in this release. Existing consumers should only need to update to `@qvac/onnx@^0.14.0` and rebuild against the refreshed prebuild set.
