Checking WebGPU…

Each page runs one SDK feature in a Dedicated Worker on WebGPU. Models download once into the browser's private storage (OPFS) and are reused by every page.

  • CompletionStreaming, generation parameters, stats and the backend device.
  • CancelCancel a run by request id, then run again on the same model.
  • Tool calling and reasoningA tool round trip with Qwen3.5, with its thinking shown separately.
  • Sharded modelLoad a split GGUF from a URL or from picked files.
  • MultimodalAsk about an image, with a projection model.
  • LoRA adapterThe same prompt with and without an adapter.
  • Speculative decodingAn external MTP draft model, with accepted-token stats.
  • Batch completionThree prompts decoded together with parallel: 2.
  • KV cache on diskTurn 1, reload the page, turn 2 reuses the saved cache.
  • Model fit and finetuningassessModelFit, then a short finetune that saves a LoRA adapter.

Enable Vulkan in Chrome on Linux

Chrome did not expose a WebGPU adapter with shader-f16. A page cannot change browser settings.

  1. Open chrome://flags/#enable-vulkan in the address bar.
  2. Set Vulkan to Enabled.
  3. Relaunch Chrome and reopen this page.

Do not enable Unsafe WebGPU, Ignore GPU blocklist, or Dawn overrides.
