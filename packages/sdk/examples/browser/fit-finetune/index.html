QVAC SDK in the browser

Model fit and finetuning

Checking WebGPU…

1. Check the fit before loading


        

          The fit is sized from a model's registry description, which a URL does not have, and the
          browser cannot read free GPU memory, so the verdict is unknown with a
          reason. Show it as "can't say", never as "no".
        

      


      

        
2. Finetune a LoRA adapter

        

          Loads the model, trains a small adapter on a built-in dataset of short answers, and saves
          it in browser storage. Training may fall back to the CPU for operations WebGPU lacks, so
          it can take 20 minutes or more.
        

        

          
          
        

        

        

        

          Then open the LoRA page to compare answers with it.
