assessModelFit — estimate vs. reality

Estimate reads catalog metadata and one memory sample: no download, no load. Run loads the model for real and generates a few tokens, so the verdict can be checked against what happens. Each row is judged on its own, not as one co-resident set. Watch the elapsed time: a likely-too-large model usually still runs on an OS with swap, just badly — the verdict is about the interactive budget, not about whether the load throws.
