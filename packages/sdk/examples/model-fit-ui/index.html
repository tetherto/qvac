assessModelFit — estimate vs. reality

Estimate reads catalog metadata and one memory sample: no download, no load. Run loads the model for real and generates a few tokens, so the verdict can be checked against what happens. Each row is judged on its own, not as one co-resident set. Reality puts the memory the load actually took next to the predicted range. A likely-too-large that runs means either the OS reclaimed or compressed other memory to make room, or the estimate was off — the measured figure says which.
