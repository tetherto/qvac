Opens a bidirectional transcription session with a loaded Whisper or Parakeet model. You write raw audio chunks to the session and iterate it for transcript output as the engine decodes speech. Depending on the options, the session yields text, segments, or a stream of conversation events (text, segments, voice activity, end of turn). For a complete recording, use [`transcribe()`](/sdk/reference/api/transcribe). See [Transcription](/sdk/ai-capabilities/transcription) and [Voice assistant](/sdk/ai-capabilities/voice-assistant).

## Signature

```ts
function transcribeStream(params: TranscribeClientParams & { metadata: true }, options?: RPCOptions): AsyncGenerator<TranscribeSegment>;
function transcribeStream(params: TranscribeClientParams, options?: RPCOptions): AsyncGenerator<string>;
function transcribeStream(params: TranscribeStreamClientParams & { emitVadEvents: true }, options?: RPCOptions): Promise<TranscribeStreamConversationSession>;
function transcribeStream(params: TranscribeStreamClientParams & { parakeetStreamingConfig: NonNullable<TranscribeStreamClientParams['parakeetStreamingConfig']> }, options?: RPCOptions): Promise<TranscribeStreamConversationSession>;
function transcribeStream(params: TranscribeStreamClientParams & { metadata: true }, options?: RPCOptions): Promise<TranscribeStreamMetadataSession>;
function transcribeStream(params: TranscribeStreamClientParams, options?: RPCOptions): Promise<TranscribeStreamSession>;
```

The options select the form. They are checked in this order:

| Form | `params` | Returns | Use it when |
| --- | --- | --- | --- |
| Upfront audio (deprecated) | [`TranscribeClientParams`](/sdk/reference/api/transcribe#transcribeclientparams), with `audioChunk` set | `AsyncGenerator<string>`, or `AsyncGenerator<TranscribeSegment>` with `metadata: true` | Never in new code. Pass the audio to [`transcribe()`](/sdk/reference/api/transcribe) instead; this form is removed in the next major version and logs a warning. |
| Conversation session | [`TranscribeStreamClientParams`](#transcribestreamclientparams) with `emitVadEvents: true` or `parakeetStreamingConfig` set | [`TranscribeStreamConversationSession`](#session) | You need voice-activity or end-of-turn events, or per-call Parakeet streaming settings. |
| Segment session | [`TranscribeStreamClientParams`](#transcribestreamclientparams) with `metadata: true` | [`TranscribeStreamMetadataSession`](#session) | You need segment timing and engine detail. |
| Text session | [`TranscribeStreamClientParams`](#transcribestreamclientparams) | [`TranscribeStreamSession`](#session) | You need the transcript text only. |

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model and session options. One of the forms above. | See [forms](#signature) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](/sdk/reference/api/transcribe#rpcoptions) | No |

### `TranscribeStreamClientParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a loaded Whisper or Parakeet model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes | — |
| `prompt` | Initial Whisper context. Parakeet ignores it. An empty string is not sent. | `string` | No | — |
| `metadata` | Yield segments instead of text. In a conversation session, yields `segment` events instead of `text` events. | `boolean` | No | `false` |
| `emitVadEvents` | Whisper only: yield `vad` events as speech starts and stops. Selects the conversation session. | `boolean` | No | `false` |
| `endOfTurnSilenceMs` | Whisper only: silence, in milliseconds, before an `endOfTurn` event fires. A non-negative integer; `0` or unset disables end-of-turn detection. | `number` | No | — |
| `vadRunIntervalMs` | Whisper only: how often the VAD is evaluated, in milliseconds. A positive integer. | `number` | No | Engine default |
| `parakeetStreamingConfig` | Parakeet only: per-call overrides of the load-time streaming settings. Selects the conversation session. | [`ParakeetStreamingRunConfig`](#parakeetstreamingrunconfig) | No | Load-time values |

#### `ParakeetStreamingRunConfig`

Each field overrides its `streaming*` counterpart in the Parakeet load configuration (for example, `chunkMs` overrides `streamingChunkMs`). A field left out keeps the load-time value.

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `chunkMs` | Streaming chunk cadence, in milliseconds. Nemotron supports `80`, `160`, `320`, `560`, or `1120`. Positive integer. | `number` | No |
| `historyMs` | Sortformer rolling-history window, in milliseconds. Positive integer. | `number` | No |
| `leftContextMs` | ASR encoder left-context window, in milliseconds. Non-negative integer. | `number` | No |
| `rightLookaheadMs` | ASR encoder right-lookahead window, in milliseconds. Non-negative integer. | `number` | No |
| `emitPartials` | Emit partial results before chunk boundaries. | `boolean` | No |
| `emitEnergyVad` | Run the engine's RMS energy detector on CTC, TDT, RNN-T, and Nemotron streaming sessions, and emit `vad` events with `source: "energy"` on each speech/silence transition. | `boolean` | No |
| `energyVadThresholdDb` | Energy-VAD speech threshold, in dBFS RMS; audio above it counts as speech. | `number` | No |
| `energyVadWindowMs` | Energy-VAD RMS window, in milliseconds; the engine caps it at 1000. Positive integer. | `number` | No |
| `energyVadHangoverMs` | Silence the energy VAD requires before leaving the speaking state, in milliseconds. Non-negative integer. | `number` | No |
| `emitSpeakerVad` | Emit speaker-activity `vad` events with the dominant speaker ID during diarization streaming. | `boolean` | No |
| `diarizationThreshold` | Speaker-activity threshold, from 0 to 1. | `number` | No |
| `diarizationMinSegmentMs` | Shortest diarization turn, in milliseconds. Non-negative integer. | `number` | No |
| `spkCacheEnable` | AOSC (Sortformer v2.1): enable speaker-cache streaming. | `boolean` | No |
| `spkCacheLen` | AOSC: long-term speaker-cache rows. Positive integer. | `number` | No |
| `fifoLen` | AOSC: FIFO warmup buffer rows. Positive integer. | `number` | No |
| `chunkLeftContextMs` | Diarization encoder left-context window, in milliseconds. Non-negative integer. | `number` | No |
| `chunkRightContextMs` | AOSC: encoder right-context window, in milliseconds. Non-negative integer. | `number` | No |
| `spkCacheUpdatePeriod` | AOSC: FIFO-overflow pop-out count. Positive integer. | `number` | No |

## Returns

The session forms return a promise that resolves once the duplex connection is open. The deprecated upfront-audio form returns an async generator directly.

### Session

The three session types share one shape and differ only in what iteration yields.

| Field | Description | Type |
| --- | --- | --- |
| `write(audioChunk)` | Sends a chunk of raw PCM audio. Write it in the format the model reads: the Whisper model's `audio_format`, or 16 kHz mono `s16le` for Parakeet. | `(audioChunk: Uint8Array) => void` |
| `end()` | Closes the audio input. The engine finishes the audio it has and sends its terminal frame, which ends iteration. | `() => void` |
| `destroy()` | Tears down both directions of the connection at once. `stats` and `diagnostics` resolve `undefined`. | `() => void` |
| `[Symbol.asyncIterator]()` | Iterates the output. A session can be iterated once. | `TranscribeStreamSession`: `string`; `TranscribeStreamMetadataSession`: [`TranscribeSegment`](/sdk/reference/api/transcribe#transcribesegment); `TranscribeStreamConversationSession`: [`TranscribeStreamEvent`](#transcribestreamevent) |
| `stats` | Engine statistics from the terminal frame. Resolves `undefined` when the stream closes without them, rejects when the stream fails. | `Promise<` [`TranscribeStats`](/sdk/reference/api/transcribe#transcribestats) ` \| undefined>` |
| `diagnostics` | Backend selection detail for the session, settled from the same terminal frame as `stats`. | `Promise<` [`InferenceBackendDiagnostics`](#inferencebackenddiagnostics) ` \| undefined>` |

Iteration skips text that is empty or only whitespace. It ends on the engine's terminal frame, or when the connection closes. Lines the client cannot parse are logged and skipped.

#### `TranscribeStreamEvent`

What a conversation session yields. Narrow on `type`.

| Event | Fields | Emitted when |
| --- | --- | --- |
| `{ type: "text" }` | `text: string` | New transcript text is available (without `metadata`). |
| `{ type: "segment" }` | `segment:` [`TranscribeSegment`](/sdk/reference/api/transcribe#transcribesegment) | A segment is available (with `metadata: true`). |
| `{ type: "vad" }` | `speaking: boolean`, `probability: number`, and optionally `source`, `timestamp`, `speakerId` | Voice-activity state changes. `source` is `"silero"` for Whisper, `"energy"` for Parakeet energy VAD, `"sortformer"` for Sortformer speaker activity. `timestamp` (Parakeet) is seconds from the start of the session. `speakerId` is the dominant speaker during Parakeet diarization. |
| `{ type: "endOfTurn", source: "whisper" }` | `silenceDurationMs: number` | Whisper measured `endOfTurnSilenceMs` of silence. |
| `{ type: "endOfTurn", source: "parakeet" }` | — | A Parakeet EOU model emitted its end-of-utterance token. |

#### `InferenceBackendDiagnostics`

| Field | Description | Type |
| --- | --- | --- |
| `selectedBackend` | Backend the session ran on. | `string` |
| `selectedDevice` | Device class the session ran on. | `"cpu" \| "gpu"` |
| `graphicsApi` | Graphics API of the selected backend. | `"vulkan" \| "opencl" \| "opengl" \| "webgpu" \| "metal" \| "direct3d11" \| "direct3d12" \| "cuda" \| "levelZero" \| "rocm"` |
| `driver` | Driver of the selected backend. | `{ name: string; version?: string }` |
| `gpuId` | GPU ID from the current worker's resource collector; stable only for that collector's lifetime. | `string` |
| `fallback` | Present when the run did not get the backend it asked for: what was requested and why it fell back. | `{ requestedBackend?: string; requestedDevice?: "cpu" \| "gpu"; reason: string }` |
| `probe` | Backend compatibility probe result. | `{ status: "compatible" \| "incompatible" \| "unknown"; backend: string; reason?: string }` |

### Upfront audio (deprecated)

An async generator that sends the whole `audioChunk` and yields each non-empty text chunk (or each segment, with `metadata: true`) as it arrives. It ends on the terminal frame.

## Throws

| Error | When |
| --- | --- |
| `TranscriptionFailedError` | A session is iterated a second time. |
| `TranscriptionFailedError` | The server sends an error frame during iteration. `stats` and `diagnostics` reject with the same error. |
| `QvacErrorBase` | The session cannot be opened; the message carries the details. |

## Examples

```ts
// Whisper text session: write PCM, then read the transcript.
const session = await transcribeStream({ modelId });

const reader = (async () => {
  for await (const text of session) process.stdout.write(text);
})();

for (const chunk of pcmChunks) session.write(chunk);
session.end();
await reader;

const stats = await session.stats;
console.log(stats?.audioDuration, stats?.realTimeFactor);

// Whisper conversation session with VAD and end-of-turn events.
const conversation = await transcribeStream({
  modelId,
  emitVadEvents: true,
  endOfTurnSilenceMs: 800,
});
microphone.on("data", (chunk) => conversation.write(chunk));

for await (const event of conversation) {
  switch (event.type) {
    case "text":
      console.log(event.text);
      break;
    case "vad":
      console.log("speaking:", event.speaking);
      break;
    case "endOfTurn":
      if (event.source === "whisper") console.log(`turn ended after ${event.silenceDurationMs} ms`);
      break;
  }
}

// Parakeet EOU model with per-call streaming settings.
const parakeetId = await loadModel({ modelSrc: PARAKEET_EOU_120M_V1_Q8_0 });
const parakeet = await transcribeStream({
  modelId: parakeetId,
  parakeetStreamingConfig: { chunkMs: 1000, emitPartials: true },
});
```
