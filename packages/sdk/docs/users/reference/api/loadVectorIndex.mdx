Loads a snapshot written by a vector index's `write()` method into the SDK worker's memory and resolves with a [`VectorIndex`](/sdk/reference/api/createVectorIndex#vectorindex) handle, with the same methods as one from [`createVectorIndex()`](/sdk/reference/api/createVectorIndex). Use it to reopen a saved index, including after a worker restart. See [RAG](/sdk/ai-capabilities/rag).

## Signature

```ts
function loadVectorIndex(params: LoadVectorIndexParams, options?: RPCOptions): Promise<VectorIndex>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The snapshot to load. | [`LoadVectorIndexParams`](#loadvectorindexparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `LoadVectorIndexParams`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `path` | Path of the snapshot file. Cannot be empty. An absolute path is used as given; a relative path resolves under the QVAC data directory, as in `write()`. | `string` | Yes |

### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. | [`PerCallProfiling`](#percallprofiling) | No |

#### `PerCallProfiling`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `enabled` | Profile this call only. When omitted, the global profiler configuration applies. | `boolean` | No |
| `includeServerBreakdown` | Include the server-side timing breakdown in the profiling payload. | `boolean` | No |
| `includeResourceGauges` | Attach one local CPU, memory, and GPU resource sample to the operation event. | `boolean` | No |
| `mode` | Detail level: `"summary"` keeps aggregates only, `"verbose"` keeps recent events. | `"summary" \| "verbose"` | No |

## Returns

A promise that resolves with a [`VectorIndex`](/sdk/reference/api/createVectorIndex#vectorindex) handle holding the snapshot's entries. `dim` and `length` come from the snapshot. `storage` is derived from the snapshot's bit width, so a 4-bit snapshot (`q4` or `turbovec-q4`) reports `undefined`.

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `path` is empty. |
| `VECTOR_INDEX_PROVIDER_UNAVAILABLE` | No registered plugin exposes a vector index provider, such as the built-in `llamacpp-embedding` plugin. |
| `VECTOR_INDEX_FAILED` | The file is missing, corrupt, or not a vector index snapshot. |

## Examples

```ts
const index = await loadVectorIndex({ path: "indexes/notes.qvi" });
console.log(`${index.length} vectors of dimension ${index.dim}`);

const { embedding: query } = await embed({ modelId, text: "Which moon has methane rain?" });
const hits = await index.search({ query, k: 3 });

await index.dispose();
```
