Synthesizes audio with a loaded text-to-speech model and returns a result object synchronously. Depending on `stream` and `sentenceStream`, the audio arrives in one piece through `buffer`, sample by sample or chunk by chunk through `bufferStream` / `chunkStream`, or chunk by chunk with sentence metadata through `chunkUpdates`. The same call drives MOSS-SoundEffect (sound effects from a description) and MOSS-Speech (spoken or text replies to a text or audio question). When the text itself arrives incrementally, use [`textToSpeechStream()`](/sdk/reference/api/textToSpeechStream). See [Text-to-Speech](/sdk/ai-capabilities/text-to-speech).

## Signature

```ts
function textToSpeech(params: TtsClientParamsInput, options?: RPCOptions): TextToSpeechStreamResult;
```

`stream` and `sentenceStream` select how the audio is delivered:

| Mode | Options | Audio arrives in | Use it when |
| --- | --- | --- | --- |
| Streamed (default) | `stream: true` | `bufferStream` or `chunkStream` | You want to start playback before synthesis ends. |
| Sentence-streamed | `stream: true, sentenceStream: true` | `bufferStream`, `chunkStream`, or `chunkUpdates` | You also need to know which sentence chunk each piece of audio belongs to. |
| Collected | `stream: false` | `buffer` | You want the complete audio in one array. |

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | What to synthesize and how. | [`TtsClientParamsInput`](#ttsclientparamsinput) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](/sdk/reference/api/transcribe#rpcoptions) | No |

### `TtsClientParamsInput`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a loaded TTS model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes | — |
| `text` | Text to synthesize, or the sound description for MOSS-SoundEffect, or the typed question for MOSS-Speech. Must not be empty or whitespace-only. Supply exactly one of `text` and `audio`. | `string` | Yes, unless `audio` is set | — |
| `requestId` | ID for this run, used instead of a generated one. Must be non-empty. | `string` | No | Generated |
| `inputType` | Input type. Synthesis always reads `text` as plain text. | `string` | No | `"text"` |
| `stream` | Deliver the audio incrementally through `bufferStream` / `chunkStream`. When `false`, the complete audio resolves on `buffer`. | `boolean` | No | `true` |
| `sentenceStream` | Split the text into sentence chunks and also deliver per-chunk metadata on `chunkUpdates`. Requires `stream: true`. | `boolean` | No | `false` |
| `sentenceStreamLocale` | BCP-47 locale for sentence splitting. Applies when the text is split into sentences; a MOSS request accepts it only with `sentenceStream: true`. | `string` | No | The model's language |
| `sentenceStreamMaxChunkScalars` | Maximum graphemes per sentence chunk. Positive. Same applicability as `sentenceStreamLocale`. | `number` | No | `300`, or `120` for Korean |
| `description` | Parler: free-text voice description. Cannot be combined with `voiceDescription` or with the voice-template fields. | `string` | No | — |
| `voiceDescription` | Alias of `description`, with the same restrictions. | `string` | No | — |
| `voice` | Parler voice-template speaker name. | `string` | No | — |
| `emotion` | Speaking style. Parler accepts every value; CosyVoice3 accepts `"anger"`, `"happy"`, `"neutral"`, and `"sad"`. | [`TtsParlerEmotion`](#ttsparleremotion) | No | — |
| `pitch` | Parler voice-template pitch descriptor. | `string` | No | — |
| `pace` | Speaking rate. Parler and CosyVoice3. On CosyVoice3, a non-`"moderate"` pace cannot be combined with `emotion`. | `"slow" \| "moderate" \| "fast"` | No | — |
| `expressivity` | Parler voice-template expressivity descriptor. | `string` | No | — |
| `noise` | Parler voice-template background-noise descriptor. | `string` | No | — |
| `reverb` | Parler voice-template reverb descriptor. | `string` | No | — |
| `quality` | Parler voice-template audio-quality descriptor. | `string` | No | — |
| `seconds` | MOSS-SoundEffect: effect duration in seconds, greater than 0 and at most 30. | `number` | No | — |
| `negativePrompt` | MOSS-SoundEffect: description of sounds to avoid. | `string` | No | — |
| `steps` | MOSS-SoundEffect: diffusion denoising steps, an integer from 1 to 1000. | `number` | No | `100` |
| `guidance` | MOSS-SoundEffect: classifier-free guidance scale, from 1 to 50. | `number` | No | — |
| `shift` | MOSS-SoundEffect: diffusion timestep schedule shift, greater than 0 and at most 100. | `number` | No | — |
| `audio` | MOSS-Speech: the spoken question, as mono samples in `[-1, 1]`. Requires `sampleRate`. Supply exactly one of `text` and `audio`. | `number[]` | No | — |
| `sampleRate` | MOSS-Speech: sample rate of `audio`, an integer from 8000 to 192000 Hz. Required with `audio`. | `number` | No | — |
| `messages` | MOSS-Speech: earlier turns, oldest first. The new question is appended after them. | [`MossSpeechMessage[]`](#mossspeechmessage) | No | — |
| `systemPrompt` | MOSS-Speech: a system turn placed first; replaces the model's default system prompt. | `string` | No | — |
| `replyVoice` | MOSS-Speech: reply voice prompt, as mono samples in `[-1, 1]`. Requires `replyVoiceSampleRate`. | `number[]` | No | The codec's default voice |
| `replyVoiceSampleRate` | MOSS-Speech: sample rate of `replyVoice`, an integer from 8000 to 192000 Hz. Required with `replyVoice`. | `number` | No | — |
| `textReply` | MOSS-Speech: reply with text only; the audio buffer is empty and the text resolves on `text`. | `boolean` | No | — |
| `maxReplySeconds` | MOSS-Speech: cut the spoken reply after this many seconds, from 0 to 3600. `0` means no cut. | `number` | No | — |
| `maxNewTokens` | MOSS-Speech: bound on generated rows, an integer from 1 to 4096. | `number` | No | Remaining model context |
| `greedy` | MOSS-Speech: greedy decoding instead of sampling. | `boolean` | No | — |
| `temperature` | MOSS-Speech: sampling temperature, greater than 0 and at most 10. | `number` | No | `0.7` |
| `topP` | MOSS-Speech: nucleus sampling, greater than 0 and at most 1. | `number` | No | `0.95` |
| `topK` | MOSS-Speech: top-k sampling, a non-negative integer. | `number` | No | `20` |

The voice-template fields are `voice`, `emotion`, `pitch`, `pace`, `expressivity`, `noise`, `reverb`, and `quality`. Sending any of `description`, `voiceDescription`, or a voice-template field to an engine other than Parler — or anything but `emotion` and `pace` to CosyVoice3 — is rejected by the server.

#### `TtsParlerEmotion`

`"command" | "anger" | "narration" | "conversation" | "disgust" | "fear" | "happy" | "neutral" | "proper noun" | "news" | "sad" | "surprise"`

#### `MossSpeechMessage`

A turn carries `text` or `audio`, never both.

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `role` | Who spoke the turn. | `"system" \| "user" \| "assistant"` | Yes |
| `text` | The turn as text. Non-empty. | `string` | No |
| `audio` | The turn as mono samples in `[-1, 1]`. Requires `sampleRate`. | `number[]` | No |
| `sampleRate` | Sample rate of `audio`, an integer from 8000 to 192000 Hz. | `number` | No |

## Returns

A `TextToSpeechStreamResult`, returned synchronously. In the default streamed mode the request is sent when you start iterating `bufferStream` or `chunkStream`; in the other two modes it is sent at once.

| Field | Description | Type |
| --- | --- | --- |
| `requestId` | ID of this run, available synchronously. Pass it to [`cancel({ requestId })`](/sdk/reference/api/cancel) to stop synthesis. Abandoning a stream stops delivery but leaves the native job running. | `string` |
| `buffer` | The complete audio, as signed 16-bit mono PCM samples, when `stream: false`. Resolves `[]` in the streamed modes. | `Promise<number[]>` |
| `bufferStream` | The audio one sample at a time. Empty when `stream: false`. | `AsyncGenerator<number>` |
| `chunkStream` | The same audio as one `Int16Array` per response frame: signed 16-bit mono samples. Empty when `stream: false`. Shares the run with `bufferStream`, so iterate one of the two. | `AsyncGenerator<Int16Array>` |
| `chunkUpdates` | Present only with `sentenceStream: true`: one update per frame that carries audio or chunk metadata. | `AsyncGenerator<` [`TtsSentenceChunkUpdate`](#ttssentencechunkupdate) `>` |
| `done` | Resolves `true` when the run ends. In the default streamed mode it resolves `false` when you stop iterating before the end. Rejects when the run fails. | `Promise<boolean>` |
| `sampleRate` | Sample rate of the PCM, in Hz, resolved from the first audio frame. `undefined` when the run produced no audio. Read it rather than assuming the engine default. | `Promise<number \| undefined>` |
| `text` | MOSS-Speech reply text, resolved when the run finishes. | `Promise<string \| undefined>` |
| `stats` | Runtime statistics from the final frame. `undefined` when the run ended before the engine reported any. | `Promise<` [`TtsStats`](#ttsstats) ` \| undefined>` |
| `stopReason` | `"cancelled"` when [`cancel()`](/sdk/reference/api/cancel) stopped the run, `"completed"` otherwise; `undefined` when no terminal frame was seen. | `Promise<"completed" \| "cancelled" \| undefined>` |

`sampleRate`, `text`, `stats`, and `stopReason` always resolve; they never reject. A cancelled run ends cleanly: `done` resolves `true` and the audio stops at what was delivered.

### `TtsSentenceChunkUpdate`

| Field | Description | Type |
| --- | --- | --- |
| `buffer` | Signed 16-bit mono PCM samples of this frame; `[]` for a metadata-only frame. | `number[]` |
| `sampleRate` | Sample rate of `buffer`, in Hz. | `number` |
| `chunkIndex` | Index of the sentence chunk. | `number` |
| `sentenceChunk` | Text of the sentence chunk. | `string` |
| `isLast` | `true` on the final audio-bearing chunk of the synthesis. | `boolean` |

### `TtsStats`

Every field is optional. The streamed modes run one native job per sentence: they sum `totalTime`, `audioDuration`, `totalSamples`, and `generatedFrames` across sentences, and keep the backend fields from the last sentence that reported them.

| Field | Description | Type |
| --- | --- | --- |
| `audioDuration` | Length of the synthesized audio, in milliseconds. | `number` |
| `totalTime` | Synthesis time, in seconds. | `number` |
| `realTimeFactor` | `totalTime × 1000 / audioDuration`; below 1.0 is faster than real time. | `number` |
| `tokensPerSecond` | Input characters synthesized per second; codec frames per second on Audio8 and MOSS. | `number` |
| `totalSamples` | PCM sample count. | `number` |
| `generatedFrames` | Audio8 and MOSS: codec frames generated. | `number` |
| `backendDevice` | Device chosen at load: `0` CPU, `1` GPU. | `number` |
| `backendId` | Backend family: `0` CPU, `1` Metal, `2` CUDA, `3` Vulkan, `4` OpenCL, `99` other GPU. | `number` |
| `gpuUnsupported` | `1` when a GPU is present but unusable by engine policy, so the run fell back to CPU. | `number` |
| `enhancerBackendDevice` | LavaSR enhancer device: `-1` not loaded, `0` CPU, `1` GPU, `2` Core ML-managed. | `number` |
| `enhancerBackendId` | LavaSR enhancer backend family, same codes as `backendId`. | `number` |
| `denoiserBackendDevice` | LavaSR denoiser device: `-1` not loaded, `0` CPU, `1` GPU, `2` Core ML-managed. | `number` |
| `denoiserBackendId` | LavaSR denoiser backend family, same codes as `backendId`. | `number` |
| `codecSidecarLoaded` | Audio8 on macOS / iOS: `1` while the Core ML codec sidecar is attached, `0` without one or once a failing sidecar was retired. | `number` |
| `codecOnCoreml` | Audio8: `1` when this synthesis ran its codec on the Core ML sidecar, `0` when it ran on the ggml backend `backendId` reports. | `number` |

## Throws

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` fails validation — for example `text` is empty, both or neither of `text` and `audio` are set, `audio` comes without `sampleRate`, or `description` is combined with a voice-template field. Thrown synchronously. |
| `TextToSpeechStreamFailedError` | `sentenceStream: true` is paired with `stream: false`. Thrown synchronously. |
| `QvacErrorBase` | Synthesis fails on the server. Surfaces when iterating the streams, and rejects `done` (and `buffer` when `stream: false`). |

## Examples

```ts
// Collected: the complete audio in one array.
const result = textToSpeech({ modelId, text: "Hello from QVAC.", stream: false });
const pcm = await result.buffer;
const sampleRate = await result.sampleRate;

// Streamed: play each chunk as it arrives.
const streamed = textToSpeech({ modelId, text: longArticle });
for await (const chunk of streamed.chunkStream) {
  player.write(chunk);
}
console.log(await streamed.stopReason, (await streamed.stats)?.realTimeFactor);

// Sentence-streamed: audio with the sentence it belongs to.
const sentences = textToSpeech({ modelId, text: longArticle, sentenceStream: true });
for await (const update of sentences.chunkUpdates!) {
  console.log(update.chunkIndex, update.sentenceChunk, update.buffer.length);
}

// Parler conditioning per request.
const parler = textToSpeech({
  modelId: parlerId,
  text: "Welcome to Parler text-to-speech.",
  stream: false,
  emotion: "happy",
  pace: "moderate",
});

// Cancel a run.
const run = textToSpeech({ modelId, text: longArticle, stream: false });
await cancel({ requestId: run.requestId });
```
