Translates text with a loaded translation model: an NMT model (`nmtcpp-translation`, alias `nmt`), or an LLM (`llamacpp-completion`, alias `llm`) told the target language. An NMT model also takes a batch of texts. It returns a handle synchronously: with `stream: true`, read the translation from `tokenStream`; with `stream: false`, await `translations` or `text`. See [Translation](/sdk/ai-capabilities/translation).

## Signature

```ts
function translate(params: TranslateClientParams, options?: RPCOptions): {
  tokenStream: AsyncGenerator<string>;
  stats: Promise<TranslationStats | undefined>;
  translations: Promise<string[]>;
  text: Promise<string>;
  requestId: string;
};
```

`modelType` selects the form of `params`:

| Form | `params` | Use it when |
| --- | --- | --- |
| NMT | [`TranslateParamsNmt`](#translateparamsnmt) | The model is an NMT model. Its languages are set at load time. |
| LLM | [`TranslateParamsLlm`](#translateparamsllm) | The model is an LLM. You pass the target language, and optionally the source language and a context hint. |

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model, the text, and the language options. One of the two forms above. | See [forms](#signature) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `TranslateParamsNmt`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelId` | ID of a loaded NMT model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes |
| `modelType` | `"nmtcpp-translation"` or its alias `"nmt"`. | `"nmtcpp-translation" \| "nmt"` | Yes |
| `text` | Text to translate. A string returns one translation; an array returns one translation per string, in order. Strings and the array must not be empty. | `string \| string[]` | Yes |
| `stream` | `true` streams the output through `tokenStream`; `false` resolves `translations` and `text` once. | `boolean` | Yes |

### `TranslateParamsLlm`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a loaded LLM, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes | — |
| `modelType` | `"llamacpp-completion"` or its alias `"llm"`. | `"llamacpp-completion" \| "llm"` | Yes | — |
| `text` | Text to translate. Must not be empty. | `string` | Yes | — |
| `stream` | `true` streams the output through `tokenStream`; `false` resolves `translations` and `text` once. | `boolean` | Yes | — |
| `to` | Target language code, such as `"it"`. | `string` | Yes | — |
| `from` | Source language code. | `string` | No | Detected from `text` |
| `context` | Translation context passed to the LLM as a system hint. | `string` | No | — |

#### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. See [Profiler](/sdk/runtime/profiler). | `PerCallProfiling` | No |

## Returns

A handle, returned synchronously. Which fields carry the output depends on `stream`:

| Field | Description | Type |
| --- | --- | --- |
| `requestId` | ID of this request, available as soon as `translate()` returns. Pass it to [`cancel({ requestId })`](/sdk/reference/api/cancel) to stop it. | `string` |
| `tokenStream` | With `stream: true`: the output as it is produced. For an array `text`, each token is one whole translation, in input order. Empty with `stream: false`. | `AsyncGenerator<string>` |
| `translations` | With `stream: false`: one translation per input, in input order. Resolves with `[]` with `stream: true`. | `Promise<string[]>` |
| `text` | With `stream: false`: `translations` joined with newlines. Resolves with `""` with `stream: true`. | `Promise<string>` |
| `stats` | Resolves with the performance figures when the translation ends, or `undefined` when none were reported or the stream ended early. With `stream: true`, it settles only as `tokenStream` is consumed. | `Promise<`[`TranslationStats`](#translationstats)` \| undefined>` |

### `TranslationStats`

Every field is optional.

| Field | Description | Type |
| --- | --- | --- |
| `totalTime` | Total translation time, in milliseconds. | `number` |
| `totalTokens` | Total tokens produced. | `number` |
| `tokensPerSecond` | Tokens generated per second. | `number` |
| `timeToFirstToken` | Time to the first token, in milliseconds. LLM only. | `number` |
| `encodeTime` | Time spent in the NMT encoder, in milliseconds. NMT only. | `number` |
| `decodeTime` | Time spent in the NMT decoder, in milliseconds. NMT only. | `number` |
| `cacheTokens` | Tokens served from the KV cache. LLM only. | `number` |

## Throws

`translate()` returns synchronously. Failures reject `translations` and `text` (with `stream: false`) or are thrown by `tokenStream` (with `stream: true`):

| Error | When |
| --- | --- |
| `TranslationFailedError` | `from` is omitted for an LLM and the source language cannot be detected from `text`. |
| `QvacErrorBase` | Translation fails; the message carries the details. |

## Examples

```ts
import { loadModel, translate, BERGAMOT_EN_FR, SALAMANDRATA_2B_INST_Q4 } from "@qvac/sdk";

// NMT: languages are set at load time; translate a batch.
const nmtId = await loadModel({
  modelSrc: BERGAMOT_EN_FR,
  modelConfig: { engine: "Bergamot", from: "en", to: "fr" },
});
const translations = await translate({
  modelId: nmtId,
  modelType: "nmtcpp-translation",
  text: ["Hello world", "How are you today?"],
  stream: false,
}).translations;

// LLM: pass the target language; the source language is detected when omitted.
const llmId = await loadModel({ modelSrc: SALAMANDRATA_2B_INST_Q4 });
const italian = await translate({
  modelId: llmId,
  modelType: "llamacpp-completion",
  text: "Hello, how are you today?",
  from: "en",
  to: "it",
  stream: false,
}).text;

// Streaming.
const run = translate({ modelId: llmId, modelType: "llm", text: "Hola, ¿cómo estás?", to: "en", stream: true });
for await (const token of run.tokenStream) process.stdout.write(token);
const stats = await run.stats;
```
