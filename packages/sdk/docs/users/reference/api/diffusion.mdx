Generates images with a model loaded with `modelType: "diffusion"` in the default `modelConfig.mode: "diffusion"`. Without input images it runs text-to-image; `init_image` runs image-to-image or reference editing, and `init_images` runs ordered multi-reference editing on supported models. The call returns immediately with a progress stream and promises for the PNG images and the run statistics. See [Image generation](/sdk/ai-capabilities/image-generation) for model families and their requirements.

## Signature

```ts
function diffusion(params: DiffusionClientParams): DiffusionResult;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model, the prompt, and the generation settings. | [`DiffusionClientParams`](#diffusionclientparams) | Yes |

### `DiffusionClientParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of the loaded diffusion model. | `string` | Yes | — |
| `prompt` | Positive prompt describing the image to generate. | `string` | Yes | — |
| `negative_prompt` | What to avoid in the image. | `string` | No | — |
| `width` | Image width in pixels: a positive multiple of 8. Qwen-Image-2.1 requires a multiple of 32. | `number` | No | — |
| `height` | Image height in pixels: a positive multiple of 8. Qwen-Image-2.1 requires a multiple of 32. | `number` | No | — |
| `steps` | Number of sampling steps, a positive integer. Overridden by `custom_sigmas`. | `number` | No | — |
| `cfg_scale` | Classifier-free guidance scale for SD and Qwen-Image models. Typical range 1–20. | `number` | No | `7` |
| `img_cfg_scale` | Image CFG scale for img2img and inpaint workflows where the image and the prompt take different guidance weights. `-1` reuses `cfg_scale`. | `number` | No | `-1` |
| `guidance` | Distilled guidance for FLUX models. Typical range 1–10. | `number` | No | `3.5` |
| `sampling_method` | Sampling algorithm used by the scheduler. | `"euler" \| "euler_a" \| "heun" \| "dpm2" \| "dpm++2m" \| "dpm++2mv2" \| "dpm++2s_a" \| "lcm" \| "ipndm" \| "ipndm_v" \| "ddim_trailing" \| "tcd" \| "res_multistep" \| "res_2s"` | No | — |
| `scheduler` | Noise schedule to apply when sampling. Overridden by `custom_sigmas`. | `"discrete" \| "karras" \| "exponential" \| "ays" \| "gits" \| "sgm_uniform" \| "simple" \| "lcm" \| "smoothstep" \| "kl_optimal" \| "bong_tangent"` | No | — |
| `custom_sigmas` | Explicit noise schedule, including the terminal zero: at least two non-negative values, strictly decreasing at float precision, ending in `0`. Overrides `scheduler` and `steps`; the effective step count is its length minus one. | `number[]` | No | — |
| `seed` | Random seed, an integer. | `number` | No | Picked at random and returned in `stats.seed` |
| `batch_count` | Number of images to generate in this call, a positive integer. | `number` | No | — |
| `vae_tiling` | Enable VAE tiling for large images on constrained VRAM. Overrides the model configuration for this call. | `boolean` | No | Model configuration |
| `vae_tile_size` | VAE tile size in latent units: a positive integer, or a `"WxH"` string such as `"64x32"`. Each dimension is from 1 to 2147483647. For Qwen-Image-2.1 outputs at 2048×2048 or larger, use `vae_tiling: true` with `vae_tile_size: 64` to bound decode memory. | `number \| string` | No | — |
| `cache_preset` | Name of a cached sampler preset to reuse. | `string` | No | — |
| `init_image` | Source image as PNG or JPEG bytes, for img2img or reference editing. Qwen-Image-2.1 requires `projectionModelSrc` at load for editing, and preserves the reference's alpha. Cannot be combined with `init_images`. | `Uint8Array` | No | — |
| `init_images` | Ordered reference images as PNG or JPEG bytes, at least one, for models with reference editing such as FLUX.2 and Qwen-Image-2.1. Native model detection validates support. Qwen-Image-2.1 requires `projectionModelSrc` at load, and preserves alpha. Cannot be combined with `init_image`. | `Uint8Array[]` | No | — |
| `increase_ref_index` | FLUX.2 fusion only. When `false`, all reference latents share one RoPE index slot and blend through attention, as recommended for FLUX.2-klein. When `true`, each reference gets its own slot; use it only with text encoders that receive per-image vision tokens. | `boolean` | No | Addon default (`false`) |
| `auto_resize_ref_image` | FLUX.2 only. Resize every reference image to the target `width` × `height` before VAE encoding. Disable it only when the buffers already have the exact target dimensions. | `boolean` | No | Addon default (`true`) |
| `lora` | Absolute path to a local LoRA adapter applied to this generation. Whether it persists across later `diffusion()` calls depends on `modelConfig.lora_apply_mode`, set at load. | `string` | No | — |
| `strength` | img2img denoising strength for SD and SDXL (SDEdit), from 0 to 1. It does not control reference-editing strength for FLUX.2 or Qwen-Image-2.1, which start the target from noise. | `number` | No | — |
| `upscale` | Post-generation ESRGAN upscale. Requires a model loaded with `modelConfig.upscaler.model_src`. `true`, `{}`, and `{ repeats: 1 }` run one pass at the upscaler's native scale factor; `{ repeats: N }` runs N passes, each multiplying the dimensions by that factor; `false` does nothing. With `batch_count` above 1, every image is upscaled independently. ESRGAN accepts RGB only, so Qwen-Image-2.1 RGBA output rejects it. | `boolean \| { repeats?: number }` | No | — |

## Returns

An object, returned synchronously. Generation starts when `diffusion()` is called; consuming `progressStream` is optional.

| Field | Description | Type |
| --- | --- | --- |
| `progressStream` | Yields a progress tick each time the worker reports one. Ends when the generation finishes; throws the run's error when it fails. | `AsyncGenerator<`[`DiffusionProgressTick`](#diffusionprogresstick)`>` |
| `outputs` | Resolves with the generated images, one PNG per buffer, when the generation completes. | `Promise<Uint8Array[]>` |
| `stats` | Resolves with the run statistics when the generation completes, or `undefined` when the engine reports none. | `Promise<`[`DiffusionStats`](#diffusionstats)` \| undefined>` |

#### `DiffusionProgressTick`

| Field | Description | Type |
| --- | --- | --- |
| `step` | Current sampling step. | `number` |
| `totalSteps` | Total sampling steps of the run. | `number` |
| `elapsedMs` | Time elapsed in the run, in milliseconds. | `number` |

#### `DiffusionStats`

Every field is optional.

| Field | Description | Type |
| --- | --- | --- |
| `modelLoadMs` | Time spent loading the diffusion model, in milliseconds. | `number` |
| `generationMs` | Wall-clock time spent generating the output, in milliseconds. | `number` |
| `conditionerMs` | Time spent conditioning the prompt before denoising, in milliseconds. | `number` |
| `denoiseMs` | Time spent in the denoising loop, in milliseconds. | `number` |
| `vaeMs` | Time spent decoding latents with the VAE, in milliseconds. | `number` |
| `postProcessMs` | Time spent encoding, upscaling, muxing, and emitting outputs, in milliseconds. | `number` |
| `stepsPerSecond` | Denoising throughput, in sampling steps per second. | `number` |
| `totalGenerationMs` | Total generation time across all images in the batch, in milliseconds. | `number` |
| `totalWallMs` | Total wall-clock time including model load and sampling, in milliseconds. | `number` |
| `totalSteps` | Total number of sampling steps executed. | `number` |
| `totalGenerations` | Total number of generation passes executed. | `number` |
| `totalImages` | Total number of images produced. | `number` |
| `totalPixels` | Total number of pixels generated across all images. | `number` |
| `width` | Width of each generated image, in pixels. | `number` |
| `height` | Height of each generated image, in pixels. | `number` |
| `seed` | Seed that produced these outputs; randomized when the call passed none. | `number` |

## Throws

`diffusion()` does not throw. Errors reject `outputs` and `stats`, and are thrown by `progressStream`.

| Error | When |
| --- | --- |
| `InferenceCancelledError` | The active generation is cancelled, for example with `cancel({ modelId, kind: "diffusion" })`. See [Cancellation](/sdk/runtime/cancellation). |
| `RequestRejectedByPolicyError` | Another image or video generation already owns the model. |

## Examples

```ts
import { diffusion, loadModel, SD_V2_1_1B_Q8_0 } from "@qvac/sdk";
import fs from "fs";

const modelId = await loadModel({
  modelSrc: SD_V2_1_1B_Q8_0,
  modelType: "sdcpp-generation",
  modelConfig: { prediction: "v" },
});

// Text-to-image, with progress.
const { progressStream, outputs, stats } = diffusion({
  modelId,
  prompt: "a photo of a cat sitting on a windowsill",
  width: 512,
  height: 512,
  steps: 20,
  seed: 42,
});
for await (const { step, totalSteps } of progressStream) {
  console.log(`step ${step}/${totalSteps}`);
}
const [image] = await outputs;
fs.writeFileSync("cat.png", image!);
console.log(await stats);

// Image-to-image (SD SDEdit): keep half of the source.
const edit = diffusion({
  modelId,
  prompt: "oil painting style, vibrant colors",
  init_image: new Uint8Array(fs.readFileSync("input.png")),
  strength: 0.5,
});
const [edited] = await edit.outputs;
fs.writeFileSync("edited.png", edited!);
```
