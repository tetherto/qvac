Deletes cached files from disk. Three forms delete the KV caches that [`completion()`](/sdk/reference/api/completion) writes with its `kvCache` parameter: all of them, the SDK-managed auto caches, or one cache key. The fourth form deletes a registry model's cached download, including a partial download kept for resume. See [KV cache](/sdk/ai-capabilities/text-generation#kv-cache) and [Download lifecycle](/sdk/models/download-lifecycle).

## Signature

```ts
function deleteCache(params: { all: true } | { auto: true } | { kvCacheKey: string; modelId?: string } | { modelSrc: string }): Promise<{ success: boolean }>;
```

The shape of `params` selects what is deleted:

| Form | `params` | Use it when |
| --- | --- | --- |
| All KV caches | `{ all: true }` | Every KV cache of every key and model must go, such as on an app reset. |
| Auto caches | `{ auto: true }` | You want to reclaim the SDK-managed caches created with `kvCache: true` now, instead of waiting for their retention limits. Caches a request is still using, and caches under a caller-managed key, are kept. |
| One cache key | [`{ kvCacheKey, modelId? }`](#kv-cache-key) | You manage a cache key yourself, such as one per user session, and want to delete it. |
| Model download | [`{ modelSrc }`](#model-download) | You want to delete a registry model's cached files, or a download you paused. |

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | What to delete. One of the four forms above. | See [forms](#signature) | Yes |

### KV cache key

KV cache files are stored as `{kvCacheKey}/{modelId}/` under the KV cache directory.

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `kvCacheKey` | The cache key passed as `kvCache` to `completion()`. Deletes the key's whole directory, for every model. Deleting a key that does not exist succeeds. | `string` | Yes |
| `modelId` | Delete only this model's caches under the key. | `string` | No |

<Callout type="warn">
Do not delete a cache key that a running request is using. Only the `{ auto: true }` form skips caches in use.
</Callout>

### Model download

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelSrc` | `registry://` source of the model whose cached download to delete, in the form `registry://<source>/<path>`. A registry model constant carries it as `src`. Also clears the blocks a cancelled or failed download kept for resume. | `string` | Yes |

The delete fails while the model, or another model sharing its files, is downloading: cancel the download first. It also fails while the model is loaded: unload it with [`unloadModel({ modelId, clearStorage: true })`](/sdk/reference/api/unloadModel) instead.

## Returns

A promise that resolves with `{ success: boolean }` once the files are deleted. A delete the worker reports as failed throws instead.

## Throws

| Error | When |
| --- | --- |
| `InvalidDeleteCacheParamsError` | `params` matches none of the four forms, such as `{ all: false }`. |
| `DeleteCacheFailedError` | The worker reports a failed delete: `modelSrc` is not a `registry://` URL, the model is downloading or loaded, or a file operation fails. The message carries the details. |

## Examples

```ts
import { deleteCache, QWEN3_4B_INST_Q4_K_M } from "@qvac/sdk";

// Delete one caller-managed cache key, for every model.
await deleteCache({ kvCacheKey: "user-alice-session" });

// Delete only one model's caches under a key.
await deleteCache({ kvCacheKey: "user-bob-session", modelId });

// Reclaim SDK-managed auto caches that no request is using.
await deleteCache({ auto: true });

// Delete every KV cache.
await deleteCache({ all: true });

// Delete a registry model's cached download.
await deleteCache({ modelSrc: QWEN3_4B_INST_Q4_K_M.src });
```
