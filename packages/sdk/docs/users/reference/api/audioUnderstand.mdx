Runs the ACE-Step generation pipeline backwards over a recording: the engine encodes the PCM, recovers its FSQ semantic codes, and the LM reports a caption and the clip's musical metadata. It returns a run object synchronously, shaped like the one [`audioGen()`](/sdk/reference/api/audioGen) returns but with `description` in place of `audio`. The recovered codes are a valid `audioCodes` input to `audioGen()`. MiniMax-Music3 does not support it. See [Music generation](/sdk/ai-capabilities/music-generation#understand-a-recording).

## Signature

```ts
function audioUnderstand(params: AudioUnderstandClientParams): AudioUnderstandResult;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The recording and the LM sampling settings. Unknown keys are rejected. | [`AudioUnderstandClientParams`](#audiounderstandclientparams) | Yes |

### `AudioUnderstandClientParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a loaded ACE-Step model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes | — |
| `sourceAudio` | The recording to analyse: a file path read on the server, or raw interleaved stereo 48 kHz Float32 LE PCM with every sample in `[-1, 1]`. Capped at 600 s. Path decoding is as for [`audioGen()`](/sdk/reference/api/audioGen#audiogenclientparams). | `string \| Uint8Array` | Yes | — |
| `seed` | RNG seed for the LM decode, an integer; omit for a random one. | `number` | No | Random |
| `vocalLanguage` | Language hint, such as `"es"`, forced into the result instead of the LM's guess. | `string` | No | — |
| `lmTemperature` | LM sampling temperature, non-negative. | `number` | No | `0.85` |
| `lmTopP` | LM nucleus-sampling probability, from 0 to 1. | `number` | No | `0.9` |
| `lmTopK` | LM top-k cutoff, a non-negative integer. `0` disables top-k filtering. | `number` | No | — |

## Returns

An `AudioUnderstandResult`, returned synchronously. The request is sent at once.

| Field | Description | Type |
| --- | --- | --- |
| `requestId` | ID of this run, available synchronously. Pass it to [`cancel({ requestId })`](/sdk/reference/api/cancel). | `string` |
| `progressStream` | Stage and step updates while the run executes. Ends when the run ends; throws the run's error when it fails. | `AsyncGenerator<` [`AudioGenProgress`](/sdk/reference/api/audioGen#audiogenprogress) `>` |
| `description` | The LM's description of the clip. | `Promise<` [`AudioGenUnderstandResult`](#audiogenunderstandresult) `>` |
| `stats` | Run statistics; `understand` repeats the description. | `Promise<` [`AudioGenStats`](/sdk/reference/api/audioGen#audiogenstats) ` \| undefined>` |
| `diagnostics` | Backend selection detail for the completed run. | `Promise<` [`InferenceBackendDiagnostics`](/sdk/reference/api/transcribeStream#inferencebackenddiagnostics) ` \| undefined>` |

A cancelled run rejects `description`, `stats`, and `diagnostics` with `InferenceCancelledError`.

### `AudioGenUnderstandResult`

| Field | Description | Type |
| --- | --- | --- |
| `caption` | The LM's description of the clip. | `string` |
| `bpm` | Beats per minute the LM read off the recording. | `number` |
| `duration` | The LM's estimate, in seconds. The recovered codes fix the true length. | `number` |
| `keyscale` | Key and scale the LM read off the recording. | `string` |
| `timesignature` | Time signature the LM read off the recording. | `string` |
| `vocalLanguage` | Vocal language the LM read off the recording, or the `vocalLanguage` you forced. | `string` |
| `audioCodes` | FSQ semantic codes recovered from the clip, reusable as a generation's `audioCodes` input. | `number[]` |
| `seed` | The seed the LM decode used: the engine-drawn one when none was passed. | `number` |

## Throws

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` fails validation, for example an unknown key or a missing `sourceAudio`. Thrown synchronously. |
| `InferenceCancelledError` | The run was cancelled. Rejects `description`, `stats`, and `diagnostics`. |
| `InvalidResponseError` | The stream ends without a terminal frame, or without a description. |
| `QvacErrorBase` | The run fails on the server. Rejects `description`, `stats`, `diagnostics`, and `progressStream`. |

## Examples

```ts
const run = audioUnderstand({
  modelId,
  sourceAudio: "/path/to/song.wav",
  vocalLanguage: "en",
  seed: 11,
});

for await (const progress of run.progressStream) {
  console.log(`${progress.stage}: ${progress.step}/${progress.total}`);
}
const { caption, bpm, keyscale, timesignature, audioCodes } = await run.description;

// Re-synthesize the same piece without re-running the LM.
const remake = audioGen({ modelId, caption, audioCodes });
```
