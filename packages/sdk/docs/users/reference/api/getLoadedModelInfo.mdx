Returns what the worker knows about a loaded model: its model type, the operations its plugin handles, where it was loaded from, and the outcome of the [fit check](/sdk/models/assess-model-fit#load-time-check) that ran before the load. For a catalog model's cache state, use [`getModelInfo()`](/sdk/reference/api/getModelInfo) instead.

## Signature

```ts
function getLoadedModelInfo(params: GetLoadedModelInfoParams, rpcOptions?: RPCOptions): Promise<LoadedModelInfo>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model to inspect. | [`GetLoadedModelInfoParams`](#getloadedmodelinfoparams) | Yes |
| `rpcOptions` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `GetLoadedModelInfoParams`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelId` | ID of the loaded model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes |

### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. | [`PerCallProfiling`](#percallprofiling) | No |

#### `PerCallProfiling`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `enabled` | Profile this call only. When omitted, the global profiler configuration applies. | `boolean` | No |
| `includeServerBreakdown` | Include the server-side timing breakdown in the profiling payload. | `boolean` | No |
| `includeResourceGauges` | Attach one local CPU, memory, and GPU resource sample to the operation event. | `boolean` | No |
| `mode` | Detail level: `"summary"` keeps aggregates only, `"verbose"` keeps recent events. | `"summary" \| "verbose"` | No |

## Returns

A promise that resolves with a `LoadedModelInfo`:

| Field | Description | Type |
| --- | --- | --- |
| `modelId` | ID of the loaded model. | `string` |
| `modelType` | The model type the model was loaded with. | `string` |
| `handlers` | Names of the operations the model's plugin handles. Empty when no plugin is registered for the model type. | `string[]` |
| `displayName` | The plugin's display name. Absent when no plugin is registered. | `string \| undefined` |
| `addonPackage` | The plugin's addon package. Absent when no plugin is registered. | `string \| undefined` |
| `loadedAt` | When the model was loaded. | `Date` |
| `name` | The model's name, when known. | `string \| undefined` |
| `path` | Path of the model file on disk, when known. | `string \| undefined` |
| `toolDialect` | The tool-call dialect the completion parser reads for this model, so a prior tool call can be replayed in the model's own dialect. Present only for models that run completions. | `"hermes" \| "pythonic" \| "json" \| "harmony" \| "qwen35" \| "gemma4" \| "dsml" \| undefined` |
| `fitProbe` | Outcome of the engine fitter's check that ran before this load, in the shape of an [`assessModelFit()` result](/sdk/reference/api/assessModelFit#returns) with one model. Absent when the load set `modelFitPolicy: "off"`. | [`ModelFitProbe`](#modelfitprobe)` \| undefined` |

#### `ModelFitProbe`

| Field | Description | Type |
| --- | --- | --- |
| `verdict` | The verdict for this load against free memory. | `"fits" \| "does-not-fit" \| "unknown"` |
| `pools` | The memory pools the verdict was judged on, with what the load takes from each. | [`ModelFitPool`](/sdk/reference/api/assessModelFit#modelfitpool)`[]` |
| `models` | The load's own entry: the engine addon's fit result. | [`ModelFitModelResult`](/sdk/reference/api/assessModelFit#modelfitmodelresult)`[]` |

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `MODEL_NOT_FOUND` | No loaded model has this `modelId`. |
| `InvalidResponseError` | The worker answers with an unexpected response type. |

## Examples

```ts
import { getLoadedModelInfo, loadModel, LLAMA_3_2_1B_INST_Q4_0 } from "@qvac/sdk";

const modelId = await loadModel({ modelSrc: LLAMA_3_2_1B_INST_Q4_0 });
const info = await getLoadedModelInfo({ modelId });

console.log(info.modelType, info.handlers);
console.log(info.toolDialect);
console.log(info.fitProbe?.verdict); // "fits" | "does-not-fit" | "unknown"
```
