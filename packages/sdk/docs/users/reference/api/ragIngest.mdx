Runs the full ingestion pipeline — chunk, embed with a loaded embedding model, save — into a built-in RAG workspace, and resolves with one result per saved item. It opens the workspace, creating it if it does not exist, and leaves it open until [`ragCloseWorkspace()`](/sdk/reference/api/ragCloseWorkspace). To embed or chunk on your own terms, use [`ragChunk()`](/sdk/reference/api/ragChunk), [`embed()`](/sdk/reference/api/embed), and [`ragSaveEmbeddings()`](/sdk/reference/api/ragSaveEmbeddings) instead. See [RAG](/sdk/ai-capabilities/rag).

<Callout type="warn">
**Prototype only:** the built-in RAG vector store is not production grade. For production, use an external vector DB, as shown in the [RAG guide](/sdk/ai-capabilities/rag).
</Callout>

A new workspace stores its vectors in HyperDB, or in a TurboVec index when [`ragTurbovec`](/sdk/configuration#options) is set in the configuration. The choice is fixed for the life of the workspace.

Starting `ragIngest()`, `ragSaveEmbeddings()`, or `ragReindex()` on a workspace cancels the one of these already running on that workspace.

## Signature

```ts
function ragIngest(params: RagIngestParams, options?: RPCOptions): Promise<{ processed: RagSaveEmbeddingsResult[]; droppedIndices: number[] }> & { requestId: string };
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The documents, the model, and the target workspace. | [`RagIngestParams`](#ragingestparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `RagIngestParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of the loaded embedding model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. While the workspace stays open, every `ragIngest()` and `ragSearch()` on it must use the model it was first used with. | `string` | Yes | — |
| `documents` | Text to ingest: one document, or an array of documents. | `string \| string[]` | Yes | — |
| `workspace` | Name of the workspace to save into. Must name a single child path: no `..`, null bytes, `%00`, or `%2e`. | `string` | No | `"default"` |
| `chunk` | Split documents into chunks before embedding. When `false`, each string is embedded and saved whole, and empty or whitespace-only strings are skipped. | `boolean` | No | `true` |
| `chunkOpts` | How to split the text when `chunk` is `true`. | [`ChunkOpts`](#chunkopts) | No | See [`ChunkOpts`](#chunkopts) |
| `progressInterval` | Number of documents prepared between two `saving:preparing` progress updates. Must be positive. | `number` | No | `10` |
| `onProgress` | Called with each progress update. When set, the call streams its progress instead of resolving in one response. | `(stage: ` [`RagIngestStage`](#ragingeststage)`, current: number, total: number) => void` | No | — |

#### `ChunkOpts`

| Field | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `chunkSize` | Maximum size of a chunk, counted in the units `splitStrategy` produces. | `number` | No | `256` |
| `chunkOverlap` | Units repeated between consecutive chunks. Must be less than `chunkSize`. | `number` | No | `50` |
| `chunkStrategy` | How units are grouped: `"paragraph"` fits as many whole paragraphs (separated by `\n\n` or by the end of an array element) into a chunk as it can, and splits a paragraph only when it alone exceeds `chunkSize`; `"character"` fits as many units as it can, ignoring paragraphs. | `"character" \| "paragraph"` | No | `"paragraph"` |
| `splitStrategy` | The unit text is split into before grouping. | `"character" \| "word" \| "token" \| "sentence" \| "line"` | No | `"token"` |

#### `RagIngestStage`

The `stage` passed to `onProgress`, in pipeline order. `current` and `total` count the items of that stage.

| Stage | What runs |
| --- | --- |
| `"chunking"` | Documents are split into chunks. Skipped when `chunk` is `false`. |
| `"embedding"` | Chunks are embedded with the model. |
| `"saving:deduplicating"` | Chunks whose content is already stored are set aside. |
| `"saving:preparing"` | Chunks are prepared for writing. Reported every `progressInterval` chunks. |
| `"saving:writing"` | Chunks are written to the workspace, batch by batch. |

| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. | [`PerCallProfiling`](#percallprofiling) | No |

#### `PerCallProfiling`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `enabled` | Profile this call only. When omitted, the global profiler configuration applies. | `boolean` | No |
| `includeServerBreakdown` | Include the server-side timing breakdown in the profiling payload. | `boolean` | No |
| `includeResourceGauges` | Attach one local CPU, memory, and GPU resource sample to the operation event. | `boolean` | No |
| `mode` | Detail level: `"summary"` keeps aggregates only, `"verbose"` keeps recent events. | `"summary" \| "verbose"` | No |

## Returns

A promise that resolves with an object:

| Field | Description | Type |
| --- | --- | --- |
| `processed` | One result per chunk (or per document, when `chunk` is `false`). | [`RagSaveEmbeddingsResult`](#ragsaveembeddingsresult)`[]` |
| `droppedIndices` | Indices into `documents` of the strings skipped because they were empty or whitespace-only. Always empty when `chunk` is `true`. | `number[]` |

The promise also carries `requestId`, available synchronously, so the ingest can be cancelled with [`cancel({ requestId })`](/sdk/reference/api/cancel) before it resolves. See [Cancellation](/sdk/runtime/cancellation).

### `RagSaveEmbeddingsResult`

| Field | Description | Type |
| --- | --- | --- |
| `status` | `"fulfilled"` when the item was saved, `"rejected"` when it was not. | `"fulfilled" \| "rejected"` |
| `id` | ID of the saved item. For an item rejected as a duplicate, the ID of the item that already holds the same content. | `string \| undefined` |
| `error` | Why the item was rejected, such as `"Document already exists in database"`. | `string \| undefined` |

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` fails validation, for example a missing `modelId` or an invalid `workspace` name. |
| `RAG_WORKSPACE_MODEL_MISMATCH` | The workspace is open with a different embedding model than `modelId`. |
| `RAG_SAVE_FAILED` | The worker reports that the ingest failed. |
| `StreamEndedError` | The progress stream ends without a final result (only with `onProgress`). |

## Examples

```ts
const modelId = await loadModel({ modelSrc: GTE_LARGE_FP16 });

// Save each string as one document.
const { processed } = await ragIngest({
  modelId,
  workspace: "notes",
  documents: ["Titan has methane lakes.", "Bees communicate by dancing."],
  chunk: false,
});
console.log(processed.filter((r) => r.status === "fulfilled").length);

// Chunk long articles, with progress.
await ragIngest({
  modelId,
  workspace: "articles",
  documents: articles,
  chunkOpts: { chunkSize: 50, chunkOverlap: 10, splitStrategy: "token" },
  onProgress: (stage, current, total) => console.log(`${stage} ${current}/${total}`),
});

// Cancel an ingest before it resolves.
const ingest = ragIngest({ modelId, workspace: "articles", documents: articles });
await cancel({ requestId: ingest.requestId });
```
