Deletes the documents with the given IDs, and their vectors, from an existing built-in RAG workspace. It resolves with no value. The IDs are the ones [`ragIngest()`](/sdk/reference/api/ragIngest) and [`ragSaveEmbeddings()`](/sdk/reference/api/ragSaveEmbeddings) report and [`ragSearch()`](/sdk/reference/api/ragSearch) returns. See [RAG](/sdk/ai-capabilities/rag).

<Callout type="warn">
**Prototype only:** the built-in RAG vector store is not production grade. For production, use an external vector DB, as shown in the [RAG guide](/sdk/ai-capabilities/rag).
</Callout>

## Signature

```ts
function ragDeleteEmbeddings(params: RagDeleteEmbeddingsParams, options?: RPCOptions): Promise<void>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The IDs to delete and their workspace. | [`RagDeleteEmbeddingsParams`](#ragdeleteembeddingsparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `RagDeleteEmbeddingsParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `ids` | IDs of the documents to delete. At least one. | `string[]` | Yes | — |
| `workspace` | Name of the workspace. It must already exist. Must name a single child path: no `..`, null bytes, `%00`, or `%2e`. | `string` | No | `"default"` |
| `modelId` | Not used by this operation. | `string` | No | — |

## Returns

A promise that resolves with no value once the documents are deleted.

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` fails validation, for example an empty `ids` array. |
| `RAG_DELETE_FAILED` | The workspace does not exist, or the deletion fails. |

## Examples

```ts
const { processed } = await ragIngest({ modelId, workspace: "notes", documents: notes });

const ids = processed.flatMap((r) => (r.status === "fulfilled" && r.id ? [r.id] : []));
await ragDeleteEmbeddings({ workspace: "notes", ids: ids.slice(0, 1) });
```
