Decodes a whole neural-signal recording — a `.bin` file path or a raw neural buffer — into text with a loaded brain–computer interface (BCI) model. It resolves with the joined transcript, or with the transcript segments when `metadata` is `true`. To feed the signal as it arrives, use [`bciTranscribeStream()`](/sdk/reference/api/bciTranscribeStream). See [BCI](/sdk/ai-capabilities/bci) for the signal format.

## Signature

```ts
function bciTranscribe(params: BciTranscribeClientParams & { metadata: true }, options?: RPCOptions): Promise<TranscribeSegment[]> & { requestId: string };
function bciTranscribe(params: BciTranscribeClientParams, options?: RPCOptions): Promise<string> & { requestId: string };
```

| Form | `params` | Resolves with |
| --- | --- | --- |
| Text | [`BciTranscribeClientParams`](#bcitranscribeclientparams) | The transcript as one `string`. |
| Segments | [`BciTranscribeClientParams`](#bcitranscribeclientparams) with `metadata: true` | An array of [`TranscribeSegment`](/sdk/reference/api/transcribe#transcribesegment). |

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model and the signal. | [`BciTranscribeClientParams`](#bcitranscribeclientparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](/sdk/reference/api/transcribe#rpcoptions) | No |

### `BciTranscribeClientParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a loaded BCI model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes | — |
| `neuralData` | The neural signal. A `string` is the path of a `.bin` recording; a `Uint8Array` is raw neural bytes, sent base64-encoded. The bytes start with an 8-byte header — `timesteps` and `channels`, each a little-endian `uint32` — followed by row-major `float32` features. Each timestep is a 20 ms bin. | `string \| Uint8Array` | Yes | — |
| `metadata` | Resolve with segment objects (`{ text, startMs, endMs, append, id }`) instead of joined text. | `boolean` | No | `false` |

## Returns

A promise that resolves when the engine sends its terminal frame: the concatenated text, or the segments in arrival order with `metadata: true`. Batch segment timings are absolute. The promise also carries `requestId`, available synchronously, so the call can be cancelled with [`cancel({ requestId })`](/sdk/reference/api/cancel).

The terminal frame also carries run `stats` and backend `diagnostics`, but this function does not expose them.

## Throws

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` fails validation. Thrown synchronously, before any request is sent. |
| `QvacErrorBase` | Transcription fails on the server; the message carries the details. |

## Examples

```ts
const modelId = await loadModel({
  modelSrc: BCI_WINDOWED,
  modelConfig: {
    whisperConfig: { language: "en", temperature: 0.0 },
    // Match the recording session of the input signal.
    bciConfig: { day_idx: 1 },
  },
});

// Joined text from a file.
const text = await bciTranscribe({ modelId, neuralData: "/path/to/signal.bin" });

// Segments from an in-memory buffer.
const segments = await bciTranscribe({
  modelId,
  neuralData: new Uint8Array(readFileSync("/path/to/signal.bin")),
  metadata: true,
});
for (const segment of segments) {
  console.log(`[${segment.startMs}–${segment.endMs} ms] ${segment.text}`);
}
```
