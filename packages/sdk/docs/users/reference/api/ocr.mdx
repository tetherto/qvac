Runs optical character recognition on an image and returns the recognized text blocks, each with an optional bounding box and confidence. The call returns immediately with an object of promises and a stream; read `blocks` for the whole result, or pass `stream: true` and iterate `blockStream`. See [OCR](/sdk/ai-capabilities/ocr) for supported models.

## Signature

```ts
function ocr(params: OCRClientParams): { blockStream: AsyncGenerator<OCRTextBlock[]>; blocks: Promise<OCRTextBlock[]>; stats: Promise<OCRStats | undefined> };
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model, the image, and how to deliver the result. | [`OCRClientParams`](#ocrclientparams) | Yes |

### `OCRClientParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a model loaded with `modelType: "ocr"` (`"ggml-ocr"`). | `string` | Yes | — |
| `image` | The image to read: a file path on the machine that runs the worker, or the encoded image bytes. JPEG, PNG, and BMP are supported. | `string \| Buffer` | Yes | — |
| `options` | Options for this run. | [`OCROptions`](#ocroptions) | No | — |
| `stream` | Deliver blocks through `blockStream` instead of `blocks`. | `boolean` | No | `false` |

#### `OCROptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `paragraph` | Merge nearby text boxes into one block. | `boolean` | No |

## Returns

An object, returned synchronously:

| Field | Description | Type |
| --- | --- | --- |
| `blocks` | Without `stream`: resolves with every recognized block once the run completes. With `stream: true`: resolves immediately with `[]`. | `Promise<`[`OCRTextBlock`](#ocrtextblock)`[]>` |
| `blockStream` | With `stream: true`: yields each batch of blocks the worker sends, and ends when the run completes. Without `stream`: yields nothing. | `AsyncGenerator<`[`OCRTextBlock`](#ocrtextblock)`[]>` |
| `stats` | Resolves with the run's timings when it completes, or `undefined` when the engine reports none. | `Promise<`[`OCRStats`](#ocrstats)` \| undefined>` |

Without `stream`, the request starts when `ocr()` is called. With `stream: true`, it starts when you begin iterating `blockStream`, and `stats` resolves only after the stream is consumed to the end. The worker sends all blocks in one batch once recognition finishes, so `blockStream` typically yields once.

`stats` never rejects. When the run fails, the error rejects `blocks` (or is thrown by `blockStream`), and `stats` stays pending.

#### `OCRTextBlock`

| Field | Description | Type |
| --- | --- | --- |
| `text` | The recognized text. | `string` |
| `bbox` | Bounding box of the text, as `[minX, minY, maxX, maxY]`. Absent when the engine reports no box. | `[number, number, number, number]` |
| `confidence` | Recognition confidence, from 0 to 1. Absent when the engine reports none. | `number` |

#### `OCRStats`

Every field is optional.

| Field | Description | Type |
| --- | --- | --- |
| `detectionTime` | Duration of the text-detection step, in seconds. | `number` |
| `recognitionTime` | Duration of the text-recognition step, in seconds. | `number` |
| `totalTime` | Total wall-clock time of the run, in seconds. | `number` |

## Throws

| Error | When |
| --- | --- |
| `ImageFileNotFoundError` | `image` is a file path the worker cannot access. |

## Examples

```ts
import { loadModel, ocr, OCR_LATIN } from "@qvac/sdk";
import fs from "fs";

const modelId = await loadModel({
  modelSrc: OCR_LATIN,
  modelConfig: { langList: ["en"] },
});

// Every block at once, from a file path.
const { blocks, stats } = ocr({ modelId, image: "/path/to/receipt.png" });
for (const block of await blocks) {
  console.log(block.text, block.bbox, block.confidence);
}
console.log(await stats);

// Streaming, from in-memory bytes.
const imageBuffer = fs.readFileSync("/path/to/scan.jpg");
const { blockStream } = ocr({ modelId, image: imageBuffer, stream: true });
for await (const batch of blockStream) {
  for (const block of batch) console.log(block.text);
}
```
