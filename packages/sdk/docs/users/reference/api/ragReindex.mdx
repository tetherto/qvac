Rebuilds the search index of an existing built-in RAG workspace and resolves with whether it did. In a HyperDB workspace it rebalances the centroids with k-means clustering, which needs a minimum number of documents (16 by default); in a TurboVec workspace it rebuilds the index from the stored documents. Run it after large ingests. See [RAG](/sdk/ai-capabilities/rag).

<Callout type="warn">
**Prototype only:** the built-in RAG vector store is not production grade. For production, use an external vector DB, as shown in the [RAG guide](/sdk/ai-capabilities/rag).
</Callout>

Starting `ragIngest()`, `ragSaveEmbeddings()`, or `ragReindex()` on a workspace cancels the one of these already running on that workspace.

## Signature

```ts
function ragReindex(params: RagReindexParams, options?: RPCOptions): Promise<RagReindexResult> & { requestId: string };
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The workspace to reindex. Pass `{}` for the default workspace. | [`RagReindexParams`](#ragreindexparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `RagReindexParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `workspace` | Name of the workspace. It must already exist. Must name a single child path: no `..`, null bytes, `%00`, or `%2e`. | `string` | No | `"default"` |
| `modelId` | Not used by this operation. | `string` | No | — |
| `onProgress` | Called with each progress update. When set, the call streams its progress instead of resolving in one response. | `(stage: ` [`RagReindexStage`](#ragreindexstage)`, current: number, total: number) => void` | No | — |

#### `RagReindexStage`

The `stage` passed to `onProgress`, in order. A TurboVec workspace reports only `"collecting"` and `"updating"`.

| Stage | What runs |
| --- | --- |
| `"collecting"` | The stored vectors are collected. |
| `"clustering"` | New centroids are computed. |
| `"reassigning"` | Each document is assigned to its nearest new centroid. `current` and `total` count documents. |
| `"updating"` | The index is written back. |

### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. | [`PerCallProfiling`](#percallprofiling) | No |

#### `PerCallProfiling`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `enabled` | Profile this call only. When omitted, the global profiler configuration applies. | `boolean` | No |
| `includeServerBreakdown` | Include the server-side timing breakdown in the profiling payload. | `boolean` | No |
| `includeResourceGauges` | Attach one local CPU, memory, and GPU resource sample to the operation event. | `boolean` | No |
| `mode` | Detail level: `"summary"` keeps aggregates only, `"verbose"` keeps recent events. | `"summary" \| "verbose"` | No |

## Returns

A promise that resolves with a `RagReindexResult`:

| Field | Description | Type |
| --- | --- | --- |
| `reindexed` | `true` when the index was rebuilt. `false` when a HyperDB workspace holds too few documents to cluster. | `boolean` |
| `details` | Extra information. When `reindexed` is `false`: `reason`, `documentCount`, and `centroidCount`. From a TurboVec workspace: `documentCount`, `revision`, and `storage`. | `Record<string, any> \| undefined` |

The promise also carries `requestId`, available synchronously, so the reindex can be cancelled with [`cancel({ requestId })`](/sdk/reference/api/cancel) before it resolves. See [Cancellation](/sdk/runtime/cancellation).

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` fails validation, for example an invalid `workspace` name. |
| `RAG_HYPERDB_FAILED` | The workspace does not exist. |
| `RAG_SAVE_FAILED` | The worker reports that the reindex failed. |
| `StreamEndedError` | The progress stream ends without a final result (only with `onProgress`). |

## Examples

```ts
const result = await ragReindex({
  workspace: "articles",
  onProgress: (stage, current, total) => console.log(`${stage} ${current}/${total}`),
});

if (!result.reindexed) {
  console.log("Not reindexed:", result.details);
}
```
