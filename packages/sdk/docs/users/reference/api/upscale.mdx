Runs ESRGAN upscaling on any PNG or JPEG image, without running diffusion. The model must be loaded with `modelType: "diffusion"` and `modelConfig.mode: "upscale"`. The call returns immediately with promises for the upscaled PNG and the run statistics. To upscale images as part of a generation instead, use the `upscale` option of [`diffusion()`](/sdk/reference/api/diffusion). See [Image generation](/sdk/ai-capabilities/image-generation).

## Signature

```ts
function upscale(params: UpscaleClientParams): UpscaleResult;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model, the image, and the number of passes. | [`UpscaleClientParams`](#upscaleclientparams) | Yes |

### `UpscaleClientParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a model loaded with `modelType: "diffusion"` and `modelConfig.mode: "upscale"`. | `string` | Yes | — |
| `image` | The source image as PNG or JPEG bytes. | `Uint8Array` | Yes | — |
| `repeats` | Number of ESRGAN passes to run in sequence, a positive integer. Each pass multiplies the dimensions by the model's native scale factor; only the final image is emitted. | `number` | No | `1` |

## Returns

An object, returned synchronously. The request starts when `upscale()` is called.

| Field | Description | Type |
| --- | --- | --- |
| `outputs` | Resolves with a single-element array holding the final upscaled PNG, at the source dimensions times `scale^repeats`. | `Promise<Uint8Array[]>` |
| `stats` | Resolves with the run statistics, or `undefined` when the engine reports none. | `Promise<`[`UpscaleStats`](#upscalestats)` \| undefined>` |

#### `UpscaleStats`

Every field is optional.

| Field | Description | Type |
| --- | --- | --- |
| `modelLoadMs` | Wall-clock time spent loading the upscaler model, in milliseconds. | `number` |
| `upscaleMs` | Wall-clock time of the most recent upscale job, in milliseconds. | `number` |
| `totalUpscaleMs` | Cumulative upscale time across all jobs, in milliseconds. | `number` |
| `totalWallMs` | Total wall-clock time including model load and upscaling, in milliseconds. | `number` |
| `totalUpscales` | Cumulative number of upscale calls. | `number` |
| `totalImages` | Cumulative number of images produced. | `number` |
| `totalPixels` | Cumulative number of pixels produced across all images. | `number` |
| `width` | Width of the most recent emitted PNG. | `number` |
| `height` | Height of the most recent emitted PNG. | `number` |
| `repeats` | Number of ESRGAN passes of the most recent upscale job. | `number` |
| `backendDevice` | Compute device the upscaler actually used. On Android, `"gpu"` falls back to `"cpu"`. | `"cpu" \| "gpu"` |

## Throws

`upscale()` does not throw. Errors reject `outputs` and `stats`.

| Error | When |
| --- | --- |
| `ModelOperationNotSupportedError` | The model was not loaded with `modelConfig.mode: "upscale"`. |
| `StreamEndedError` | The RPC stream closes without a terminal `done` chunk. |

## Examples

```ts
import { loadModel, upscale, REALESRGAN_X4PLUS_ANIME_6B } from "@qvac/sdk";
import fs from "fs";

const modelId = await loadModel({
  modelSrc: REALESRGAN_X4PLUS_ANIME_6B,
  modelType: "diffusion",
  modelConfig: { mode: "upscale", upscaler: { tile_size: 128 } },
});

// Two passes of an x4 model: x16 in total.
const { outputs, stats } = upscale({
  modelId,
  image: new Uint8Array(fs.readFileSync("input.png")),
  repeats: 2,
});
const [upscaled] = await outputs;
fs.writeFileSync("upscaled.png", upscaled!);
console.log(await stats);
```
