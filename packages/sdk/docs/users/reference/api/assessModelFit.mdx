Runs each engine's own fitter against a set of candidate loads and reports whether they fit in this device's memory when loaded together. It reads a model from disk when it is already there and otherwise from the registry's weightless description of it, so nothing is downloaded and nothing is loaded. The verdict is advisory: it does not reserve memory or block [`loadModel()`](/sdk/reference/api/loadModel). See [Assess model fit](/sdk/models/assess-model-fit) for how verdicts are computed and which engines have a fitter.

## Signature

```ts
function assessModelFit(input: AssessModelFitInput): Promise<AssessModelFitResult>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `input` | The loads to assess. | [`AssessModelFitInput`](#assessmodelfitinput) | Yes |

### `AssessModelFitInput`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `models` | Models to assess as if loaded at the same time. At least one. | [`ModelFitCandidate`](#modelfitcandidate)`[]` | Yes |

#### `ModelFitCandidate`

One load, described with [`loadModel()`](/sdk/reference/api/loadModel)'s own parameters. The engine's plugin resolves it, so the settings the fitter reads are the ones the load would run with.

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `modelSrc` | The model to assess, as `loadModel()` takes it. Optional for the loads `loadModel()` also takes without one, where every source is a config field. | `string \| ` [`ModelDescriptor`](/sdk/reference/api/loadModel#modeldescriptor) | No |
| `modelType` | Engine that would run the load. Inferred from `modelSrc` when omitted, as `loadModel()` infers it; required only where the source names no engine. | [`ModelType`](/sdk/reference/api/loadModel#modeltype) | No |
| `modelConfig` | The config `loadModel()` would be given, including any companion model sources. | `Record<string, unknown>` | No |
| `transcriptionWorkload` | MOSS-Transcribe fit-only workload. Required for a MOSS verdict; does not configure loading. | [`TranscriptionFitWorkload`](#transcriptionfitworkload) | No |
| `ttsWorkload` | MOSS-TTS/TTSD or MOSS-SoundEffect fit-only workload; never passed to model loading. | [`TtsFitWorkload`](#ttsfitworkload) | No |

#### `TranscriptionFitWorkload`

`prompt` cannot be combined with `hotwords`. Unknown fields are rejected.

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `audioSeconds` | Longest whole recording to project, in seconds. Greater than `0`. | `number` | Yes |
| `prompt` | Replacement MOSS transcription instruction. | `string` | No |
| `hotwords` | MOSS names and domain terms; at most 64 entries of 64 UTF-8 bytes each. | `string[]` | No |
| `maxNewTokens` | MOSS generated-token limit; `0` uses the model default. Integer from `0` to `2147483647`. | `number` | No |

#### `TtsFitWorkload`

One of two shapes. Unknown fields are rejected.

MOSS-TTS/TTSD workload:

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `promptRows` | Complete native prompt rows, including dialogue and references. Positive integer. | `number` | Yes |
| `referenceSamples` | Total mono reference audio samples. Non-negative integer. | `number` | Yes |
| `streaming` | Whether the MOSS workload uses native streaming. | `boolean` | Yes |

MOSS-SoundEffect workload:

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `prompt` | Sound-effect description. Not empty. | `string` | Yes |
| `seconds` | Sound-effect duration in seconds, greater than `0` and up to `30`. | `number` | Yes |

## Returns

A promise that resolves with an `AssessModelFitResult`:

| Field | Description | Type |
| --- | --- | --- |
| `verdict` | The verdict for every model loaded together. See [verdicts](/sdk/models/assess-model-fit#verdict). | [`ModelFitVerdict`](#modelfitverdict) |
| `pools` | The memory pools the verdict was judged on, with what the set takes from each. | [`ModelFitPool`](#modelfitpool)`[]` |
| `models` | One entry per model, in input order. | [`ModelFitModelResult`](#modelfitmodelresult)`[]` |

#### `ModelFitVerdict`

| Value | Meaning |
| --- | --- |
| `"fits"` | The load fits in free memory. |
| `"does-not-fit"` | The fitter projects the load will not fit. |
| `"unknown"` | The load would start but cannot be sized: the engine has no fitter, cannot project this load, has no registry description of a model that is not on disk, or a device reported no free memory. |

#### `ModelFitPool`

| Field | Description | Type |
| --- | --- | --- |
| `id` | `"host"` for the host's memory, the device's `id` for a GPU with its own memory. | `string` |
| `unified` | Whether this is the host pool. | `boolean` |
| `usedBytes` | The sum of every model's rows in this pool. | `number` |
| `freeBytes` | The lowest free figure reported for the pool. | `number \| undefined` |
| `totalBytes` | The lowest total figure reported for the pool. | `number \| undefined` |

#### `ModelFitModelResult`

The engine addon's own fit result for one model.

| Field | Description | Type |
| --- | --- | --- |
| `status` | The engine fitter's verdict for this model alone. | [`ModelFitVerdict`](#modelfitverdict) |
| `devices` | One row per device the load uses, the host last. Empty when unknown. | [`ModelFitDevice`](#modelfitdevice)`[]` |
| `stats` | The resolved load of a llama.cpp verdict: `{ ctxSize, gpuLayers }`, the context size and the number of layers offloaded to the GPU. Empty (`{}`) otherwise. | `{ ctxSize: number; gpuLayers: number } \| {}` |

#### `ModelFitDevice`

| Field | Description | Type |
| --- | --- | --- |
| `id` | The device's PCI bus ID when the backend reports one, its name otherwise. | `string` |
| `name` | The backend's device name, such as `CPU`, `CUDA0` or `MTL0`. | `string` |
| `unified` | Memory the host owns: the CPU, and a GPU that shares the host's memory. | `boolean` |
| `usedBytes` | The memory the load takes on this device. | `number` |
| `freeBytes` | The free memory the device reported. | `number \| undefined` |
| `totalBytes` | The total memory the device reported. | `number \| undefined` |

## Throws

| Error | When |
| --- | --- |
| `ModelTypeRequiredError` | A candidate has no `modelType` and none can be inferred from its `modelSrc`. |
| `ZodError` | `input` fails validation, such as an empty `models` array or a workload with unknown fields. |
| The error `loadModel()` would throw | A load `loadModel()` would refuse: no plugin for the model type, a config the plugin refuses, or a model the fitter cannot read. |
| `InvalidResponseError` | The worker answers with an unexpected response type. |

## Examples

```ts
import { assessModelFit, QWEN3_8B_INST_Q4_K_M } from "@qvac/sdk";

// One model, described as loadModel() would take it.
const result = await assessModelFit({
  models: [
    {
      modelSrc: QWEN3_8B_INST_Q4_K_M,
      modelType: "llamacpp-completion",
      modelConfig: { ctx_size: 8192 },
    },
  ],
});

console.log(result.verdict); // "fits" | "does-not-fit" | "unknown"
for (const pool of result.pools) {
  console.log(pool.id, pool.usedBytes, pool.freeBytes);
}
```
