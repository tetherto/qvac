Deletes a built-in RAG workspace and all its data from disk, and resolves with no value. The workspace must not be open: close it first with [`ragCloseWorkspace()`](/sdk/reference/api/ragCloseWorkspace), or close and delete it in one call with `ragCloseWorkspace({ workspace, deleteOnClose: true })`. [`ragListWorkspaces()`](/sdk/reference/api/ragListWorkspaces) shows which workspaces exist and are open. See [RAG](/sdk/ai-capabilities/rag).

<Callout type="warn">
**Prototype only:** the built-in RAG vector store is not production grade. For production, use an external vector DB, as shown in the [RAG guide](/sdk/ai-capabilities/rag).
</Callout>

## Signature

```ts
function ragDeleteWorkspace(params: RagDeleteWorkspaceParams, options?: RPCOptions): Promise<void>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The workspace to delete. | [`RagDeleteWorkspaceParams`](#ragdeleteworkspaceparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `RagDeleteWorkspaceParams`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `workspace` | Name of the workspace to delete. Cannot be empty. Must name a single child path: no `..`, null bytes, `%00`, or `%2e`. | `string` | Yes |

| `profiling` | Profiler settings for this call; override the global profiler settings. | [`PerCallProfiling`](#percallprofiling) | No |

## Returns

A promise that resolves with no value once the workspace is deleted.

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `workspace` is empty or not a valid name. |
| `RAG_WORKSPACE_IN_USE` | The workspace is open, or opening. |
| `RAG_WORKSPACE_NOT_FOUND` | No workspace has that name. |
| `RAG_DELETE_FAILED` | The worker reports that the deletion failed. |

## Examples

```ts
// Delete every closed workspace.
const workspaces = await ragListWorkspaces();
for (const { name } of workspaces.filter((w) => !w.open)) {
  await ragDeleteWorkspace({ workspace: name });
}
```
