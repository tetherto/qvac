Trains a LoRA adapter on top of a loaded LLM from a dataset, and writes the adapter as a `.gguf` file you load at inference time through `modelConfig.lora`. Called with a run operation, it returns a handle with a progress stream and a result promise. Called with `pause`, `cancel`, or `getState`, it returns a promise with the job's status. A paused job resumes from its checkpoint. See [Fine-tuning](/sdk/ai-capabilities/fine-tuning).

## Signature

```ts
function finetune(params: FinetuneRunParams, rpcOptions?: RPCOptions): FinetuneHandle;
function finetune(params: FinetuneReplyParams, rpcOptions?: RPCOptions): Promise<FinetuneResult>;
```

`FinetuneReplyParams` is [`FinetuneStopParams`](#finetunestopparams) or [`FinetuneGetStateParams`](#finetunegetstateparams). `operation` selects what the call does:

| Form | `params` | `operation` | Does |
| --- | --- | --- | --- |
| Run | [`FinetuneRunParams`](#finetunerunparams) | omitted | Resumes from a pause checkpoint in `checkpointSaveDir` when one exists; otherwise starts a fresh run. |
| Run | [`FinetuneRunParams`](#finetunerunparams) | `"start"` | Starts a fresh run. Fails when a pause checkpoint exists. |
| Run | [`FinetuneRunParams`](#finetunerunparams) | `"resume"` | Resumes from the pause checkpoint. Fails when there is none. |
| Pause | [`FinetuneStopParams`](#finetunestopparams) | `"pause"` | Pauses the running job and saves a pause checkpoint. |
| Cancel | [`FinetuneStopParams`](#finetunestopparams) | `"cancel"` | Cancels the job and removes its pause checkpoints, so the next run starts fresh. |
| Get state | [`FinetuneGetStateParams`](#finetunegetstateparams) | `"getState"` | Reports whether a job is running, paused, or idle. |

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model and the operation. One of the forms above. | See [forms](#signature) | Yes |
| `rpcOptions` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `FinetuneRunParams`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelId` | ID of a loaded LLM, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes |
| `options` | Dataset, output, and training settings. Pass the same object when resuming. | [`FinetuneOptions`](#finetuneoptions) | Yes |
| `operation` | `"start"` or `"resume"`; see the [forms](#signature). | `"start" \| "resume"` | No |

### `FinetuneStopParams`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelId` | ID of the model whose job to stop. | `string` | Yes |
| `operation` | `"pause"` or `"cancel"`. | `"pause" \| "cancel"` | Yes |

### `FinetuneGetStateParams`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelId` | ID of the model to inspect. | `string` | Yes |
| `options` | The job's options. Its `checkpointSaveDir` is inspected for a pause checkpoint. | [`FinetuneOptions`](#finetuneoptions) | Yes |
| `operation` | `"getState"`. | `"getState"` | Yes |

### `FinetuneOptions`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `trainDatasetDir` | Path to the training dataset file: `.jsonl` with a `messages` array per line for SFT, plain text for causal training. Non-empty. | `string` | Yes | — |
| `validation` | How to validate during training. | [`FinetuneValidation`](#finetunevalidation) | Yes | — |
| `outputParametersDir` | Directory, or file path ending in `.gguf`, for the final LoRA adapter. Non-empty. | `string` | Yes | — |
| `numberOfEpochs` | Number of training epochs. Positive integer. | `number` | No | `1` |
| `learningRate` | Initial learning rate. Positive. | `number` | No | `1e-4` |
| `contextLength` | Training sequence length. Positive integer. | `number` | No | `128` |
| `batchSize` | Tokens per batch (backend `n_batch`). Must be at least `microBatchSize` and divisible by it. Positive integer. | `number` | No | `128` |
| `microBatchSize` | Micro-batch size (backend `n_ubatch`). Must not exceed `batchSize`. Positive integer. | `number` | No | `128` |
| `assistantLossOnly` | `true` trains in SFT (chat) mode; `false` trains on raw text (causal). | `boolean` | No | `false` |
| `loraModules` | Comma-separated LoRA target modules, such as `"attn_q,attn_k,attn_v,attn_o"`. | `string` | No | Attention Q, K, V, O |
| `loraRank` | LoRA rank. Positive integer. | `number` | No | `8` |
| `loraAlpha` | LoRA alpha (scaling factor). Positive. | `number` | No | `16` |
| `loraInitStd` | Standard deviation of the LoRA weight initialization. Positive. | `number` | No | `0.02` |
| `loraSeed` | Seed for the LoRA weight initialization. `0` is non-deterministic. Integer. | `number` | No | `42` |
| `checkpointSaveDir` | Directory for checkpoints, including the pause checkpoint. | `string` | No | `"./checkpoints"` |
| `checkpointSaveSteps` | Save a checkpoint every N optimizer steps. `0` saves only on pause. | `number` | No | `0` |
| `chatTemplatePath` | Path to a custom chat template file, for SFT. | `string` | No | — |
| `lrScheduler` | Learning-rate schedule. | `"constant" \| "cosine" \| "linear"` | No | `"cosine"` |
| `lrMin` | Minimum learning rate for the `cosine` and `linear` schedules. | `number` | No | `0` |
| `warmupRatio` | Warmup as a fraction of total steps, from `0` to `1`. Takes effect only with `warmupRatioSet: true`. | `number` | No | `0.1` |
| `warmupRatioSet` | Compute warmup steps as `warmupRatio` × total steps. | `boolean` | No | `false` |
| `warmupSteps` | Explicit warmup steps. Takes effect only with `warmupStepsSet: true`. | `number` | No | `0` |
| `warmupStepsSet` | Use `warmupSteps` instead of the ratio. | `boolean` | No | `false` |
| `weightDecay` | Weight decay. | `number` | No | `0.01` |

#### `FinetuneValidation`

| `type` | Other fields | Validation |
| --- | --- | --- |
| `"none"` | — | None. All data trains; no validation loss is computed. |
| `"split"` | `fraction?: number`, from `0` to `1`, default `0.05` | Holds out that fraction of the training data. |
| `"dataset"` | `path: string`, non-empty | Uses a separate evaluation dataset file. It must differ from `trainDatasetDir`. |

#### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. See [Profiler](/sdk/runtime/profiler). | `PerCallProfiling` | No |

## Returns

The run form returns a `FinetuneHandle` synchronously. The other forms return a `Promise<FinetuneResult>`.

### `FinetuneHandle`

| Field | Description | Type |
| --- | --- | --- |
| `requestId` | ID of this run. Pass it to [`cancel({ requestId })`](/sdk/reference/api/cancel) to stop it. | `string` |
| `progressStream` | One update per training or validation batch. Ends when the run ends. | `AsyncGenerator<`[`FinetuneProgress`](#finetuneprogress)`>` |
| `result` | Resolves when the run completes, pauses, or is cancelled. | `Promise<`[`FinetuneResult`](#finetuneresult)`>` |

#### `FinetuneProgress`

| Field | Description | Type |
| --- | --- | --- |
| `is_train` | `true` for a training batch, `false` for a validation batch. | `boolean` |
| `loss` | Loss. | `number \| null` |
| `loss_uncertainty` | Uncertainty of `loss`. | `number \| null` |
| `accuracy` | Accuracy. | `number \| null` |
| `accuracy_uncertainty` | Uncertainty of `accuracy`. | `number \| null` |
| `global_steps` | Optimizer steps so far. | `number` |
| `current_epoch` | Current epoch, zero-based. | `number` |
| `current_batch` | Current batch in the epoch. | `number` |
| `total_batches` | Batches in the epoch. | `number` |
| `elapsed_ms` | Elapsed time, in milliseconds. | `number` |
| `eta_ms` | Estimated time remaining, in milliseconds. | `number` |

### `FinetuneResult`

| Field | Description | Type |
| --- | --- | --- |
| `type` | Always `"finetune"`. | `"finetune"` |
| `status` | The job's status. A run resolves with `"COMPLETED"`, `"PAUSED"`, or `"CANCELLED"`. `getState` reports `"RUNNING"`, `"PAUSED"` (a pause checkpoint exists), or `"IDLE"`. | `"IDLE" \| "RUNNING" \| "PAUSED" \| "CANCELLED" \| "COMPLETED"` |
| `stats` | Terminal metrics of a run, when reported. | [`FinetuneStats`](#finetunestats) |

#### `FinetuneStats`

| Field | Description | Type |
| --- | --- | --- |
| `global_steps` | Optimizer steps completed. | `number` |
| `epochs_completed` | Epochs completed. | `number` |
| `train_loss` | Training loss. | `number` |
| `train_loss_uncertainty` | Uncertainty of `train_loss`. | `number \| null` |
| `val_loss` | Validation loss. | `number` |
| `val_loss_uncertainty` | Uncertainty of `val_loss`. | `number \| null` |
| `train_accuracy` | Training accuracy. | `number` |
| `train_accuracy_uncertainty` | Uncertainty of `train_accuracy`. | `number \| null` |
| `val_accuracy` | Validation accuracy. | `number` |
| `val_accuracy_uncertainty` | Uncertainty of `val_accuracy`. | `number \| null` |
| `learning_rate` | Learning rate. | `number` |

Every field except `global_steps` and `epochs_completed` is optional.

## Throws

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` is invalid, checked on the client before the request is sent. Thrown synchronously by `finetune()` itself. |
| `InvalidResponseError` | The worker answers with an unexpected response type. |
| `StreamEndedError` | The run's stream ends without a result. |
| `QvacErrorBase` | The worker rejects the run: `"start"` with a pause checkpoint present, `"resume"` without one, or a second run while one is active on the model. |

For the run form, failures reject `result` and are thrown by `progressStream`.

## Examples

```ts
import { finetune, loadModel, QWEN3_600M_INST_Q4, type FinetuneRunParams } from "@qvac/sdk";

const modelId = await loadModel({
  modelSrc: QWEN3_600M_INST_Q4,
  modelConfig: { device: "gpu", ctx_size: 512 },
});

const params: FinetuneRunParams = {
  modelId,
  options: {
    trainDatasetDir: "/home/user/data/train.jsonl",
    validation: { type: "dataset", path: "/home/user/data/eval.jsonl" },
    outputParametersDir: "./finetune-output",
    numberOfEpochs: 2,
    assistantLossOnly: true,
    checkpointSaveDir: "./finetune-output/checkpoints",
  },
};

const handle = finetune(params);
for await (const tick of handle.progressStream) {
  console.log(`epoch ${tick.current_epoch + 1} batch ${tick.current_batch}/${tick.total_batches} loss ${tick.loss}`);
}
const result = await handle.result; // { type: "finetune", status: "COMPLETED", stats }

// Pause a running job, then resume it with the same options.
await finetune({ modelId, operation: "pause" });
const resumed = finetune({ ...params, operation: "resume" });

// Inspect or cancel.
const { status } = await finetune({ ...params, operation: "getState" });
await finetune({ modelId, operation: "cancel" });
```
