Resolves with every built-in RAG workspace that exists on disk, each with whether it is open: loaded in memory and holding resources until [`ragCloseWorkspace()`](/sdk/reference/api/ragCloseWorkspace). Use it to find workspaces to close or delete. See [RAG](/sdk/ai-capabilities/rag).

<Callout type="warn">
**Prototype only:** the built-in RAG vector store is not production grade. For production, use an external vector DB, as shown in the [RAG guide](/sdk/ai-capabilities/rag).
</Callout>

## Signature

```ts
function ragListWorkspaces(options?: RPCOptions): Promise<RagWorkspaceInfo[]>;
```

## Returns

A promise that resolves with one `RagWorkspaceInfo` per workspace, or an empty array when there is none:

| Field | Description | Type |
| --- | --- | --- |
| `name` | Workspace name, as passed in `workspace`. | `string` |
| `open` | `true` when the workspace is loaded in memory and holding resources. | `boolean` |

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `RAG_LIST_WORKSPACES_FAILED` | The worker reports that listing failed. |

## Examples

```ts
const workspaces = await ragListWorkspaces();
for (const { name, open } of workspaces) {
  console.log(`${name} (${open ? "open" : "closed"})`);
}

// Close every open workspace.
for (const { name } of workspaces.filter((w) => w.open)) {
  await ragCloseWorkspace({ workspace: name });
}
```
