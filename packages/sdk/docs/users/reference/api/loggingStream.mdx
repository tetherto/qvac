Opens a stream of the server-side logs emitted under one ID and returns an async generator that yields each log line as it arrives. The stream does not end on its own: break out of the loop, or abort `signal` to end it from elsewhere. To receive every source through one subscription, use [`subscribeServerLogs`](/sdk/reference/api/subscribeServerLogs). See [Logging](/sdk/runtime/logging).

## Signature

```ts
function loggingStream(params: LoggingParams, options?: AbortableRPCOptions): AsyncGenerator<LoggingStreamResponse>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The log source to stream. | [`LoggingParams`](#loggingparams) | Yes |
| `options` | Transport options for this stream, and a signal that ends it. | [`AbortableRPCOptions`](#abortablerpcoptions) | No |

### `LoggingParams`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `id` | The log source. See [Log sources](#log-sources). | `string` | Yes |

#### Log sources

| `id` | Streams |
| --- | --- |
| `SDK_LOG_ID` | The SDK server's own logs. |
| A model ID | The addon logs of that model, as [`loadModel`](/sdk/reference/api/loadModel) returned its ID. |
| `SDK_ALL_LOG_ID` | Every server-side log. Each line's `id` names its origin: `SDK_LOG_ID`, a model ID, or a RAG workspace key. |

Import `SDK_LOG_ID` and `SDK_ALL_LOG_ID` from `@qvac/sdk`.

A stream on a model ID opened up to 5 seconds after its load ends first receives the logs the model emitted while loading, up to the 100 most recent.

### `AbortableRPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `signal` | Ends the stream when aborted. The stream ends without an error, and the worker releases the subscription at once. | `AbortSignal` | No |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. | [`PerCallProfiling`](#percallprofiling) | No |

#### `PerCallProfiling`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `enabled` | Profile this call only. When omitted, the global profiler configuration applies. | `boolean` | No |
| `includeServerBreakdown` | Include the server-side timing breakdown in the profiling payload. | `boolean` | No |
| `includeResourceGauges` | Attach one local CPU, memory, and GPU resource sample to the operation event. | `boolean` | No |
| `mode` | Detail level: `"summary"` keeps aggregates only, `"verbose"` keeps recent events. | `"summary" \| "verbose"` | No |

## Returns

An `AsyncGenerator<LoggingStreamResponse>` that yields one item per log line, in order.

### `LoggingStreamResponse`

| Field | Description | Type |
| --- | --- | --- |
| `type` | Always `"loggingStream"`. | `"loggingStream"` |
| `id` | The source the line was emitted under. Equals `params.id`, except on the `SDK_ALL_LOG_ID` stream, where it is the line's origin. | `string` |
| `level` | Log level. | `"error" \| "warn" \| "info" \| "debug" \| "off"` |
| `namespace` | Namespace of the logger that emitted the line. | `string` |
| `message` | The log message. | `string` |
| `timestamp` | Worker time in milliseconds since the Unix epoch. | `number` |

## Throws

The generator throws while you iterate it.

| Error | When |
| --- | --- |
| `QvacErrorBase` | A response has the wrong type, or the stream fails. |

## Examples

```ts
import { loggingStream, loadModel, SDK_LOG_ID, LLAMA_3_2_1B_INST_Q4_0 } from "@qvac/sdk";

// SDK server logs, read in the background.
void (async () => {
  for await (const log of loggingStream({ id: SDK_LOG_ID })) {
    console.log(`[SDK] [${log.level.toUpperCase()}] [${log.namespace}] ${log.message}`);
  }
})();

// One model's logs, ended from outside the loop with a signal.
const modelId = await loadModel({ modelSrc: LLAMA_3_2_1B_INST_Q4_0 });
const controller = new AbortController();
void (async () => {
  for await (const log of loggingStream({ id: modelId }, { signal: controller.signal })) {
    console.log(`${new Date(log.timestamp).toISOString()} ${log.namespace}: ${log.message}`);
  }
})();

// Later: stop the model stream.
controller.abort();
```
