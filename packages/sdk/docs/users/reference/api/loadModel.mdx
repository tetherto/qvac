Loads a model from a registry constant, a local file, an HTTP(S) URL, or a `pear://` / `registry://` source, and resolves with the model ID that every other call uses to target it. Called with the ID of a model already loaded, it hot-reloads that model's configuration instead.

## Signature

```ts
function loadModel<S extends ModelDescriptor>(options: LoadModelDescriptorParam<S>, rpcOptions?: RPCOptions): Promise<string> & { requestId: string };
function loadModel(options: LoadModelOptions, rpcOptions?: RPCOptions): Promise<string> & { requestId: string };
function loadModel<T extends string>(options: LoadCustomPluginModelOptions<T>, rpcOptions?: RPCOptions): Promise<string> & { requestId: string };
function loadModel(options: ReloadConfigOptions, rpcOptions?: RPCOptions): Promise<string> & { requestId: string };
```

The shape of `options` selects what the call does:

| Form | `options` | Use it when |
| --- | --- | --- |
| From descriptor | [`LoadModelDescriptorParam`](#loadmodeldescriptorparam) | `modelSrc` is a registry model constant. `modelType` is inferred from it. |
| Load new model | [`LoadModelOptions`](#loadmodeloptions) | You name the `modelType` yourself, for any source. |
| Custom plugin | [`LoadCustomPluginModelOptions`](#loadcustompluginmodeloptions) | `modelType` is the name of a [custom plugin](/sdk/configuration/plugins). |
| Hot-reload config | [`ReloadConfigOptions`](#reloadconfigoptions) | The model is already loaded and only its configuration changes. |

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `options` | What to load and how. One of the four forms above. | See [forms](#signature) | Yes |
| `rpcOptions` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `LoadModelOptions`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelSrc` | The model to load: a registry model constant, or a model source — a local file path, an HTTP(S) URL, or a `registry://` / `pear://` URI. Optional only for the `audiogen` and `classification` model types. | `string \| ` [`ModelDescriptor`](#modeldescriptor) | Yes | — |
| `modelType` | The engine that runs the model. | [`ModelType`](#modeltype) | Yes | — |
| `modelConfig` | Engine configuration. Its fields depend on `modelType`. | See [`modelConfig`](#modelconfig) | No | Engine defaults |
| `seed` | Keep sharing the downloaded model with peers over P2P after the download. Applies to `pear://` sources; an HTTP or local source throws `SeedingNotSupportedError`, and registry sources ignore it. | `boolean` | No | `false` |
| `fallbackSrc` | Alternate source — an HTTP URL or local file path — used to load a built-in registry model when it cannot be downloaded from the registry. The bytes are validated against the model checksum before use. | `string` | No | — |
| `requireHttpChecksum` | Reject a Hugging Face download that exposes no usable SHA-256 instead of downloading it unverified. Overrides [`requireHttpChecksum`](/sdk/configuration#options) in the configuration for this call. | `boolean` | No | Configuration value (`false`) |
| `requireSecureTransport` | Reject plaintext `http://` and HTTPS→HTTP downgrades for every HTTP source on this call (loopback exempt). When unset, only Hugging Face transport is hardened. Overrides the configuration for this call. | `boolean` | No | Configuration value (`false`) |
| `modelFitPolicy` | What the fitter's verdict does to this load: `"log"` reports it and loads anyway, `"refuse"` rejects a load the fitter projects will not fit, `"off"` skips the check. See [Assess model fit](/sdk/models/assess-model-fit). | `"log" \| "refuse" \| "off"` | No | Configuration value (`"log"`) |
| `onProgress` | Called with each download progress update. When set, the load streams its progress instead of resolving in one response. | `(progress: ` [`ModelProgressUpdate`](#modelprogressupdate)`) => void` | No | — |
| `logger` | Receives the model's native log stream once it is loaded. | `Logger` | No | — |

#### `ModelDescriptor`

The object form of `modelSrc`. Registry model constants are descriptors.

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `src` | Location of the model file: a local file path, an HTTP(S) URL, or a `registry://` / `pear://` URI. | `string` | Yes |
| `name` | Display name for this model instance; overrides the name derived from the source. | `string` | No |
| `modelId` | Unique identifier used to reference the model in QVAC calls. | `string` | No |
| `registryPath` | Registry-relative path to the model, set for registry-backed models. | `string` | No |
| `registrySource` | Registry source identifier, such as `huggingface`. | `string` | No |
| `blobCoreKey` | Hyperdrive blob core key for the model file. | `string` | No |
| `engine` | Canonical engine identifier, such as `llamacpp-completion`. A literal value narrows `modelConfig` to that engine's fields. | `string` | No |
| `expectedSize` | Expected total size of the model file, in bytes. | `number` | No |
| `sha256Checksum` | Expected SHA-256 checksum of the model file. | `string` | No |
| `addon` | Inference addon or capability category the model belongs to. | `string` | No |

| Canonical | Alias | `modelConfig` |
| --- | --- | --- |

| `llamacpp-embedding` | `embeddings` | [Embedding configuration](#embedding-configuration) |
| `llamacpp-decision` | — | Decision configuration |
| `llamacpp-rerank` | — | Rerank configuration |
| `whispercpp-transcription` | `whisper` | Whisper configuration |
| `bci-whispercpp-transcription` | `bci` | BCI configuration |
| `parakeet-transcription` | `parakeet` | Parakeet configuration |
| `moss-transcribe` | — | MOSS transcription configuration |
| `nmtcpp-translation` | `nmt` | Translation configuration (required) |
| `tts-ggml` | `tts` | Text-to-speech configuration (required) |
| `ggml-ocr` | `ocr` | OCR configuration |
| `sdcpp-generation` | `diffusion` | Diffusion configuration |
| `audiogen-ggml` | `audiogen` | Audio generation configuration (required) |
| `ggml-vla` | `vla` | VLA configuration |

#### `ModelProgressUpdate`

| Field | Description | Type |
| --- | --- | --- |
| `downloaded` | Bytes downloaded so far for the current file. | `number` |
| `total` | Total bytes of the current file. | `number` |
| `percentage` | Progress of the current file, from 0 to 100. | `number` |
| `downloadKey` | Identifies the download this update belongs to. | `string` |
| `shardInfo` | Present for sharded models: the current shard and the progress across all shards. | `{ currentShard, totalShards, shardName, overallDownloaded, overallTotal, overallPercentage }` |
| `fileSetInfo` | Present for models made of several files: the current file and the progress across the set. | `{ setKey, currentFile, fileIndex, totalFiles, overallDownloaded, overallTotal, overallPercentage }` |

### `LoadModelDescriptorParam`

The options of the descriptor form. `modelType` is left out: it is inferred from `modelSrc`, and the call throws `ModelTypeRequiredError` when it cannot be.

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelSrc` | A registry model constant, or any descriptor. | [`ModelDescriptor`](#modeldescriptor) | Yes |
| `modelConfig` | Engine configuration. Narrowed to the engine's fields when the descriptor's `engine` is a literal, as for registry constants; otherwise any object. | See [`modelConfig`](#modelconfig) | No |
| `seed` | As in [`LoadModelOptions`](#loadmodeloptions). | `boolean` | No |
| `fallbackSrc` | As in [`LoadModelOptions`](#loadmodeloptions). | `string` | No |
| `modelFitPolicy` | As in [`LoadModelOptions`](#loadmodeloptions). | `"log" \| "refuse" \| "off"` | No |
| `onProgress` | As in [`LoadModelOptions`](#loadmodeloptions). | `(progress: ModelProgressUpdate) => void` | No |
| `logger` | As in [`LoadModelOptions`](#loadmodeloptions). | `Logger` | No |

### `LoadCustomPluginModelOptions`

The options of [`LoadModelOptions`](#loadmodeloptions), with two differences:

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelType` | The custom plugin's model type. Built-in model types are rejected. | `string` | Yes |
| `modelConfig` | Plugin-defined configuration, passed through unchecked. | `Record<string, unknown>` | No |

### `ReloadConfigOptions`

Hot-reloads a loaded model. Only Whisper models support it.

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelId` | ID of the loaded model, as `loadModel` returned it: 16 lowercase hexadecimal characters. | `string` | Yes |
| `modelType` | `"whispercpp-transcription"` or its alias `"whisper"`. | `string` | Yes |
| `modelConfig` | The Whisper configuration fields to change. Fields left out keep their value. | Whisper configuration | Yes |

## `modelConfig`

Each model type takes its own configuration.

<Callout type="info">
**PoC:** this page is the format sample for hand-written references. Only the embedding configuration is written out below; the other model types follow the same table format.
</Callout>

### Embedding configuration

For `modelType: "llamacpp-embedding"` (`"embeddings"`).

| Field | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `device` | Device to run inference on. | `"gpu" \| "cpu"` | No | `"gpu"` |
| `gpuLayers` | Number of model layers to offload to the GPU. | `number` | No | `99` (all) |
| `ctxSize` | Runtime context size in tokens. Lower it to bound memory for long-context models. | `number` | No | The model's trained context size |
| `batchSize` | Tokens processed per batch. Each input must fit in it. | `number` | No | `1024` |
| `pooling` | How token embeddings collapse into one sequence vector. | `"none" \| "mean" \| "cls" \| "last"` | No | Model default |
| `attention` | Attention type. | `"causal" \| "non-causal"` | No | Model default |
| `embdNormalize` | Embedding normalization: `-1` none, `0` max-abs int16, `1` taxicab, `2` euclidean, `>2` p-norm. | `number` | No | `2` |
| `flashAttention` | Flash attention. | `"on" \| "off" \| "auto"` | No | `"auto"` |
| `backend` | Ordered GPU backend preference, such as `["cuda", "vulkan"]`. Falls back to the native order when none is available. Cannot be combined with `splitMode: "layer"`. | `("cuda" \| "vulkan" \| "metal" \| "opencl" \| "auto")[]` | No | Native order |
| `mainGpu` | GPU to use on multi-GPU systems: a device index, or `"integrated"` / `"dedicated"` to restrict selection to that class. | `number \| "integrated" \| "dedicated"` | No | — |
| `splitMode` | How to split the model across GPUs: `"none"` for a single GPU, `"layer"` for pipeline parallelism. | `"none" \| "layer"` | No | `"none"` |
| `tensorSplit` | Proportions for distributing layers across GPUs, such as `"1,1"` or `"3,1"`. | `string` | No | — |
| `poll` | CPU polling level, from `0` to `100`. Higher values may reduce wake latency at the cost of CPU during GPU work. See [CPU polling](/sdk/configuration#cpu-polling-for-llamacpp-models). | `number` | No | Native behavior |
| `pollBatch` | CPU polling level for batch processing, from `0` to `100`. | `number` | No | Native behavior |
| `projectionModelSrc` | Projection model for image and audio embeddings, such as the EmbeddingGemma 2 mmproj. Omit for text-only use. | `string \| ModelDescriptor` | No | — |
| `imageMaxTokens` | Maximum image token budget. Each input must fit in `batchSize`. | `number` | No | Projector default |
| `imageMinTokens` | Minimum image token budget. Must not exceed `imageMaxTokens`. | `number` | No | Projector default |
| `imageMaxMegapixels` | Maximum image size before decoding, in megapixels. | `number` | No | `50` |
| `audioMaxSeconds` | Maximum audio duration before decoding, in seconds. | `number` | No | `600` |
| `mmprojNoAudio` | Skip the projector's audio encoder. Audio input is then rejected. | `boolean` | No | `false` |
| `mmprojUseGpu` | Projector GPU override. Ignored when the model runs on CPU. | `boolean` | No | Follows the addon's device policy |
| `verbosity` | Native log verbosity: `0` error, `1` warn, `2` info, `3` debug. | `0 \| 1 \| 2 \| 3` | No | `0` |
| `openclCacheDir` | Writable directory for the OpenCL kernel binary cache. Required on Android for fast GPU startup. | `string` | No | — |

## Returns

A promise that resolves with the model ID, a `string` every other call uses to target the model. The promise also carries `requestId`, available synchronously, so the load can be cancelled with [`cancel({ requestId })`](/sdk/reference/api/cancel) before it resolves.

## Throws

| Error | When |
| --- | --- |
| `ModelTypeRequiredError` | The descriptor form cannot infer `modelType` from `modelSrc`. |
| `SeedingNotSupportedError` | `seed` is `true` for an HTTP or local source. |
| `QvacErrorBase` | Loading or reloading fails; the message carries the details. |
| `QvacErrorBase` | The progress stream ends unexpectedly (only with `onProgress`). |
| `QvacErrorBase` | The server answers with an invalid response type. |

## Examples

```ts
// Registry constant: modelType is inferred, and modelConfig narrows to the engine.
const modelId = await loadModel({
  modelSrc: LLAMA_3_2_1B_INST_Q4_0,
  modelConfig: { ctx_size: 2048 },
});

// Local file, with an explicit model type.
const embedId = await loadModel({
  modelSrc: "/home/user/models/embeddinggemma.gguf",
  modelType: "llamacpp-embedding",
  modelConfig: { device: "cpu", pooling: "mean" },
});

// Remote file with download progress.
const remoteId = await loadModel({
  modelSrc: "https://huggingface.co/<org>/<repo>/resolve/main/model.gguf",
  modelType: "llamacpp-completion",
  onProgress: (progress) => console.log(`${progress.percentage}%`),
});

// Cancel a load before it resolves.
const load = loadModel({ modelSrc: LLAMA_3_2_1B_INST_Q4_0 });
await cancel({ requestId: load.requestId });

// Hot-reload a loaded Whisper model's configuration.
await loadModel({
  modelId: whisperId,
  modelType: "whisper",
  modelConfig: { language: "pt" },
});
```
