Generates one block of video for the walk of a world built by [`worldCreateScene()`](/sdk/reference/api/worldCreateScene), or loaded from `modelConfig.sceneSrc`, under the keys held for that block. The call returns immediately with a request ID, a frame stream, a progress stream, and promises for the whole block and its statistics. One block runs at a time per model: a second call while one is in flight is rejected, so start the next call after the previous one settles. See [World simulation](/sdk/ai-capabilities/world-simulation).

At the default `modelConfig.world.numFramePerBlock`, the first block after the session loads has 9 frames (decoder warmup) and later blocks have 12. Read `stats.frames` rather than assuming these counts.

## Signature

```ts
function worldStep(params: WorldStepClientParams): WorldStepResult;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model and the keys held for this block. | [`WorldStepClientParams`](#worldstepclientparams) | Yes |

### `WorldStepClientParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a model loaded with `modelConfig.mode: "world"`. | `string` | Yes | — |
| `keys` | Keys held for this block. W, A, S, and D move; I, J, K, and L steer the camera. Omit it, or pass an empty value, for an idle block. | [`WalkKeysInput`](#walkkeysinput) | No | Idle |

#### `WalkKeysInput`

Three equivalent forms:

| Form | Example | Type |
| --- | --- | --- |
| Array of key names | `["W", "L"]` | `readonly string[]` |
| Key-state object: keys with a truthy value are held | `{ W: true, L: true }` | `Readonly<Record<string, boolean \| undefined>>` |
| 8-bit mask: bits 0 to 7 are W, A, S, D, I, J, K, L | `0b10000001` | `number` |

Key names are case-insensitive, and duplicates collapse. The mask must be an integer from 0 to 255.

## Returns

An object, returned synchronously. The block starts generating when `worldStep()` is called.

### `WorldStepResult`

| Field | Description | Type |
| --- | --- | --- |
| `requestId` | Identifies this block, for [`cancel({ requestId })`](/sdk/reference/api/cancel). | `string` |
| `frameStream` | Yields each frame of the block as the transport delivers it: PNG, or JPEG when `modelConfig.world.frameJpegQuality` is from 1 to 100. Ends when the block's stream ends; throws the step's error when it fails. | `AsyncGenerator<Uint8Array>` |
| `progressStream` | Yields one tick per block, after its frames. It is an end-of-block summary, not a sign of progress within the block. Ends with the stream; throws the step's error when it fails. | `AsyncGenerator<`[`WorldStepProgressTick`](#worldstepprogresstick)`>` |
| `frames` | Resolves with every frame of the block once it completes. | `Promise<Uint8Array[]>` |
| `stats` | Resolves with the block statistics when it completes, or `undefined` when the engine reports none. | `Promise<`[`WorldStepStats`](#worldstepstats)` \| undefined>` |

Each stream can be consumed alone.

#### `WorldStepProgressTick`

| Field | Description | Type |
| --- | --- | --- |
| `step` | Blocks completed on this session, as the engine counts them. | `number` |
| `totalSteps` | Frames delivered by the block that just finished. Named `totalSteps` to match the progress ticks of `video()` and `diffusion()`. | `number` |
| `elapsedMs` | Time elapsed within the block, in milliseconds. | `number` |

#### `WorldStepStats`

Every field is optional.

| Field | Description | Type |
| --- | --- | --- |
| `modelLoadMs` | Time spent loading the transformer, the decoder, and the scene pack, in milliseconds. | `number` |
| `stepMs` | Generation time of this block, excluding frame encoding, in milliseconds. | `number` |
| `totalStepMs` | Cumulative generation time across the session, in milliseconds. | `number` |
| `totalSteps` | Blocks generated so far in this session. Resets when the session reloads. | `number` |
| `totalFrames` | Cumulative frames delivered across the session. | `number` |
| `frames` | Frames delivered for this block. | `number` |
| `width` | Frame width in pixels. | `number` |
| `height` | Frame height in pixels. | `number` |
| `actionMask` | The 8-bit key mask this block was generated under (bits 0 to 7 are W, A, S, D, I, J, K, L). | `number` |

## Throws

`RequestValidationFailedError` raised on the client is thrown by `worldStep()` itself, before any request is sent. Every other error rejects `frames` and `stats`, and is thrown by both streams.

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | On the client: a key name is unknown, or the mask is not an integer from 0 to 255. |
| `ModelOperationNotSupportedError` | The model was not loaded with `modelConfig.mode: "world"`. |
| `RequestRejectedByPolicyError` | A block is already in flight on the model. |
| `InferenceCancelledError` | A `cancel({ requestId })` is accepted. Cancelling is block-granular: the current block finishes internally, delivery stops, and the step rejects instead of resolving with a truncated block. The session is rebuilt on the next call. |
| `StreamEndedError` | The RPC stream closes without a terminal `done` chunk. |

## Examples

```ts
import { cancel, worldStep } from "@qvac/sdk";
import fs from "fs";

// Walk a scripted tape, one block at a time, writing each frame as it arrives.
const tape = [["W"], ["W", "L"], ["W"], []];
let frameNumber = 0;
for (const keys of tape) {
  const run = worldStep({ modelId, keys });
  for await (const frame of run.frameStream) {
    fs.writeFileSync(`frame-${frameNumber++}.jpg`, frame);
  }
  const stats = await run.stats;
  console.log(`${stats?.frames} frames in ${stats?.stepMs} ms`);
}

// A key-state object from a keyboard handler, and cancellation.
const run = worldStep({ modelId, keys: { W: true, L: true } });
setTimeout(() => {
  cancel({ requestId: run.requestId }).catch(() => {
    // The block finished before the cancel landed.
  });
}, 200);
try {
  await run.frames;
} catch (error) {
  console.log("cancelled:", error);
}
```
