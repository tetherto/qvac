Generates audio from a caption and optional lyrics and musical controls with a loaded AudioGen model (`modelType: "audiogen"`). It returns a run object synchronously: `progressStream` reports the stages as they run, and `audio` resolves with interleaved PCM when generation ends. ACE-Step also re-renders (`cover-nofsq`) or rebuilds one instrument layer (`lego`) of a source recording. To edit a recording, use [`audioEdit()`](/sdk/reference/api/audioEdit); to describe one, [`audioUnderstand()`](/sdk/reference/api/audioUnderstand). See [Music generation](/sdk/ai-capabilities/music-generation).

## Signature

```ts
function audioGen(params: AudioGenClientParams): AudioGenResult;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | What to generate and how. Unknown keys are rejected. | [`AudioGenClientParams`](#audiogenclientparams) | Yes |

### `AudioGenClientParams`

Most controls apply to one engine. MiniMax-Music3 rejects the ACE-Step-only fields, except `simpleMode` and `normalizeLoudness`, which it ignores.

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a loaded AudioGen model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes | — |
| `caption` | Description of the audio to generate. Must not be empty or whitespace-only. | `string` | Yes | — |
| `lyrics` | Vocal lyrics. Use `"[Instrumental]"` for instrumental output. | `string` | No | — |
| `seed` | RNG seed, an integer; omit for a random one. An ACE-Step run reports the seed it used in `stats.metadata.seed`, so an unseeded take can be replayed. | `number` | No | Random |
| `duration` | Approximate duration in seconds. Engines round to their frame grid; `stats.audioDurationMs` and the returned PCM are authoritative. Cannot be combined with `maxFrames`. | `number` | No | — |
| `inferenceSteps` | Diffusion steps for this run, an integer from 0 to 1000. `0` is the engine default: MiniMax 20 flow steps, ACE-Step 8 on turbo DiTs and 50 on base/SFT. | `number` | No | Load-time `inferenceSteps` |
| `vocalLanguage` | ACE-Step: vocal language, such as `"en"`. Inferred from the caption when omitted. | `string` | No | — |
| `bpm` | ACE-Step: beats per minute, a non-negative integer. `0` or unset lets the LM infer it. | `number` | No | — |
| `keyscale` | ACE-Step: key and scale, such as `"A minor"`. Inferred from the caption when omitted. | `string` | No | — |
| `timesignature` | ACE-Step: time signature, such as `"4/4"`. Inferred from the caption when omitted. | `string` | No | — |
| `augmentCaptionWithMetadata` | ACE-Step: append BPM/tempo, time-signature, and key guidance to the internal conditioning caption; the result metadata keeps your caption. | `boolean` | No | `false` |
| `simpleMode` | ACE-Step: treat `caption` as a short query and let the LM compose a detailed caption, lyrics, and any metadata left unset. Options you set are kept. Leave `lyrics` unset for LM-written vocals, or pass `"[Instrumental]"`. Cannot be combined with `rewriteQuery` or `audioCodes`. | `boolean` | No | — |
| `rewriteQuery` | ACE-Step: the LM rewrites `caption` into a detailed musical description, preserving the lyric content and filling metadata left unset. Requires real `lyrics`. Faithful rewriting needs the 1.7B LM. Cannot be combined with `simpleMode` or `audioCodes`. | `boolean` | No | — |
| `generateLrc` | ACE-Step: align the lyrics with the generated audio and return LRC text in `stats.lrc`, with a confidence in `stats.lyricsScore`. Needs lyrics; instrumental requests are rejected. | `boolean` | No | — |
| `computeQualityScore` | ACE-Step: score the generated codes against the request, in `[0, 1]`, in `stats.qualityScore`. Costs extra LM forwards; made for ranking a batch of takes. | `boolean` | No | — |
| `normalizeLoudness` | ACE-Step: percentile loudness normalization — the 99.999th-percentile sample scales to full scale and the tail above it clips. `false` returns the raw engine output. | `boolean` | No | `true` |
| `guidanceScale` | ACE-Step: DiT classifier-free guidance scale, non-negative. `0` resolves to `1.0` on turbo variants (CFG off) and `7.0` on base/SFT. Values above `1` double the DiT cost per step. | `number` | No | `0` |
| `shift` | ACE-Step: DiT timestep shift for this run, `0` or a positive float32 value. `0` is the engine default: `3.0` on turbo DiTs, `1.0` on base/SFT. | `number` | No | Load-time `shift` |
| `lmTemperature` | ACE-Step: LM sampling temperature, non-negative. | `number` | No | `0.85` |
| `lmTopP` | ACE-Step: LM nucleus-sampling probability, from 0 to 1. | `number` | No | `0.9` |
| `lmTopK` | ACE-Step: LM top-k cutoff, a non-negative integer. `0` disables top-k filtering. | `number` | No | — |
| `lmCfgScale` | ACE-Step: classifier-free guidance scale used by the LM, non-negative. | `number` | No | — |
| `lmPhase1` | ACE-Step: let the LM infer missing metadata before semantic-code generation. | `boolean` | No | — |
| `dcwEnabled` | ACE-Step: apply the Haar DCW correction during DiT sampling. | `boolean` | No | `true` |
| `dcwScaler` | ACE-Step: DCW low-frequency correction strength, non-negative. | `number` | No | `0.05` |
| `dcwHighScaler` | ACE-Step: DCW high-frequency correction strength, non-negative. | `number` | No | `0.02` |
| `audioCodes` | ACE-Step: frozen semantic codes (int32) to synthesize instead of running the LM, such as the codes [`audioUnderstand()`](/sdk/reference/api/audioUnderstand) recovered. 1 to 3000 codes (`AUDIOGEN_MAX_AUDIO_CODES`). | `Int32Array \| number[]` | No | — |
| `taskType` | ACE-Step: `"text2music"` generates from the caption; `"cover-nofsq"` re-renders `sourceAudio` with a new caption, keeping its structure; `"lego"` regenerates one instrument layer of `sourceAudio`, named by `track`. `simpleMode`, `rewriteQuery`, `generateLrc`, and `computeQualityScore` require `"text2music"`. | `"text2music" \| "cover-nofsq" \| "lego"` | No | `"text2music"` |
| `track` | ACE-Step: the instrument layer `"lego"` regenerates. Required with `"lego"`, rejected otherwise. | [`AudioGenTrack`](#audiogentrack) | No | — |
| `sourceAudio` | ACE-Step: the recording a `"cover-nofsq"` or `"lego"` task works from; required for both. | `string \| Uint8Array` | No | — |
| `referenceAudio` | ACE-Step: timbre reference; omit to keep the engine default. | `string \| Uint8Array` | No | — |
| `audioCoverStrength` | ACE-Step: fraction of DiT steps that keep the source context, from 0 to 1. `"cover-nofsq"` currently requires `1`. | `number` | No | `1` |
| `coverNoiseStrength` | ACE-Step: blend of the initial DiT noise toward the clean source latent, from 0 (pure noise) to 1 (≈ source latent). | `number` | No | `0` |
| `maxFrames` | MiniMax: semantic-frame cap, a positive integer. Cannot be combined with `duration`. | `number` | No | — |
| `cfgScale` | MiniMax: flow classifier-free guidance scale, `0` or a positive float32 value. `0` uses the model default. | `number` | No | Model default |

`sourceAudio` and `referenceAudio` take a file path or raw PCM. A path is read on the server: `.wav`, `.mp3`, `.m4a`, `.ogg`, `.flac`, and `.aac` are decoded, and any other extension is read as raw PCM. Raw PCM — in a file or a `Uint8Array` — is interleaved stereo 48 kHz Float32 LE (`AUDIOGEN_INPUT_SAMPLE_RATE`, `AUDIOGEN_INPUT_CHANNELS`). Clips are capped at 600 s.

#### `AudioGenTrack`

`"vocals" | "backing_vocals" | "drums" | "bass" | "guitar" | "keyboard" | "percussion" | "strings" | "synth" | "fx" | "brass" | "woodwinds"`, exported as `AUDIOGEN_TRACKS`.

## Returns

An `AudioGenResult`, returned synchronously. The request is sent at once.

| Field | Description | Type |
| --- | --- | --- |
| `requestId` | ID of this run, available synchronously. Pass it to [`cancel({ requestId })`](/sdk/reference/api/cancel); cancellation interrupts the active generation. | `string` |
| `progressStream` | Stage and step updates while the run executes. Ends when the run ends; throws the run's error when it fails. | `AsyncGenerator<` [`AudioGenProgress`](#audiogenprogress) `>` |
| `audio` | The generated audio, resolved from the terminal frame. | `Promise<` [`AudioGenAudio`](#audiogenaudio) `>` |
| `stats` | Timing statistics and what the run rendered. | `Promise<` [`AudioGenStats`](#audiogenstats) ` \| undefined>` |
| `diagnostics` | Backend selection detail for the completed run. | `Promise<` [`InferenceBackendDiagnostics`](/sdk/reference/api/transcribeStream#inferencebackenddiagnostics) ` \| undefined>` |

A cancelled run ends with `stopReason: "cancelled"`: `progressStream` ends, and `audio`, `stats`, and `diagnostics` reject with `InferenceCancelledError`.

### `AudioGenProgress`

| Field | Description | Type |
| --- | --- | --- |
| `stage` | Pipeline stage the update belongs to. | `string` |
| `step` | Current step, a non-negative integer. | `number` |
| `total` | Total steps when greater than zero. A value of zero or less means indeterminate progress; do not render it as `step / total`. | `number` |

### `AudioGenAudio`

| Field | Description | Type |
| --- | --- | --- |
| `pcm` | Raw interleaved PCM, without a container header. | `Uint8Array` |
| `sampleRate` | Sample rate, in Hz. | `number` |
| `channels` | Channel count. | `number` |
| `bitsPerSample` | Sample width, in bits. Use it to count samples or build a WAV header. | `number` |

### `AudioGenStats`

Every field is optional.

| Field | Description | Type |
| --- | --- | --- |
| `audioDurationMs` | Duration of the generated audio, in milliseconds. | `number` |
| `totalTimeMs` | Total generation time, in milliseconds. | `number` |
| `realTimeFactor` | Real-time factor of the run. | `number` |
| `backendDevice` | Device the engine used: `0` CPU, `1` GPU. | `number` |
| `backendId` | Backend the engine used: `0` CPU, `1` Metal, `2` CUDA, `3` Vulkan, `4` OpenCL. | `number` |
| `gpuFallbackReason` | Why a run that asked for a GPU resolved to the CPU: `0` none, `1` not requested, `2` no devices, `3` init failed. | `number` |
| `emittedFrames` | MiniMax: semantic frames the autoregressive stage emitted (25 per second). Below the frame cap when the song ended on its own. | `number` |
| `arMs` | MiniMax: time in the autoregressive semantic stage, in milliseconds. | `number` |
| `conditionMs` | MiniMax: time building the flow conditioning, in milliseconds. | `number` |
| `flowMs` | MiniMax: time in the flow-matching DiT, in milliseconds. | `number` |
| `vocoderMs` | MiniMax: time in the vocoder, in milliseconds. | `number` |
| `metadata` | ACE-Step: what the run rendered, after the LM filled in what was left unset. | [`AudioGenGenerationMetadata`](#audiogengenerationmetadata) |
| `lyricsScore` | Lyric-to-audio alignment confidence, in `[0, 1]`. Only with `generateLrc`. | `number` |
| `lrc` | LRC-formatted lyric timestamps. Only with `generateLrc`. | `string` |
| `qualityScore` | Weighted quality of the generated codes against the request, in `[0, 1]`. Only with `computeQualityScore`. | `number` |
| `understand` | Only on an [`audioUnderstand()`](/sdk/reference/api/audioUnderstand) run: the description of the clip. | [`AudioGenUnderstandResult`](/sdk/reference/api/audioUnderstand#audiogenunderstandresult) |

#### `AudioGenGenerationMetadata`

| Field | Description | Type |
| --- | --- | --- |
| `caption` | The caption the run used: the LM-composed one under Simple Mode or Query Rewriting. With `augmentCaptionWithMetadata`, always your own caption. Empty for an edit. | `string` |
| `lyrics` | The lyrics the run used (LM-written under Simple Mode). | `string` |
| `bpm` | Beats per minute; `0` when unresolved. | `number` |
| `keyscale` | Key and scale the run used. | `string` |
| `beatsPerBar` | Time-signature numerator (`4` for 4/4); `0` when unresolved. | `number` |
| `vocalLanguage` | Vocal language the run used. | `string` |
| `seed` | The seed the run used: the engine-drawn one when none was passed. | `number` |
| `codeFrames` | 5 Hz semantic code frames the DiT was conditioned on; `0` when the LM and detokenizer are skipped (`cover-nofsq`, `lego`, edits). | `number` |
| `qualityReport` | Per-condition breakdown of `qualityScore`. Only with `computeQualityScore`. | `string` |

## Throws

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` fails validation — for example an unknown key, `duration` with `maxFrames`, `"lego"` without `track`, or `simpleMode` with `rewriteQuery`. Thrown synchronously. |
| `InferenceCancelledError` | The run was cancelled. Rejects `audio`, `stats`, and `diagnostics`. |
| `InvalidResponseError` | The stream ends without a terminal frame, or without the audio format. Rejects `audio`, `stats`, `diagnostics`, and `progressStream`. |
| `QvacErrorBase` | Generation fails on the server. Rejects `audio`, `stats`, `diagnostics`, and `progressStream`. |

## Examples

```ts
// ACE-Step song with lyrics and musical controls.
const run = audioGen({
  modelId,
  caption: "Energetic cumbia with brass stabs and live percussion",
  lyrics: "[verse]\nThe city wakes beneath the moon",
  vocalLanguage: "en",
  bpm: 98,
  keyscale: "A minor",
  timesignature: "4/4",
  duration: 30,
  seed: 42,
});

for await (const progress of run.progressStream) {
  console.log(`${progress.stage}: ${progress.step}/${progress.total}`);
}
const { pcm, sampleRate, channels, bitsPerSample } = await run.audio;
const rendered = (await run.stats)?.metadata;

// Cover: keep the structure of a source song, change the arrangement.
const cover = audioGen({
  modelId,
  caption: "orchestral arrangement with dramatic strings",
  lyrics: "[Instrumental]",
  taskType: "cover-nofsq",
  sourceAudio: "/path/to/source.wav",
});

// Cancel a run.
const pending = audioGen({ modelId, caption: "Ambient electronic music" });
await cancel({ requestId: pending.requestId });
try {
  await pending.audio;
} catch (error) {
  if (!(error instanceof InferenceCancelledError)) throw error;
}
```
