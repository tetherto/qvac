Edits one source recording with a loaded ACE-Step AudioGen model. The edit is an ordered pipeline of operations, executed in array order: `flow-edit` re-conditions the whole clip from a source prompt to a target prompt, and `repaint` regenerates a time range against a new prompt. It returns the same run object as [`audioGen()`](/sdk/reference/api/audioGen), synchronously. MiniMax-Music3 does not support it. See [Music generation](/sdk/ai-capabilities/music-generation#edit-an-existing-recording).

## Signature

```ts
function audioEdit(params: AudioEditClientParams): AudioGenResult;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The source recording and the edit pipeline. Unknown keys are rejected. | [`AudioEditClientParams`](#audioeditclientparams) | Yes |

### `AudioEditClientParams`

The fields after `operations` apply to every operation in the pipeline.

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a loaded ACE-Step model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes | — |
| `sourceAudio` | The recording to edit: a file path read on the server, or raw interleaved stereo 48 kHz Float32 LE PCM with every sample in `[-1, 1]`. Path decoding and limits are as for [`audioGen()`](/sdk/reference/api/audioGen#audiogenclientparams). | `string \| Uint8Array` | Yes | — |
| `operations` | The edit pipeline, at least one operation. Operations run in array order and may repeat or mix. | [`AudioEditOperation[]`](#audioeditoperation) | Yes | — |
| `referenceAudio` | Timbre reference for every operation, in the same forms as `sourceAudio`. | `string \| Uint8Array` | No | — |
| `seed` | Seeds the first operation; each following operation uses `seed` + its index. Omit for a random one, reported in `stats.metadata.seed`. | `number` | No | Random |
| `vocalLanguage` | Vocal language hint for the edit prompts. | `string` | No | `"unknown"` |
| `bpm` | Beats per minute for the edit prompts, a non-negative integer. `0` or unset leaves it unset. | `number` | No | — |
| `keyscale` | Key and scale for the edit prompts, such as `"C minor"`. | `string` | No | — |
| `timesignature` | Time signature for the edit prompts, such as `"4/4"`. | `string` | No | — |
| `augmentCaptionWithMetadata` | Append BPM, time signature, and key to each operation's conditioning caption. | `boolean` | No | `false` |
| `dcwEnabled` | Repaint only: apply the Haar DCW sampler correction. | `boolean` | No | `true` |
| `dcwScaler` | Repaint only: DCW low-frequency correction strength, non-negative. | `number` | No | `0.05` |
| `dcwHighScaler` | Repaint only: DCW high-frequency correction strength, non-negative. | `number` | No | `0.02` |
| `inferenceSteps` | DiT steps for every operation, an integer from 0 to 1000. | `number` | No | Load-time `inferenceSteps` |
| `shift` | DiT timestep shift for every operation, `0` or a positive float32 value. | `number` | No | Load-time `shift` |

#### `AudioEditOperation`

One of two shapes, selected by `type`.

**`flow-edit`** — re-conditions the whole clip. Supported on the turbo DiT variants only.

| Field | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `type` | `"flow-edit"`. | `"flow-edit"` | Yes | — |
| `from` | Description of the unedited source audio. | [`AudioEditPrompt`](#audioeditprompt) | Yes | — |
| `to` | Description of the desired audio. | [`AudioEditPrompt`](#audioeditprompt) | Yes | — |
| `nMin` | Start of the diffusion window, from 0 to 1. Must not exceed `nMax`. | `number` | No | `0` |
| `nMax` | End of the diffusion window, from 0 to 1. | `number` | No | `1` |
| `nAvg` | Forward-noise samples averaged per active step, a positive integer. | `number` | No | `1` |

**`repaint`** — regenerates a time range and keeps the audio outside it.

| Field | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `type` | `"repaint"`. | `"repaint"` | Yes | — |
| `caption` | Description of the repainted region. Must not be empty or whitespace-only. | `string` | Yes | — |
| `lyrics` | Lyrics for the repainted region. | `string` | No | `"[Instrumental]"` |
| `start` | Region start, in seconds. Must lie inside the source recording. | `number` | Yes | — |
| `end` | Region end, in seconds; greater than `start`. The range must span at least one latent frame (1/25 s). | `number` | No | End of the source |
| `mode` | Preservation mode outside the repainted region. | `"conservative" \| "balanced" \| "aggressive"` | No | `"balanced"` |
| `strength` | Balanced-mode preservation strength, from 0 to 1. | `number` | No | `0.5` |

#### `AudioEditPrompt`

| Field | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `caption` | Description of the audio. Must not be empty or whitespace-only. | `string` | Yes | — |
| `lyrics` | Lyrics for this prompt. | `string` | No | `"[Instrumental]"` |

## Returns

An [`AudioGenResult`](/sdk/reference/api/audioGen#returns), returned synchronously, with the same fields and cancellation behavior as for `audioGen()`. `audio` resolves with the edited recording; edits are never loudness-normalized. `stats.metadata` reports the base seed and the prompt metadata, with an empty `caption` and `codeFrames` `0`.

## Throws

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` fails validation — for example an unknown key, an empty `operations`, a `flow-edit` with `nMin` greater than `nMax`, or a `repaint` with `end` not greater than `start`. Thrown synchronously. |
| `InferenceCancelledError` | The run was cancelled. Rejects `audio`, `stats`, and `diagnostics`. |
| `InvalidResponseError` | The stream ends without a terminal frame, or without the audio format. |
| `QvacErrorBase` | The edit fails on the server. Rejects `audio`, `stats`, `diagnostics`, and `progressStream`. |

## Examples

```ts
const run = audioEdit({
  modelId,
  sourceAudio: "/path/to/song.wav",
  operations: [
    {
      type: "flow-edit",
      from: { caption: "original pop song" },
      to: { caption: "guitar pop-rock" },
    },
    {
      type: "repaint",
      caption: "analog synth solo",
      lyrics: "[Instrumental]",
      start: 10,
      end: 20,
    },
  ],
  seed: 22883,
});

for await (const progress of run.progressStream) {
  console.log(`${progress.stage}: ${progress.step}/${progress.total}`);
}
const { pcm, sampleRate, channels, bitsPerSample } = await run.audio;
```
