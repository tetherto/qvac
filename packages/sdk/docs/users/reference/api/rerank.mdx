Scores each document against a query with a loaded `llamacpp-rerank` model (a cross-encoder) and resolves with one score per document, in input order. Higher is more relevant. `rerank()` does not sort: sort the documents by score yourself. See [Reranking](/sdk/ai-capabilities/reranking).

## Signature

```ts
function rerank(params: RerankParams, options?: RPCOptions): Promise<number[]> & { requestId: string };
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model, the query, and the documents. | [`RerankParams`](#rerankparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `RerankParams`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelId` | ID of a loaded reranker model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. Non-empty. | `string` | Yes |
| `query` | Query to score each document against. Non-empty. | `string` | Yes |
| `documents` | Documents to score. At least one. Each document, paired with the query, must fit in the model's load-time `batch_size`. | `string[]` | Yes |

#### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. See [Profiler](/sdk/runtime/profiler). | `PerCallProfiling` | No |

## Returns

A promise that resolves with one score per document, in input order (`number[]`). Higher is more relevant. Scores are the model's raw classifier output, a logit for most rerankers, so they can be negative and are comparable only within one model.

The promise also carries `requestId`, available synchronously, so the call can be cancelled with [`cancel({ requestId })`](/sdk/reference/api/cancel) before it resolves.

## Throws

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` is invalid, checked on the client before the request is sent. |
| `InferenceCancelledError` | The request is cancelled, while running or queued. |
| `RequestRejectedByPolicyError` | The model's rerank queue is full: 64 waiting requests. Active and queued requests are unaffected. |
| `InvalidResponseError` | The worker returns a malformed result, or a score count that does not match `documents`. |

## Examples

```ts
import { loadModel, rerank } from "@qvac/sdk";

const modelId = await loadModel({
  modelSrc: "/home/user/models/jina-reranker-v1-tiny-en-f16.gguf",
  modelType: "llamacpp-rerank",
});

const query = "How do I get a refund for a duplicate charge?";
const documents = [
  "Refunds for duplicate or failed payments are issued within 5 business days.",
  "Our office is open Monday to Friday, 9am to 5pm.",
  "If you were charged twice, contact billing with both transaction IDs.",
];

const scores = await rerank({ modelId, query, documents });
const ranked = documents
  .map((document, index) => ({ document, score: scores[index]! }))
  .sort((a, b) => b.score - a.score);
```
