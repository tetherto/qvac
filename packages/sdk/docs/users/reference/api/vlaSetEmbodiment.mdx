Switches a loaded multi-embodiment GR00T model to another embodiment shipped in the same GGUF. Nothing is reloaded: only that embodiment's weight rows are re-read. Resolves with the refreshed hyperparameters, which follow the newly active embodiment; rebuild your [`vla()`](/sdk/reference/api/vla) input buffers from them. To pick the embodiment at load instead, set `modelConfig.embodiment` in [`loadModel()`](/sdk/reference/api/loadModel). See [GR00T embodiments](/sdk/ai-capabilities/vla#gr00t-embodiments).

## Signature

```ts
function vlaSetEmbodiment(params: { modelId: string; embodiment: VlaEmbodimentSelection }): Promise<{ hparams: VlaHparams }>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params.modelId` | ID of a GR00T model loaded with `modelType: "vla"` (`"ggml-vla"`). | `string` | Yes |
| `params.embodiment` | The embodiment to activate. | [`VlaEmbodimentSelection`](#vlaembodimentselection) | Yes |

### `VlaEmbodimentSelection`

One of:

| Form | Description | Type |
| --- | --- | --- |
| Tag | The embodiment tag as stored in the GGUF, such as `"libero_sim"`. 1 to 256 characters. | `string` |
| Category ID | The embodiment's numeric `cat_id`, an integer from 0 to 31. | `number` |
| Object | A `tag` or a `catId` (exactly one), plus an optional `numCameras`. | `{ tag: string; numCameras?: number } \| { catId: number; numCameras?: number }` |

`numCameras` overrides the camera count stored in the GGUF for the selected embodiment, as an integer from 1 to 64. It is required to select an embodiment whose camera count the GGUF does not store.

## Returns

A promise that resolves with `{ hparams }`: the model's [`VlaHparams`](/sdk/reference/api/vlaHparams#vlahparams) after the switch. `numCameras`, `actionDim`, `selectedEmbodimentTag`, and `selectedEmbodimentCatId` follow the newly active embodiment. Selecting by `catId` reports that ID's canonical tag, which may differ from an alias used to select it; the ID is the stable identity.

## Throws

The promise rejects, and the current embodiment stays active, when:

- the model is not GR00T, or its GGUF stores a single embodiment;
- the tag or `cat_id` is unknown, or not stored in the GGUF;
- the embodiment has no known camera count and `numCameras` is not given;
- a `vla()` call on the model is still pending. Await it first.

## Examples

```ts
import { loadModel, vlaSetEmbodiment } from "@qvac/sdk";

const modelId = await loadModel({
  modelSrc: "/path/to/groot-multi.gguf",
  modelType: "ggml-vla",
  modelConfig: { embodiment: "libero_sim" },
});

const { hparams } = await vlaSetEmbodiment({ modelId, embodiment: "real_droid" });
console.log(hparams.selectedEmbodimentTag, hparams.selectedEmbodimentCatId, hparams.numCameras);

// By category ID, overriding the camera count.
await vlaSetEmbodiment({ modelId, embodiment: { catId: 24, numCameras: 2 } });
```
