Reads the CPU, memory, and GPU capabilities of the machine the SDK worker runs on, and, on request, a sample of their current usage. Every value is a [`ResourceMetric`](#resourcemetric) that says whether the platform could report it. The result is diagnostic: it does not reserve memory or predict whether a model fits. To check fit, use [`assessModelFit()`](/sdk/reference/api/assessModelFit).

## Signature

```ts
function getSystemResources(input?: GetSystemResourcesInput): Promise<SystemResources>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `input` | What to read. | [`GetSystemResourcesInput`](#getsystemresourcesinput) | No |

### `GetSystemResourcesInput`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `sample` | Also take a sample of current usage. Sampling performs fresh usage queries, so request it only when current usage is needed. | `boolean` | No | `false` |

## Returns

A promise that resolves with a `SystemResources`:

| Field | Description | Type |
| --- | --- | --- |
| `capabilities` | What the machine has. | [`SystemResourceCapabilities`](#systemresourcecapabilities) |
| `sample` | Current usage. Present only when `sample` is `true`. | [`SystemResourceSample`](#systemresourcesample)` \| undefined` |

#### `ResourceMetric`

Every value is wrapped in a metric, discriminated by `status`:

| `status` | Other fields | Meaning |
| --- | --- | --- |
| `"supported"` | `value: T`, `provenance: { source: string; scope?: ResourceScope }` | The value was read. `provenance` names where it came from; `scope` is one of `"system"`, `"process"`, `"device"`, `"budget"`, `"shared-system"`. |
| `"unavailable"` | `reason?: string` | The platform does not report this value. |
| `"unverified"` | `reason?: string` | The value could not be verified. |
| `"failed"` | `reason?: string` | Reading the value failed, such as when the resource collector is not initialized. |

#### `SystemResourceCapabilities`

| Field | Description | Type |
| --- | --- | --- |
| `cpu` | CPU capabilities. | `ResourceMetric<`[`CPUResourceCapabilities`](#cpuresourcecapabilities)`>` |
| `memory.totalBytes` | Total system memory, in bytes. | `ResourceMetric<number>` |
| `gpus` | One entry per GPU. | `ResourceMetric<`[`GPUResourceCapabilities`](#gpuresourcecapabilities)`[]>` |

#### `CPUResourceCapabilities`

Each field is a `ResourceMetric` of the type shown.

| Field | Description | Type |
| --- | --- | --- |
| `name` | CPU name. | `string` |
| `vendor` | CPU vendor. | `string` |
| `architecture` | CPU architecture, as a native enumeration code. | `number` |
| `physicalCores` | Number of physical cores. | `number` |
| `logicalCores` | Number of logical cores. | `number` |
| `performanceCores` | Number of performance cores. | `number` |
| `efficiencyCores` | Number of efficiency cores. | `number` |
| `frequencyHz` | CPU frequency, in hertz. | `number` |
| `cacheLineBytes` | Cache line size, in bytes. | `number` |

#### `GPUResourceCapabilities`

| Field | Description | Type |
| --- | --- | --- |
| `id` | GPU ID, used to match a GPU's sample to its capabilities. | `string` |
| `name` | GPU name. | `ResourceMetric<string>` |
| `vendor` | GPU vendor. | `ResourceMetric<string>` |
| `type` | GPU type, as a native enumeration code. | `ResourceMetric<number>` |
| `driverName` | Driver name. | `ResourceMetric<string>` |
| `driverVersion` | Driver version. | `ResourceMetric<string>` |
| `drivers` | Which graphics APIs the GPU supports, one `ResourceMetric<boolean>` per API: `vulkan`, `opencl`, `opengl`, `webgpu`, `metal`, `direct3d11`, `direct3d12`, `cuda`, `levelZero`, `rocm`. | `Record<GraphicsDriver, ResourceMetric<boolean>>` |
| `unifiedMemory` | Whether the GPU shares the host's memory. | `ResourceMetric<boolean>` |
| `memoryTotalBytes` | Total GPU memory, in bytes. | `ResourceMetric<number>` |

#### `SystemResourceSample`

| Field | Description | Type |
| --- | --- | --- |
| `sampledAt` | When the sample was taken, in milliseconds since the Unix epoch. | `number` |
| `cpu` | CPU utilization, from `0` to `1`. | `ResourceMetric<number>` |
| `memory.usedBytes` | System memory in use, in bytes. | `ResourceMetric<number>` |
| `memory.totalBytes` | Total system memory, in bytes. | `ResourceMetric<number>` |
| `memory.processUsedBytes` | This process's resident footprint (RSS), in bytes. Process-scoped, unlike `usedBytes`. | `ResourceMetric<number>` |
| `memory.processAvailableBytes` | How much more this process may allocate before the OS intervenes, in bytes. On iOS this is the limit jetsam enforces. Unavailable where no per-process limit is exposed. | `ResourceMetric<number>` |
| `gpus` | One sample per GPU. | `ResourceMetric<`[`GPUResourceSample`](#gpuresourcesample)`[]>` |

#### `GPUResourceSample`

Each field except `id` is a `ResourceMetric` of the type shown.

| Field | Description | Type |
| --- | --- | --- |
| `id` | GPU ID, matching `GPUResourceCapabilities.id`. | `string` |
| `compute` | Compute utilization, from `0` to `1`. | `number` |
| `encode` | Encoder utilization, from `0` to `1`. | `number` |
| `decode` | Decoder utilization, from `0` to `1`. | `number` |
| `memoryUsedBytes` | GPU memory in use, in bytes. | `number` |
| `memoryTotalBytes` | Total GPU memory, in bytes. | `number` |
| `powerWatts` | Power draw, in watts. | `number` |
| `temperatureCelsius` | Temperature, in degrees Celsius. | `number` |

## Throws

| Error | When |
| --- | --- |
| `InvalidResponseError` | The worker answers with an unexpected response type. |

## Examples

```ts
import { getSystemResources } from "@qvac/sdk";

const { capabilities, sample } = await getSystemResources({ sample: true });

if (capabilities.memory.totalBytes.status === "supported") {
  console.log("Total memory:", capabilities.memory.totalBytes.value);
}

if (sample && sample.memory.processAvailableBytes.status === "supported") {
  console.log("Process can still allocate:", sample.memory.processAvailableBytes.value);
}

if (capabilities.gpus.status === "supported") {
  for (const gpu of capabilities.gpus.value) {
    const name = gpu.name.status === "supported" ? gpu.name.value : gpu.id;
    console.log(name);
  }
}
```
