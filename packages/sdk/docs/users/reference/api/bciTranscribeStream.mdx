Opens a bidirectional transcription session with a loaded brain–computer interface (BCI) model. You write neural-signal chunks to the session, and the engine decodes a sliding window over the signal and yields transcript text — or segments, with `metadata: true` — as each window is decoded. For a complete recording, use [`bciTranscribe()`](/sdk/reference/api/bciTranscribe). See [BCI](/sdk/ai-capabilities/bci).

## Signature

```ts
function bciTranscribeStream(params: BciTranscribeStreamClientParams & { metadata: true }, options?: RPCOptions): Promise<BciTranscribeStreamMetadataSession>;
function bciTranscribeStream(params: BciTranscribeStreamClientParams, options?: RPCOptions): Promise<BciTranscribeStreamSession>;
```

| Form | `params` | Iteration yields |
| --- | --- | --- |
| Text session | [`BciTranscribeStreamClientParams`](#bcitranscribestreamclientparams) | `string` |
| Segment session | [`BciTranscribeStreamClientParams`](#bcitranscribestreamclientparams) with `metadata: true` | [`TranscribeSegment`](/sdk/reference/api/transcribe#transcribesegment) |

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model and the sliding-window settings. | [`BciTranscribeStreamClientParams`](#bcitranscribestreamclientparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](/sdk/reference/api/transcribe#rpcoptions) | No |

### `BciTranscribeStreamClientParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a loaded BCI model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes | — |
| `metadata` | Yield segment objects instead of text. | `boolean` | No | `false` |
| `windowTimesteps` | Decode window size, in timesteps. Positive integer. | `number` | No | `1500` |
| `hopTimesteps` | How far the window advances between decodes, in timesteps. Positive integer, less than `windowTimesteps`. | `number` | No | `500` |
| `emit` | `"delta"` yields only the newly decoded tail of each window; `"full"` yields the full running transcript on each update. | `"delta" \| "full"` | No | `"delta"` |

## Returns

A promise that resolves with the session once the duplex connection is open.

### Session

| Field | Description | Type |
| --- | --- | --- |
| `requestId` | ID of this session. Pass it to [`cancel({ requestId })`](/sdk/reference/api/cancel) to stop it without cancelling other work on the model. | `string` |
| `write(neuralChunk)` | Sends a chunk of the neural signal. The first bytes written must be the 8-byte header — `timesteps` and `channels`, each a little-endian `uint32` — followed by row-major `float32` features. In a stream, `timesteps` is ignored and `channels` must be non-zero. | `(neuralChunk: Uint8Array) => void` |
| `end()` | Closes the signal input. The engine finishes decoding and sends its terminal frame, which ends iteration. | `() => void` |
| `destroy()` | Tears down both directions of the connection at once. | `() => void` |
| `[Symbol.asyncIterator]()` | Iterates the output: non-empty text chunks (`BciTranscribeStreamSession`) or segments (`BciTranscribeStreamMetadataSession`). A session can be iterated once. | `AsyncIterator<string>` or `AsyncIterator<TranscribeSegment>` |

Iteration ends on the engine's terminal frame, or when the connection closes. Lines the client cannot parse are logged and skipped. The session exposes no run statistics: the engine reports none for a stream.

With `metadata: true` and `emit: "delta"`, each segment also carries `windowStartTimestep`, the absolute index of the 20 ms timestep where its decode window began. The segment's own `startMs` and `endMs` are window-local; add `windowStartTimestep * 20` to place them on the stream timeline. The field is not part of the declared `TranscribeSegment` type.

## Throws

| Error | When |
| --- | --- |
| `TranscriptionFailedError` | A session is iterated a second time. |
| `TranscriptionFailedError` | The server sends an error frame during iteration. |
| `QvacErrorBase` | The session cannot be opened; the message carries the details. |

## Examples

```ts
const session = await bciTranscribeStream({ modelId, emit: "delta" });

// Drain the session while writing, so decoding keeps up with the input.
const reader = (async () => {
  let transcript = "";
  for await (const text of session) transcript += text;
  return transcript;
})();

const data = readFileSync("/path/to/signal.bin");
for (let offset = 0; offset < data.length; offset += 64 * 1024) {
  session.write(data.subarray(offset, offset + 64 * 1024));
}
session.end();

console.log(await reader);
```
