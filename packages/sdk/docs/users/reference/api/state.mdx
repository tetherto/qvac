Returns the SDK runtime's current lifecycle state. It is the source of truth for whether the runtime accepts operations, so app logic can branch on it instead of tracking [`suspend()`](/sdk/reference/api/suspend) and [`resume()`](/sdk/reference/api/resume) calls itself. The lifecycle gate never blocks `state()`. See [Runtime lifecycle](/sdk/runtime/lifecycle).

## Signature

```ts
function state(): Promise<LifecycleState>;
```

## Returns

A promise that resolves with a `LifecycleState`:

| Value | Meaning |
| --- | --- |
| `"active"` | All SDK operations are accepted. |
| `"suspending"` | `suspend()` is in progress. Operations other than `suspend()`, `resume()`, and `state()` are blocked. |
| `"suspended"` | The runtime is paused. Only `suspend()`, `resume()`, and `state()` are accepted. |
| `"resuming"` | `resume()` is in progress. Operations other than `suspend()`, `resume()`, and `state()` are still blocked. |

A blocked operation throws `LIFECYCLE_OPERATION_BLOCKED`.

## Throws

| Error | When |
| --- | --- |
| `InvalidResponseError` | The worker answers with an unexpected response type. |

## Examples

```ts
import { resume, state } from "@qvac/sdk";

// Branch on lifecycle state before issuing work.
if ((await state()) !== "active") {
  await resume();
}
```
