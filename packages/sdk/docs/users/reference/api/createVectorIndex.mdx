Creates an empty vector index in the SDK worker's memory and resolves with a [`VectorIndex`](#vectorindex) handle. The index holds vectors only, under IDs you assign: keep the documents in any store you like and map result IDs back to them. Vectors are searched by dot product, so L2-normalize vectors and queries when you want cosine similarity. Save the index with `write()` and reopen it with [`loadVectorIndex()`](/sdk/reference/api/loadVectorIndex). See [RAG](/sdk/ai-capabilities/rag).

## Signature

```ts
function createVectorIndex(params: CreateVectorIndexParams, options?: RPCOptions): Promise<VectorIndex>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | Dimension and storage mode of the index. | [`CreateVectorIndexParams`](#createvectorindexparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `CreateVectorIndexParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `dim` | Dimension every added vector and query must have. A positive integer; the TurboVec modes also require it to be divisible by 8 and no greater than 1024. | `number` | Yes | — |
| `storage` | How vectors are stored. | [`VectorIndexStorage`](#vectorindexstorage) | No | `"turbovec-q4"` |

#### `VectorIndexStorage`

Pass the value, or the `VectorIndexStorage` constant exported by `@qvac/sdk`.

| Constant | Value | Dimension |
| --- | --- | --- |
| `VectorIndexStorage.TURBOVEC_Q4` | `"turbovec-q4"` | Divisible by 8, at most 1024 |
| `VectorIndexStorage.TURBOVEC_Q2` | `"turbovec-q2"` — half the memory of `turbovec-q4` | Divisible by 8, at most 1024 |
| `VectorIndexStorage.F32` | `"f32"` | Any |
| `VectorIndexStorage.Q8` | `"q8"` | Any |
| `VectorIndexStorage.Q4` | `"q4"` | Any |

The `turbovec-*` modes are the quantized TurboVec formats; `f32`, `q8`, and `q4` are generic stores of the same addon.

## Returns

A promise that resolves with a `VectorIndex` handle to the new, empty index.

### `VectorIndex`

The index lives in worker memory until `dispose()` (or `await using`) or worker shutdown. After a worker crash or restart, every method rejects with `VECTOR_INDEX_NOT_FOUND`; recover by creating a new index or loading a snapshot written earlier with `write()`.

| Property | Description | Type |
| --- | --- | --- |
| `indexId` | Opaque ID of the worker-side index. Useful in logs; no call needs it. | `string` |
| `dim` | Dimension every added vector and query must match. | `number` |
| `storage` | Storage mode. After `loadVectorIndex()` it is derived from the snapshot's bit width, so 4-bit snapshots (`q4` or `turbovec-q4`) report `undefined`. | [`VectorIndexStorage`](#vectorindexstorage) `\| undefined` |
| `length` | Number of live entries as of the last call that changed or reported it. | `number` |

| Method | Description | Returns |
| --- | --- | --- |
| `add(params: ` [`VectorIndexAddParams`](#vectorindexaddparams)`, options?: RPCOptions)` | Adds vectors under the given IDs in one atomic batch. Rejects duplicate IDs, the reserved ID 2^64 − 1, an `ids` and `vectors` of different lengths, and rows whose length differs from `dim`. | `Promise<{ length: number }>` — the number of live entries after the add |
| `search(params: { query: number[]; k: number }, options?: RPCOptions)` | Finds the `k` nearest entries to one query. | `Promise<` [`VectorIndexHit`](#vectorindexhit)`[]>` |
| `search(params: { queries: number[][]; k: number }, options?: RPCOptions)` | Finds the `k` nearest entries to each query row. | `Promise<` [`VectorIndexHit`](#vectorindexhit)`[][]>` — one hit list per row |
| `remove(params: { ids: VectorId[] }, options?: RPCOptions)` | Removes IDs, in order. A failure leaves the IDs before it removed, and `length` as of the last successful call. | `Promise<boolean[]>` — per ID, whether it was present |
| `contains(params: { ids: VectorId[] }, options?: RPCOptions)` | Reports, per ID, whether the index holds it. | `Promise<boolean[]>` |
| `write(params: { path: string }, options?: RPCOptions)` | Writes a checksummed snapshot to `path`, replacing any existing file and creating missing directories. An absolute path is used as given; a relative path resolves under the QVAC data directory. | `Promise<{ path: string }>` — the resolved absolute path |
| `dispose(options?: RPCOptions)` | Releases the worker memory. Safe to call more than once; a failed dispose can be retried. | `Promise<void>` |
| `[Symbol.asyncDispose]()` | Calls `dispose()`, for `await using`. Absent on runtimes without explicit resource management. | `Promise<void>` |

Search hits are ordered by descending score, then ascending ID. Fewer than `k` come back when the index holds fewer entries. `k` must be a positive integer, and every query row must have `dim` components.

#### `VectorIndexAddParams`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `ids` | One ID per vector. At least one. | [`VectorId`](#vectorid)`[]` | Yes |
| `vectors` | The vectors, one row per ID, each with `dim` components. | `number[][]` | Yes |

#### `VectorId`

An ID is an unsigned 64-bit integer, passed as a decimal string, a non-negative safe integer, or a `bigint` (sent as its decimal string). `18446744073709551615` (2^64 − 1) is reserved. Results always return IDs as decimal strings, so values above 2^53 survive.

`string | number | bigint`

#### `VectorIndexHit`

| Field | Description | Type |
| --- | --- | --- |
| `id` | ID of the entry, as a decimal string. | `string` |
| `score` | Dot-product similarity to the query. Higher is closer. | `number` |

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `dim` is not a positive integer, or `storage` is not a known mode. |
| `VECTOR_INDEX_PROVIDER_UNAVAILABLE` | No registered plugin exposes a vector index provider, such as the built-in `llamacpp-embedding` plugin. |
| `VECTOR_INDEX_FAILED` | The native index rejects the dimension or storage mode. |

The handle's methods throw `RequestValidationFailedError` for a row whose length differs from `dim` (before anything is sent), `VectorIndexNotFoundError` (`VECTOR_INDEX_NOT_FOUND`) when the index is gone, `VectorIndexInvalidVectorsError` (`VECTOR_INDEX_INVALID_VECTORS`) when `ids` and `vectors` differ in length, and `VectorIndexFailedError` (`VECTOR_INDEX_FAILED`) when the native index rejects an operation.

## Examples

```ts
const documents = new Map([
  ["1", "Titan has lakes and rain of liquid methane."],
  ["2", "Solar panels turn sunlight into electricity."],
]);

const { embedding: vectors } = await embed({ modelId, text: [...documents.values()] });

const index = await createVectorIndex({ dim: vectors[0].length });
await index.add({ ids: [...documents.keys()], vectors });

const { embedding: query } = await embed({ modelId, text: "Which moon has methane rain?" });
const hits = await index.search({ query, k: 1 });
console.log(documents.get(hits[0].id));

// Save a snapshot, then release the memory.
const { path } = await index.write({ path: "indexes/notes.qvi" });
await index.dispose();

// Or let the handle dispose itself.
{
  await using scratch = await createVectorIndex({ dim: 1024, storage: VectorIndexStorage.TURBOVEC_Q2 });
  await scratch.add({ ids: [1n, 2n], vectors: [vecA, vecB] });
}
```
