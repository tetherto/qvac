Turns text, images, or audio into an embedding vector with a loaded embedding model, for semantic search, clustering, and retrieval. Pass `input` for one text, one ordered text and media input, or one image, or `text` for one string. A `llamacpp-embedding` (`embeddings`) model takes text and media; media needs a model loaded with a projector. A `ggml-image-embedding` model, such as MegaLoc, takes images. To embed several inputs in one call, use [`embedBatch()`](/sdk/reference/api/embedBatch). See [Text embeddings](/sdk/ai-capabilities/text-embeddings), [Multimodal embeddings](/sdk/ai-capabilities/multimodal-embeddings), and [Image embeddings](/sdk/ai-capabilities/image-embeddings).

## Signature

```ts
function embed(params: { modelId: string; input: EmbedClientInput; text?: never; inputs?: never }, options?: RPCOptions): Promise<{ embedding: number[]; stats?: EmbedStats }> & { requestId: string };
function embed(params: { modelId: string; text: string; inputs?: never; input?: never }, options?: RPCOptions): Promise<{ embedding: number[]; stats?: EmbedStats }> & { requestId: string };
/** @deprecated Use embedBatch({ modelId, inputs }). */
function embed(params: { modelId: string; text: string[]; inputs?: never; input?: never }, options?: RPCOptions): Promise<{ embedding: number[][]; stats?: EmbedStats }> & { requestId: string };
/** @deprecated Use embedBatch({ modelId, inputs }). */
function embed(params: { modelId: string; inputs: EmbedInput[]; text?: never; input?: never }, options?: RPCOptions): Promise<{ embedding: number[][]; stats?: EmbedStats }> & { requestId: string };
function embed(params: EmbedClientParams, options?: RPCOptions): Promise<{ embedding: number[] | number[][]; stats?: EmbedStats }> & { requestId: string };
```

| Form | `params` | `embedding` |
| --- | --- | --- |
| Single input | `input: EmbedClientInput` | One vector, `number[]` |
| Single text | `text: string` | One vector, `number[]` |
| Legacy text batch (deprecated) | `text: string[]` | One vector per string, `number[][]` |
| Legacy inputs batch (deprecated) | `inputs: EmbedInput[]` | One vector per input, `number[][]`, even for a single input |

The two legacy forms will be removed in the next major version, and the SDK logs a deprecation warning when they are used. Use [`embedBatch()`](/sdk/reference/api/embedBatch) instead; it also takes images.

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model and what to embed. | [`EmbedClientParams`](#embedclientparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `EmbedClientParams`

Pass exactly one of `input`, `text`, and `inputs`.

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelId` | ID of a loaded embedding model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes |
| `input` | One input the model supports: a text, ordered text and media parts, or an image. Returns one vector. | [`EmbedClientInput`](#embedclientinput) | One of `input`, `text`, `inputs` |
| `text` | Text to embed. A string returns one vector. An array returns one vector per string, and is deprecated. Strings and the array must not be empty. | `string \| string[]` | One of `input`, `text`, `inputs` |
| `inputs` | Deprecated. Items to embed, one vector each. At least one. Takes text and ordered text and media parts, not images. Media parts require a model loaded with `modelConfig.projectionModelSrc`. | [`EmbedInput`](#embedinput)`[]` | One of `input`, `text`, `inputs` |

#### `EmbedClientInput`

An [`EmbedInput`](#embedinput), or an [`EmbedImageInput`](#embedimageinput).

#### `EmbedInput`

A non-empty string, or a non-empty array of parts in order: strings and `{ media: EmbedMediaSource }` objects. An array made only of empty strings is rejected. A mixed input's text and media tokens must fit together in the model's `batchSize` and `ctxSize`.

#### `EmbedMediaSource`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `type` | `"base64"` for encoded bytes, `"filePath"` for a path. | `"base64" \| "filePath"` | Yes |
| `value` | The base64-encoded image or audio bytes, or a file path the inference worker can read. Non-empty. | `string` | Yes |

Images: JPEG, PNG, and BMP. Audio: WAV, MP3, and FLAC. WebP, AAC/M4A, Ogg, and video are not supported.

#### `EmbedImageInput`

An image for a `ggml-image-embedding` model. A `llamacpp-embedding` model rejects it.

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `image` | JPEG or PNG bytes, or packed RGB bytes. Not empty. For packed RGB, the length must equal `width` × `height` × `channels`. | `Uint8Array` | Yes |
| `width` | Packed RGB width in pixels, from `1` to `16384`. Pass `width`, `height`, and `channels` together, or none of them for JPEG or PNG. | `number` | No |
| `height` | Packed RGB height in pixels, from `1` to `16384`. | `number` | No |
| `channels` | Packed RGB channel count. Must be `3`. | `3` | No |

#### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. See [Profiler](/sdk/runtime/profiler). | `PerCallProfiling` | No |
| `sessionId` | Caller session to run this call as. A [session handle](/sdk/reference/api/openSession) sets it and replaces any value you pass; when omitted, the call runs as the runtime owner. Not empty. | `string` | No |

## Returns

A promise that resolves with an object. The promise also carries `requestId`, available synchronously, so the call can be cancelled with [`cancel({ requestId })`](/sdk/reference/api/cancel) before it resolves.

| Field | Description | Type |
| --- | --- | --- |
| `embedding` | The vector or vectors, in input order. See the [forms](#signature) for the shape. | `number[] \| number[][]` |
| `stats` | Performance figures, when the model reported them. | [`EmbedStats`](#embedstats) |

### `EmbedStats`

Every field is optional. Each model fills only its own fields.

| Field | Description | Type |
| --- | --- | --- |
| `totalTime` | Total embedding time, in milliseconds. For a MegaLoc batch, the sum of native times. | `number` |
| `tokensPerSecond` | Tokens processed per second. llama.cpp embedding models only. | `number` |
| `totalTokens` | Total tokens processed. llama.cpp embedding models only. | `number` |
| `backendDevice` | Device that ran inference. llama.cpp embedding models only. | `"cpu" \| "gpu"` |
| `contextSize` | Context size, in tokens. llama.cpp embedding models only. | `number` |
| `backendId` | Native backend ID: CPU `0`, Metal `1`, CUDA `2`, Vulkan `3`, OpenCL `4`, other `99`. MegaLoc only. | `number` |
| `cpuFallbackNodes` | Number of graph nodes scheduled on CPU fallback. MegaLoc only. | `number` |
| `weightBytes` | Allocated model weight bytes. MegaLoc only. | `number` |

## Throws

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` is invalid, checked on the client before the request is sent. |
| `InvalidResponseError` | The worker answers with an unexpected response type or a malformed result. |
| `EMBED_FAILED` | The model cannot embed the input: an image passed to a `llamacpp-embedding` model, or, for MegaLoc, text or an input other than one image or one media part. |
| `QvacErrorBase` | Validation or embedding fails; the message carries the details. |

An error written as a code, such as `EMBED_FAILED`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

## Examples

```ts
import fs from "node:fs";
import { embed, embedBatch, loadModel, GTE_LARGE_FP16, EMBEDDINGGEMMA_2_Q8_0, MMPROJ_EMBEDDINGGEMMA_2_Q8_0, MEGALOC_F16 } from "@qvac/sdk";

const modelId = await loadModel({ modelSrc: GTE_LARGE_FP16, modelType: "embeddings" });

// One text, one vector.
const { embedding } = await embed({ modelId, text: "Hello, world!" });

// Several texts, one vector each.
const { embedding: vectors } = await embedBatch({ modelId, inputs: ["first document", "second document"] });

// Text and an image in one ordered input, in a shared vector space.
const multimodalId = await loadModel({
  modelSrc: EMBEDDINGGEMMA_2_Q8_0,
  modelType: "llamacpp-embedding",
  modelConfig: { projectionModelSrc: MMPROJ_EMBEDDINGGEMMA_2_Q8_0, ctxSize: 2048, batchSize: 2048 },
});

const { embedding: document } = await embed({
  modelId: multimodalId,
  input: ["title: none | text: ", { media: { type: "filePath", value: "/home/user/scan.jpg" } }],
});

// An image descriptor from MegaLoc.
const megalocId = await loadModel({ modelSrc: MEGALOC_F16 });
const { embedding: descriptor } = await embed({ modelId: megalocId, input: { image: fs.readFileSync("place.jpg") } });
```
