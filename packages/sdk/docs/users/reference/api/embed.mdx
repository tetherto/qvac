Turns text, images, or audio into embedding vectors with a loaded `llamacpp-embedding` (`embeddings`) model, for semantic search, clustering, and retrieval. Pass `text` for text only, or `inputs` for a batch of items that mix text and media; media needs a model loaded with a projector. See [Text embeddings](/sdk/ai-capabilities/text-embeddings) and [Multimodal embeddings](/sdk/ai-capabilities/multimodal-embeddings).

## Signature

```ts
function embed(params: { modelId: string; text: string; inputs?: never }, options?: RPCOptions): Promise<{ embedding: number[]; stats?: EmbedStats }> & { requestId: string };
function embed(params: { modelId: string; text: string[]; inputs?: never }, options?: RPCOptions): Promise<{ embedding: number[][]; stats?: EmbedStats }> & { requestId: string };
function embed(params: { modelId: string; inputs: EmbedInput[]; text?: never }, options?: RPCOptions): Promise<{ embedding: number[][]; stats?: EmbedStats }> & { requestId: string };
function embed(params: EmbedParams, options?: RPCOptions): Promise<{ embedding: number[] | number[][]; stats?: EmbedStats }> & { requestId: string };
```

| Form | `params` | `embedding` |
| --- | --- | --- |
| Single text | `text: string` | One vector, `number[]` |
| Multiple texts | `text: string[]` | One vector per string, `number[][]` |
| Text and media batch | `inputs: EmbedInput[]` | One vector per input, `number[][]`, even for a single input |

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model and what to embed. | [`EmbedParams`](#embedparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `EmbedParams`

Pass exactly one of `text` and `inputs`.

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelId` | ID of a loaded embedding model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes |
| `text` | Text to embed. A string returns one vector; an array returns one vector per string. Strings and the array must not be empty. | `string \| string[]` | One of `text`, `inputs` |
| `inputs` | Items to embed, one vector each. At least one. Media parts require a model loaded with `modelConfig.projectionModelSrc`. | [`EmbedInput`](#embedinput)`[]` | One of `text`, `inputs` |

#### `EmbedInput`

A non-empty string, or a non-empty array of parts in order: strings and `{ media: EmbedMediaSource }` objects. An array made only of empty strings is rejected. A mixed input's text and media tokens must fit together in the model's `batchSize` and `ctxSize`.

#### `EmbedMediaSource`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `type` | `"base64"` for encoded bytes, `"filePath"` for a path. | `"base64" \| "filePath"` | Yes |
| `value` | The base64-encoded image or audio bytes, or a file path the inference worker can read. Non-empty. | `string` | Yes |

Images: JPEG, PNG, and BMP. Audio: WAV, MP3, and FLAC. WebP, AAC/M4A, Ogg, and video are not supported.

#### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. See [Profiler](/sdk/runtime/profiler). | `PerCallProfiling` | No |

## Returns

A promise that resolves with an object. The promise also carries `requestId`, available synchronously, so the call can be cancelled with [`cancel({ requestId })`](/sdk/reference/api/cancel) before it resolves.

| Field | Description | Type |
| --- | --- | --- |
| `embedding` | The vector or vectors, in input order. See the [forms](#signature) for the shape. | `number[] \| number[][]` |
| `stats` | Performance figures, when the model reported them. | [`EmbedStats`](#embedstats) |

### `EmbedStats`

| Field | Description | Type |
| --- | --- | --- |
| `totalTime` | Total embedding time, in milliseconds. | `number` |
| `tokensPerSecond` | Tokens processed per second. | `number` |
| `totalTokens` | Total tokens processed. | `number` |
| `backendDevice` | Device that ran inference. | `"cpu" \| "gpu"` |
| `contextSize` | Context size, in tokens. | `number` |

Every field is optional.

## Examples

```ts
import { embed, loadModel, GTE_LARGE_FP16, EMBEDDINGGEMMA_2_Q8_0, MMPROJ_EMBEDDINGGEMMA_2_Q8_0 } from "@qvac/sdk";

const modelId = await loadModel({ modelSrc: GTE_LARGE_FP16, modelType: "embeddings" });

// One text, one vector.
const { embedding } = await embed({ modelId, text: "Hello, world!" });

// Several texts, one vector each.
const { embedding: vectors } = await embed({ modelId, text: ["first document", "second document"] });

// Text, an image, and audio in one shared vector space.
const multimodalId = await loadModel({
  modelSrc: EMBEDDINGGEMMA_2_Q8_0,
  modelType: "llamacpp-embedding",
  modelConfig: { projectionModelSrc: MMPROJ_EMBEDDINGGEMMA_2_Q8_0, ctxSize: 2048, batchSize: 2048 },
});

const { embedding: [query, image, audio] } = await embed({
  modelId: multimodalId,
  inputs: [
    "task: search result | query: a newspaper report about the Titanic",
    ["title: none | text: ", { media: { type: "filePath", value: "/home/user/scan.jpg" } }],
    [{ media: { type: "filePath", value: "/home/user/clip.wav" } }],
  ],
});
```
