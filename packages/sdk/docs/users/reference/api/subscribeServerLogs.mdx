Subscribes to every server-side log through one stream: the SDK server's logs, the addon logs of every loaded model, and RAG logs. It calls `handler` once per log line and returns an `unsubscribe` function. You do not need to know any log source IDs ahead of time; each line's `id` names its origin. It is built on [`loggingStream`](/sdk/reference/api/loggingStream) with the reserved `SDK_ALL_LOG_ID` source. See [Logging](/sdk/runtime/logging).

## Signature

```ts
function subscribeServerLogs(handler: ServerLogHandler): () => void;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `handler` | Called with each log line, in order. | [`ServerLogHandler`](#serverloghandler) | Yes |

### `ServerLogHandler`

```ts
type ServerLogHandler = (log: LoggingStreamResponse) => void;
```

#### `LoggingStreamResponse`

| Field | Description | Type |
| --- | --- | --- |
| `type` | Always `"loggingStream"`. | `"loggingStream"` |
| `id` | The line's origin: `SDK_LOG_ID`, a model ID, or a RAG workspace key. | `string` |
| `level` | Log level. | `"error" \| "warn" \| "info" \| "debug" \| "off"` |
| `namespace` | Namespace of the logger that emitted the line. | `string` |
| `message` | The log message. | `string` |
| `timestamp` | Worker time in milliseconds since the Unix epoch. | `number` |

## Returns

An `unsubscribe` function, `() => void`. Call it to stop receiving logs; the worker releases the subscription at once.

The call itself does not throw. When the stream fails or `handler` throws, the error is written to the SDK client logger and the subscription ends.

## Examples

```ts
import { subscribeServerLogs, loadModel, unloadModel, LLAMA_3_2_1B_INST_Q4_0 } from "@qvac/sdk";

const unsubscribe = subscribeServerLogs((log) => {
  console.log(`[${log.id}] [${log.level.toUpperCase()}] [${log.namespace}] ${log.message}`);
});

const modelId = await loadModel({ modelSrc: LLAMA_3_2_1B_INST_Q4_0 });
// ... use the model ...
await unloadModel({ modelId });

unsubscribe();
```
