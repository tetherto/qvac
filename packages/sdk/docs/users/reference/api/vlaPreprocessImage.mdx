Turns an RGB camera frame into a `(3, size, size)` `Float32Array` in CHW layout with values in `[-1, 1]`, the `images` entry [`vla()`](/sdk/reference/api/vla) takes for pixel-input models (`hparams.imageInputMode` `"pixels"`: SmolVLA, π₀.₅). It does not apply to patch-input models such as GR00T. It runs synchronously in your process, needs no native binding, and produces the same tensor as `preprocessImage` in `@qvac/vla-ggml`.

The frame is resized with bilinear sampling, preserving its aspect ratio, to fit in `size` × `size`. The resized content sits at the bottom-right; the padding at the top and left is filled with `-1`.

## Signature

```ts
function vlaPreprocessImage(pixels: PixelsInput, width: number, height: number, opts?: VlaPreprocessImageOptions): Float32Array;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `pixels` | The frame's pixels, three channels, `width * height * 3` values in total. Values are in `[0, 255]` or `[0, 1]`; see `scale`. | `Float32Array \| Uint8Array \| number[]` | Yes |
| `width` | Frame width in pixels, a positive integer. | `number` | Yes |
| `height` | Frame height in pixels, a positive integer. | `number` | Yes |
| `opts` | Output size, input layout, and value range. | [`VlaPreprocessImageOptions`](#vlapreprocessimageoptions) | No |

### `VlaPreprocessImageOptions`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `size` | Side of the square output. Pass `hparams.visionImageSize` from [`vlaHparams()`](/sdk/reference/api/vlaHparams). | `number` | No | `512` (`VLA_DEFAULT_IMAGE_SIZE`, the SmolVLA-LIBERO vision tower size) |
| `layout` | Layout of `pixels`: `"hwc"` interleaves the channels per pixel, `"chw"` stores one plane per channel. | `"hwc" \| "chw"` | No | `"hwc"` |
| `scale` | Value range of `pixels`. `1`: already in `[0, 1]`, no rescale. `1/255`: in `[0, 255]`, rescaled to `[0, 1]`. Any other value, including `"auto"`, detects the range: a `Uint8Array` is treated as `[0, 255]`; for other arrays, a value above `1.001` in the first 256 entries means `[0, 255]`, otherwise `[0, 1]`. | `number \| "auto"` | No | Detected |

## Returns

A `Float32Array` of length `3 * size * size`, in CHW layout, with values in `[-1, 1]`.

## Throws

| Error | When |
| --- | --- |
| `TypeError` | `width` or `height` is not a positive integer. |
| `RangeError` | `pixels.length` is not `width * height * 3`. |

## Examples

```ts
const { hparams } = await vlaHparams({ modelId });
const size = hparams.visionImageSize;

// 8-bit RGB frame, interleaved: range detected as [0, 255].
const front = vlaPreprocessImage(frontRgb, 640, 480, { size });

// Float planes already in [0, 1].
const wrist = vlaPreprocessImage(wristPlanes, 320, 240, { size, layout: "chw", scale: 1 });
```
