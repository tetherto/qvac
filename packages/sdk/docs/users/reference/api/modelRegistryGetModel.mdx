Fetches a single model entry from the QVAC distributed model registry. Both arguments come from an entry returned by [`modelRegistryList()`](/sdk/reference/api/modelRegistryList) or [`modelRegistrySearch()`](/sdk/reference/api/modelRegistrySearch), or from a registry model constant.

## Signature

```ts
function modelRegistryGetModel(registryPath: string, registrySource: string, options?: RPCOptions): Promise<ModelRegistryEntry> & { requestId: string };
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `registryPath` | Registry-relative path to the model. | `string` | Yes |
| `registrySource` | Registry source identifier, such as `hf`. | `string` | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. | [`PerCallProfiling`](#percallprofiling) | No |
| `sessionId` | Caller session to run this call as. A [session handle](/sdk/reference/api/openSession) sets it and replaces any value you pass; when omitted, the call runs as the runtime owner. Not empty. | `string` | No |

#### `PerCallProfiling`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `enabled` | Profile this call only. When omitted, the global profiler configuration applies. | `boolean` | No |
| `includeServerBreakdown` | Include the server-side timing breakdown in the profiling payload. | `boolean` | No |
| `includeResourceGauges` | Attach one local CPU, memory, and GPU resource sample to the operation event. | `boolean` | No |
| `mode` | Detail level: `"summary"` keeps aggregates only, `"verbose"` keeps recent events. | `"summary" \| "verbose"` | No |

## Returns

A promise that resolves with the model's [`ModelRegistryEntry`](#modelregistryentry). The promise also carries `requestId`, available synchronously, so the query can be cancelled with [`cancel({ requestId })`](/sdk/reference/api/cancel) while it waits for another QVAC process to release the registry.

#### `ModelRegistryEntry`

| Field | Description | Type |
| --- | --- | --- |
| `name` | Display name: the model file name without its extension. | `string` |
| `registryPath` | Registry-relative path to the model. | `string` |
| `registrySource` | Registry source identifier, such as `hf`. | `string` |
| `modelId` | The model file name. | `string` |
| `addon` | Capability category the model belongs to. | `"llm" \| "whisper" \| "bci" \| "embeddings" \| "nmt" \| "vad" \| "tts" \| "ocr" \| "parakeet" \| "moss-transcribe" \| "diffusion" \| "audiogen" \| "vla" \| "classification" \| "other"` |
| `engine` | Canonical inference engine identifier, such as `llamacpp-completion`. | `string` |
| `quantization` | Quantization identifier, such as `Q4_K_M`. Empty when the registry has none. | `string` |
| `params` | Parameter-count label, such as `7B`. Empty when the registry has none. | `string` |
| `expectedSize` | Expected total size of the model file, in bytes. | `number` |
| `sha256Checksum` | Expected SHA-256 checksum of the model file. | `string` |
| `blobCoreKey` | Hyperdrive blob core key for the model file. | `string` |
| `blobBlockOffset` | Starting block offset of the model file in the blob. | `number` |
| `blobBlockLength` | Number of blocks occupied by the model file. | `number` |
| `blobByteOffset` | Starting byte offset of the model file within its block. | `number` |

To load an entry, pass `registry://<registrySource>/<registryPath>` as `modelSrc` to [`loadModel()`](/sdk/reference/api/loadModel).

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `ModelRegistryModelNotFoundError` | The registry has no model at this source and path. |
| `QVAC_MODEL_REGISTRY_QUERY_FAILED` | The registry query fails, or the model's engine is not recognized. |
| `ModelRegistryBusyError` | Another QVAC process holds the model registry for longer than the query waits: 60 seconds, or 30 seconds when the holder runs an older SDK, which keeps the registry until it exits. |
| `InferenceCancelledError` | The query is cancelled with [`cancel({ requestId })`](/sdk/reference/api/cancel) while it waits for the registry. |
| `SessionNotOpenError` | `options.sessionId` names a session that is not open. |

## Examples

```ts
import { modelRegistryGetModel, WHISPER_TINY } from "@qvac/sdk";

const model = await modelRegistryGetModel(
  WHISPER_TINY.registryPath,
  WHISPER_TINY.registrySource,
);
console.log(model.name, model.engine, model.sha256Checksum);
```
