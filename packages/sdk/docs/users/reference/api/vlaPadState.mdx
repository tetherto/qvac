Returns a new `Float32Array` of length `targetDim` that holds the values of `state` followed by zeros. Use it to build the `state` input of [`vla()`](/sdk/reference/api/vla) for continuous-state models (SmolVLA, GR00T), with `targetDim` set to `hparams.maxStateDim` from [`vlaHparams()`](/sdk/reference/api/vlaHparams). It runs synchronously in your process and needs no native binding.

## Signature

```ts
function vlaPadState(state: ArrayLike<number>, targetDim?: number): Float32Array;
```

## Parameters

| Parameter | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `state` | The robot state values. Its length must not exceed `targetDim`. | `ArrayLike<number>` | Yes | — |
| `targetDim` | Length of the returned vector, a positive integer. | `number` | No | `32` |

## Returns

A `Float32Array` of length `targetDim`: the values of `state`, then zeros.

## Throws

| Error | When |
| --- | --- |
| `TypeError` | `targetDim` is not a positive integer. |
| `RangeError` | `state` is longer than `targetDim`. |

## Examples

```ts
const { hparams } = await vlaHparams({ modelId });
const state = vlaPadState([0.1, -0.2, 0.3, 0, 0, 1], hparams.maxStateDim);
```
