Queries the QVAC distributed model registry and returns the models that match every filter given. Called with no filters, it returns the same list as [`modelRegistryList()`](/sdk/reference/api/modelRegistryList).

## Signature

```ts
function modelRegistrySearch(params?: ModelRegistrySearchParams): Promise<ModelRegistryEntry[]>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The filters. All filters given must match. | [`ModelRegistrySearchParams`](#modelregistrysearchparams) | No |

### `ModelRegistrySearchParams`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `filter` | Text matched, case-insensitively, as a substring of the entry's `name`, `registryPath`, `addon`, or `engine`. | `string` | No |
| `engine` | Engine the model runs on, such as `llamacpp-completion`. Legacy engine names are resolved to the canonical name before matching. | `string` | No |
| `quantization` | Quantization label, matched partially, such as `q4`. | `string` | No |
| `modelType` | Capability category. Same as `addon`, and takes precedence when both are set. | [`ModelRegistryEntryAddon`](#modelregistryentryaddon) | No |
| `addon` | Capability category the model must belong to. | [`ModelRegistryEntryAddon`](#modelregistryentryaddon) | No |

#### `ModelRegistryEntryAddon`

`"llm" | "whisper" | "bci" | "embeddings" | "nmt" | "vad" | "tts" | "ocr" | "parakeet" | "moss-transcribe" | "diffusion" | "audiogen" | "vla" | "classification" | "other"`

## Returns

A promise that resolves with one [`ModelRegistryEntry`](#modelregistryentry) per matching model. Deprecated models, and models whose engine the SDK does not recognize, are left out.

#### `ModelRegistryEntry`

| Field | Description | Type |
| --- | --- | --- |
| `name` | Display name: the model file name without its extension. | `string` |
| `registryPath` | Registry-relative path to the model. | `string` |
| `registrySource` | Registry source identifier, such as `hf`. | `string` |
| `modelId` | The model file name. | `string` |
| `addon` | Capability category the model belongs to. | `"llm" \| "whisper" \| "bci" \| "embeddings" \| "nmt" \| "vad" \| "tts" \| "ocr" \| "parakeet" \| "moss-transcribe" \| "diffusion" \| "audiogen" \| "vla" \| "classification" \| "other"` |
| `engine` | Canonical inference engine identifier, such as `llamacpp-completion`. | `string` |
| `quantization` | Quantization identifier, such as `Q4_K_M`. Empty when the registry has none. | `string` |
| `params` | Parameter-count label, such as `7B`. Empty when the registry has none. | `string` |
| `expectedSize` | Expected total size of the model file, in bytes. | `number` |
| `sha256Checksum` | Expected SHA-256 checksum of the model file. | `string` |
| `blobCoreKey` | Hyperdrive blob core key for the model file. | `string` |
| `blobBlockOffset` | Starting block offset of the model file in the blob. | `number` |
| `blobBlockLength` | Number of blocks occupied by the model file. | `number` |
| `blobByteOffset` | Starting byte offset of the model file within its block. | `number` |

To load an entry, pass `registry://<registrySource>/<registryPath>` as `modelSrc` to [`loadModel()`](/sdk/reference/api/loadModel).

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `QVAC_MODEL_REGISTRY_QUERY_FAILED` | The registry query fails. |

## Examples

```ts
import { loadModel, modelRegistrySearch, ModelType } from "@qvac/sdk";

// Text search.
const whisperModels = await modelRegistrySearch({ filter: "whisper" });

// Combined filters: Q4 LLMs.
const q4Llms = await modelRegistrySearch({
  engine: ModelType.llamacppCompletion,
  quantization: "q4",
});

// By capability category.
const transcription = await modelRegistrySearch({ addon: "whisper" });

// Load a result.
const [entry] = q4Llms;
if (entry) {
  const modelId = await loadModel({
    modelSrc: `registry://${entry.registrySource}/${entry.registryPath}`,
    modelType: "llamacpp-completion",
  });
}
```
