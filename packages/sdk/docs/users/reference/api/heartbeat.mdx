Sends a heartbeat request to the SDK worker and resolves when the worker answers. Use it to check that the worker is up and responsive.

## Signature

```ts
function heartbeat(): Promise<HeartbeatResponse>;
```

## Returns

A promise that resolves with a `HeartbeatResponse`:

| Field | Description | Type |
| --- | --- | --- |
| `type` | Always `"heartbeat"`. | `"heartbeat"` |
| `number` | A random number from `0` to `100` generated by the worker. It carries no meaning. | `number` |

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `LIFECYCLE_OPERATION_BLOCKED` | The runtime is not `"active"`: it is suspending, suspended, or resuming. See [Runtime lifecycle](/sdk/runtime/lifecycle). |
| `InvalidResponseError` | The worker answers with an unexpected response type. |

## Examples

```ts
import { heartbeat } from "@qvac/sdk";

await heartbeat(); // resolves when the worker answers
```
