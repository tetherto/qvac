Opens a bidirectional synthesis session with a loaded TTS model. You write text fragments — for example the token deltas of a [`completion()`](/sdk/reference/api/completion) stream — and iterate the session for audio frames. By default the engine accumulates the fragments into sentences and synthesizes each sentence as one job. When the whole text is known up front, use [`textToSpeech()`](/sdk/reference/api/textToSpeech). See [Text-to-Speech](/sdk/ai-capabilities/text-to-speech).

MOSS-SoundEffect and MOSS-Speech models do not support this session, and neither does a MOSS-TTSD dialogue model.

## Signature

```ts
function textToSpeechStream(params: TextToSpeechStreamClientParams, options?: RPCOptions): Promise<TextToSpeechStreamSession>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model, sentence accumulation, and voice conditioning. | [`TextToSpeechStreamClientParams`](#texttospeechstreamclientparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](/sdk/reference/api/transcribe#rpcoptions) | No |

### `TextToSpeechStreamClientParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a loaded TTS model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes | — |
| `inputType` | Input type. The type requires it; synthesis always reads the fragments as plain text. Pass `"text"`. | `string` | Yes | — |
| `requestId` | ID for this session, used instead of a generated one. Must be non-empty. | `string` | No | Generated |
| `accumulateSentences` | Buffer the written fragments and synthesize them a sentence at a time, instead of one job per fragment. | `boolean` | No | `true` |
| `sentenceDelimiterPreset` | Which punctuation ends a sentence: `"latin"` (`.` `!` `?` `…`), `"cjk"` (`。` `！` `？` `…`), or `"multilingual"` (both, plus `؟`). | `"latin" \| "cjk" \| "multilingual"` | No | `"multilingual"` |
| `maxBufferScalars` | Maximum graphemes buffered before the text is flushed without a sentence end. Positive. | `number` | No | `300`, or `120` for Korean |
| `flushAfterMs` | Idle time, in milliseconds, after which buffered text is flushed without a sentence end. Positive. | `number` | No | `500` |
| `description` | Parler: free-text voice description. Cannot be combined with `voiceDescription` or with the voice-template fields. | `string` | No | — |
| `voiceDescription` | Alias of `description`, with the same restrictions. | `string` | No | — |
| `voice` | Parler voice-template speaker name. | `string` | No | — |
| `emotion` | Speaking style. Parler accepts every value; CosyVoice3 accepts `"anger"`, `"happy"`, `"neutral"`, and `"sad"`. | [`TtsParlerEmotion`](/sdk/reference/api/textToSpeech#ttsparleremotion) | No | — |
| `pitch` | Parler voice-template pitch descriptor. | `string` | No | — |
| `pace` | Speaking rate. Parler and CosyVoice3. | `"slow" \| "moderate" \| "fast"` | No | — |
| `expressivity` | Parler voice-template expressivity descriptor. | `string` | No | — |
| `noise` | Parler voice-template background-noise descriptor. | `string` | No | — |
| `reverb` | Parler voice-template reverb descriptor. | `string` | No | — |
| `quality` | Parler voice-template audio-quality descriptor. | `string` | No | — |

The conditioning fields follow the same engine rules as on [`textToSpeech()`](/sdk/reference/api/textToSpeech#ttsclientparamsinput).

## Returns

A promise that resolves with the session once the duplex connection is open.

### `TextToSpeechStreamSession`

| Field | Description | Type |
| --- | --- | --- |
| `requestId` | ID of this session. Pass it to [`cancel({ requestId })`](/sdk/reference/api/cancel) to stop synthesis; `destroy()` alone leaves the native job running. | `string` |
| `write(textFragment)` | Sends a text fragment. A string is UTF-8 encoded; a `Uint8Array` is sent as is. Each fragment should be complete UTF-8. | `(textFragment: string \| Uint8Array) => void` |
| `end()` | Closes the text input. The engine synthesizes the remaining text and sends its terminal frame. Calling it again does nothing. | `() => void` |
| `destroy()` | Tears down both directions of the connection at once. | `() => void` |
| `[Symbol.asyncIterator]()` | Iterates the audio frames. A session can be iterated once. | `AsyncIterator<` [`TextToSpeechStreamResponse`](#texttospeechstreamresponse) `>` |

Iteration yields one frame per synthesized chunk and ends after the frame whose `done` is `true`, or when the connection closes. Lines the client cannot parse are logged and skipped.

#### `TextToSpeechStreamResponse`

| Field | Description | Type |
| --- | --- | --- |
| `type` | Always `"textToSpeechStream"`. | `"textToSpeechStream"` |
| `buffer` | Signed 16-bit mono PCM samples of this chunk. Can be empty. | `number[]` |
| `done` | `true` on the terminal frame. | `boolean` |
| `sampleRate` | Sample rate of `buffer`, in Hz. | `number` |
| `chunkIndex` | Index of the sentence chunk. | `number` |
| `sentenceChunk` | Text of the sentence chunk. | `string` |
| `isLast` | Absent in a session: the chunk count is not known up front. | `boolean` |
| `stats` | Runtime statistics, aggregated across the session's sentences. | [`TtsStats`](/sdk/reference/api/textToSpeech#ttsstats) |
| `stopReason` | On the terminal frame: `"cancelled"` when [`cancel()`](/sdk/reference/api/cancel) stopped the session, `"completed"` otherwise. | `"completed" \| "cancelled"` |

## Throws

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` fails validation, for example `description` combined with a voice-template field. The returned promise rejects. |
| `TextToSpeechStreamFailedError` | `write()` is called after `end()` or `destroy()`. Thrown synchronously. |
| `TextToSpeechStreamFailedError` | The session is iterated a second time; the first `next()` rejects. |
| `TextToSpeechStreamFailedError` | The server sends an error during iteration, for example because the model is a MOSS-SoundEffect or MOSS-Speech model. |

## Examples

```ts
// Speak an LLM answer while it is being generated.
const run = completion({
  modelId: llmModelId,
  history: [{ role: "user", content: "What is a constellation?" }],
  stream: true,
});

const session = await textToSpeechStream({ modelId: ttsModelId, inputType: "text" });

const player = (async () => {
  for await (const frame of session) {
    if (frame.buffer.length > 0) await play(frame.buffer, frame.sampleRate);
  }
})();

for await (const token of run.tokenStream) session.write(token);
session.end();
await player;
```
