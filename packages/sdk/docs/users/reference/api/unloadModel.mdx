Unloads a model that [`loadModel()`](/sdk/reference/api/loadModel) loaded and frees its memory. Requests still running on the model are cancelled and drained before it is freed, and the model's log stream to the `logger` passed at load stops. When the last loaded model is unloaded, the call can also close the RPC connection so the process can exit.

## Signature

```ts
function unloadModel(params: UnloadModelParams): Promise<void>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | Which model to unload and how. | [`UnloadModelParams`](#unloadmodelparams) | Yes |

### `UnloadModelParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of the loaded model, as `loadModel()` returned it. | `string` | Yes | — |
| `clearStorage` | Also delete the model's files from disk after unloading: the model file, the directory of a multi-file model in the cache, or the whole directory that holds a [sharded model](/sdk/models/sharded-models)'s shards. | `boolean` | No | `false` |
| `autoClose` | Close the RPC connection when no loaded model remains after this unload. | `boolean` | No | `true`, or `false` on the Bare runtime |

<Callout type="warn">
`clearStorage: true` also deletes a model loaded from a local path outside the cache. For a sharded model, it deletes the directory that holds the shards.
</Callout>

## Returns

A promise that resolves with no value once the model is unloaded.

## Throws

| Error | When |
| --- | --- |
| `ModelUnloadFailedError` | The unload fails, including when no loaded model has this `modelId`. |
| `InvalidResponseError` | The worker answers with an unexpected response type. |

## Examples

```ts
import { loadModel, unloadModel, LLAMA_3_2_1B_INST_Q4_0 } from "@qvac/sdk";

const modelId = await loadModel({ modelSrc: LLAMA_3_2_1B_INST_Q4_0 });

// Free the memory and keep the cached files.
await unloadModel({ modelId });

// Or: free the memory and delete the model's files from disk.
// await unloadModel({ modelId, clearStorage: true });

// Or: keep the RPC connection open after the last model is unloaded.
// await unloadModel({ modelId, autoClose: false });
```
