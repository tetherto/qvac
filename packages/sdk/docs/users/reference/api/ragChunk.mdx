Splits one or more documents into chunks and resolves with them, each under a generated ID. It stores nothing and needs no model. Use it as the first step of the segregated flow — `ragChunk()` → [`embed()`](/sdk/reference/api/embed) → [`ragSaveEmbeddings()`](/sdk/reference/api/ragSaveEmbeddings) — when you want to control embedding yourself. [`ragIngest()`](/sdk/reference/api/ragIngest) runs the same chunking for you. See [RAG](/sdk/ai-capabilities/rag).

## Signature

```ts
function ragChunk(params: RagChunkParams, options?: RPCOptions): Promise<RagDoc[]>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The documents and how to chunk them. | [`RagChunkParams`](#ragchunkparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `RagChunkParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `documents` | Text to chunk: one document, or an array of documents. | `string \| string[]` | Yes | — |
| `chunkOpts` | How to split the text. | [`ChunkOpts`](#chunkopts) | No | See [`ChunkOpts`](#chunkopts) |

#### `ChunkOpts`

| Field | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `chunkSize` | Maximum size of a chunk, counted in the units `splitStrategy` produces. | `number` | No | `256` |
| `chunkOverlap` | Units repeated between consecutive chunks. Must be less than `chunkSize`. | `number` | No | `50` |
| `chunkStrategy` | How units are grouped: `"paragraph"` fits as many whole paragraphs (separated by `\n\n` or by the end of an array element) into a chunk as it can, and splits a paragraph only when it alone exceeds `chunkSize`; `"character"` fits as many units as it can, ignoring paragraphs. | `"character" \| "paragraph"` | No | `"paragraph"` |
| `splitStrategy` | The unit text is split into before grouping. | `"character" \| "word" \| "token" \| "sentence" \| "line"` | No | `"token"` |

## Returns

A promise that resolves with the chunks of all documents, in order, as `RagDoc[]`:

| Field | Description | Type |
| --- | --- | --- |
| `id` | Generated ID of the chunk (a UUID v4). Reuse it as the document `id` in `ragSaveEmbeddings()`. | `string` |
| `content` | Text of the chunk. | `string` |

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` fails validation, for example an unknown `splitStrategy`. |
| `RAG_CHUNK_FAILED` | The worker reports that chunking failed. |

## Examples

```ts
const chunks = await ragChunk({
  documents: [articleA, articleB],
  chunkOpts: { chunkSize: 128, chunkOverlap: 20 },
});

// Embed the chunks, then save them to a workspace.
const { embedding } = await embed({ modelId, text: chunks.map((c) => c.content) });
await ragSaveEmbeddings({
  workspace: "docs",
  documents: chunks.map((chunk, i) => ({
    id: chunk.id,
    content: chunk.content,
    embedding: embedding[i],
    embeddingModelId: modelId,
  })),
});

// Split by sentence instead of by token.
const sentences = await ragChunk({
  documents: longText,
  chunkOpts: { splitStrategy: "sentence", chunkSize: 5, chunkOverlap: 1 },
});
```
