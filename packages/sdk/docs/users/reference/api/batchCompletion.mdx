Submits several prompts, each with its own history and options, to one loaded LLM in a single request so the model decodes them together. It returns a [`BatchCompletionRun`](#returns) synchronously: a merged stream of events tagged with their prompt ID, per-prompt streams, results in prompt order, and batch-level stats. Load the model with `modelConfig.parallel >= 2` to decode prompts concurrently; see [Batch processing](/sdk/ai-capabilities/batch-processing). For one prompt, or prompts that arrive over time, use [`completion()`](/sdk/reference/api/completion).

## Signature

```ts
function batchCompletion(params: BatchCompletionParams): BatchCompletionRun;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model, the prompts, and the options shared by the batch. | [`BatchCompletionParams`](#batchcompletionparams) | Yes |

### `BatchCompletionParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a loaded `llamacpp-completion` (`llm`) model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes | — |
| `prompts` | The prompts to run. At least one. Prompt `id`s must be unique. | [`BatchPrompt`](#batchprompt)`[]` | Yes | — |
| `stream` | `true` delivers events as the model produces them; `false` delivers every event when the batch ends. | `boolean` | No | `true` |
| `captureThinking` | Emit reasoning as `thinkingDelta` events, separate from `contentDelta`. | `boolean` | No | `false` |
| `emitRawDeltas` | Also emit every raw model token as a `rawDelta` event. | `boolean` | No | `false` |
| `toolDialect` | Tool-call output format to parse, for all prompts. Overrides the dialect detected at load. | `"hermes" \| "pythonic" \| "json" \| "harmony" \| "qwen35" \| "gemma4" \| "dsml"` | No | Detected at load |
| `rpcOptions` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No | — |

#### `BatchPrompt`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `id` | Your ID for this prompt, used to tag its events and results. Non-empty. When omitted, the model assigns one; read the assigned IDs from `run.ids`. | `string` | No |
| `history` | The conversation for this prompt, oldest message first, including multimodal `attachments`. Same shape as in `completion()`. | [`HistoryMessage`](/sdk/reference/api/completion#historymessage)`[]` | Yes |
| `generationParams` | Sampling and tool-choice parameters for this prompt. | [`GenerationParams`](/sdk/reference/api/completion#generationparams) | No |
| `responseFormat` | Structured-output constraint for this prompt. A `json_object` or `json_schema` format cannot be combined with `tools` or `mcp`. | [`ResponseFormat`](/sdk/reference/api/completion#responseformat) | No |
| `tools` | Tools for this prompt. Handlers attach only to tool calls this prompt produces. Requires a model loaded with `modelConfig.tools: true`. | [`Tool`](/sdk/reference/api/completion#tool)`[] \| ` [`ToolInput`](/sdk/reference/api/completion#toolinput)`[]` | No |
| `mcp` | MCP clients whose tools are added to this prompt. Their tools are discovered on the client before the batch is submitted. | [`McpClientInput`](/sdk/reference/api/completion#mcpclientinput)`[]` | No |

#### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. See [Profiler](/sdk/runtime/profiler). | `PerCallProfiling` | No |

## Returns

A `BatchCompletionRun`, returned synchronously.

| Field | Description | Type |
| --- | --- | --- |
| `requestId` | ID of the whole batch, available as soon as `batchCompletion()` returns. Pass it to [`cancel({ requestId })`](/sdk/reference/api/cancel) to stop the batch. | `string` |
| `ids` | Resolves with the prompt IDs, in prompt order. | `Promise<string[]>` |
| `events` | Every event of every prompt, interleaved, each tagged with its prompt ID. | `AsyncIterable<{ id: string; event: CompletionEvent }>` |
| `byId(id)` | The events and aggregated result of one prompt. An ID that is not in the batch rejects its `final` with `CompletionFailedError`. | `(id: string) => { events: AsyncIterable<CompletionEvent>; final: Promise<CompletionFinal> }` |
| `results` | Resolves with one `{ id, final }` per prompt, in prompt order. All or nothing: it rejects when the batch fails or any prompt fails or is cancelled. | `Promise<{ id: string; final: CompletionFinal }[]>` |
| `stats` | Resolves with stats aggregated across the whole batch, or `undefined` when the model reported none. Each prompt's `final.stats` is left undefined. | `Promise<`[`CompletionStats`](/sdk/reference/api/completion#completionstats)` \| undefined>` |

`event` has the same shape as in `completion()`: see [`CompletionEvent`](/sdk/reference/api/completion#completionevent). Each prompt's `final` is a [`CompletionFinal`](/sdk/reference/api/completion#completionfinal).

## Throws

`batchCompletion()` returns synchronously and does not throw. Failures reject the promise fields:

| Error | When |
| --- | --- |
| `CompletionFailedError` | A prompt fails mid-stream. Rejects that prompt's `byId(id).final`, `results`, and `stats`. |
| `InferenceCancelledError` | The batch is cancelled. Rejects each cancelled prompt's `byId(id).final` with its partial output in `partial`, `results`, and `stats`. |
| `ContextOverflowError` | The batch does not fit in the model's context window. Rejects every promise; `events` throws it. |
| `InvalidToolSchemaError` | A prompt's `tools` starts with a full `Tool` object and a later entry is not a valid `Tool`. Rejects every promise; `events` throws it. |

## Examples

```ts
import { batchCompletion, loadModel, LLAMA_3_2_1B_INST_Q4_0 } from "@qvac/sdk";

const modelId = await loadModel({
  modelSrc: LLAMA_3_2_1B_INST_Q4_0,
  modelType: "llm",
  modelConfig: { ctx_size: 4096, parallel: 4 },
});

const run = batchCompletion({
  modelId,
  prompts: [
    { id: "cherry", history: [{ role: "user", content: "Reply with only the word CHERRY." }] },
    { id: "banana", history: [{ role: "user", content: "Reply with only the word BANANA." }] },
  ],
});

// Merged stream, tagged by prompt ID.
for await (const { id, event } of run.events) {
  if (event.type === "contentDelta") process.stdout.write(`[${id}] ${event.text}`);
}

// Results in prompt order, and batch-level stats.
for (const { id, final } of await run.results) console.log(id, final.contentText);
const stats = await run.stats;

// One prompt only.
const banana = await run.byId("banana").final;
```
