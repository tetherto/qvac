Stops an RPC server started with [`startRpcServer`](/sdk/reference/api/startRpcServer). It withdraws the server's discovery announcement, if any, then waits for the native server to stop. The wait has no deadline. Unload the models that use the endpoint before you call it. See [RPC servers](/sdk/p2p-capabilities/rpc-servers).

## Signature

```ts
function stopRpcServer(options: StopRpcServerOptions, rpcOptions?: RPCOptions): Promise<void>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `options` | The server to stop. | [`StopRpcServerOptions`](#stoprpcserveroptions) | Yes |
| `rpcOptions` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `StopRpcServerOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `serverId` | ID of the server, as `startRpcServer` returned it. | `string` | Yes |

### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. | [`PerCallProfiling`](#percallprofiling) | No |
| `sessionId` | Caller session to run this call as. Non-empty. When omitted, the call runs as the owner. Only the owner may stop an RPC server ([owner-only operations](/sdk/runtime/sessions#owner-only-operations)): the worker refuses a call that names a session, and a [session handle](/sdk/runtime/sessions) has no method for it. | `string` | No |

#### `PerCallProfiling`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `enabled` | Profile this call only. When omitted, the global profiler configuration applies. | `boolean` | No |
| `includeServerBreakdown` | Include the server-side timing breakdown in the profiling payload. | `boolean` | No |
| `includeResourceGauges` | Attach one local CPU, memory, and GPU resource sample to the operation event. | `boolean` | No |
| `mode` | Detail level: `"summary"` keeps aggregates only, `"verbose"` keeps recent events. | `"summary" \| "verbose"` | No |

## Returns

A promise that resolves with no value once the server has stopped. When the stop fails, the server stays registered, and you can call `stopRpcServer` again to retry.

## Throws

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `serverId` or `rpcOptions.sessionId` is empty. |
| `SessionNotOpenError` | `rpcOptions.sessionId` names a session that is not open in the worker. |
| `OwnerOnlyError` | `rpcOptions.sessionId` names an open session. |
| `RpcServerOperationError` | No running server has this `serverId` in the worker. |
| `RpcServerOperationError` | Withdrawing the announcement or stopping the native server fails. The `details` field carries the reason. |
| `QvacErrorBase` | The worker answers with an invalid response type. |

## Examples

```ts
import { startRpcServer, stopRpcServer } from "@qvac/sdk";

const server = await startRpcServer();

// ... other workers load models on server.url, then unload them ...

await stopRpcServer({ serverId: server.serverId });
```
