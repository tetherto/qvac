description: Builds the world of an ABot-World session from a text prompt and a first-frame image.

Encodes a prompt and a first frame into a scene pack, and makes it the live world of the session that [`worldStep()`](/sdk/reference/api/worldStep) walks. Call it once per world; calling it again on the same session replaces the world and restarts the walk. The model must be loaded with `modelType: "sdcpp-generation"` (`"diffusion"`) and `modelConfig.mode: "world"`. The call returns immediately with a request ID and a `stats` promise that signals completion. See [World simulation](/sdk/ai-capabilities/world-simulation).

## Signature

```ts
function worldCreateScene(params: WorldSceneClientParams & { returnPack: true }): WorldSceneResultWithPack;
function worldCreateScene(params: WorldSceneClientParams & { returnPack?: false | undefined }): WorldSceneResult;
function worldCreateScene(params: WorldSceneClientParams): WorldSceneResult | WorldSceneResultWithPack;
```

`returnPack` selects the result type:

| Form | `returnPack` | Result |
| --- | --- | --- |
| Walk now | omitted or `false` | [`WorldSceneResult`](#worldsceneresult): no scene bytes cross the wire. |
| Keep the world | `true` | [`WorldSceneResultWithPack`](#worldsceneresultwithpack): adds `scene`, the pack bytes. |
| Decided at runtime | a `boolean` variable | The union of both; narrow it with `"scene" in result`. |

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model, the prompt, the first frame, and the scene size. | [`WorldSceneClientParams`](#worldsceneclientparams) | Yes |

### `WorldSceneClientParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a model loaded with `modelConfig.mode: "world"`. | `string` | Yes | — |
| `prompt` | Scene prompt, encoded verbatim by umT5-XXL. Must not be empty. The reference pipeline prefixes prompts with `"\| unknown \| "`. | `string` | Yes | — |
| `image` | First frame as PNG or JPEG bytes: at most 3 MB, and at most 8192×8192 pixels as declared in its header. It is cover-scaled and center-cropped to `width` × `height`, so a frame larger than the target resolution buys nothing. | `Uint8Array` | Yes | — |
| `width` | Scene width in pixels: a positive multiple of 32, at most 4096. `width * height` must not exceed 2,088,960 pixels (1920×1088). | `number` | No | `832` |
| `height` | Scene height in pixels: a positive multiple of 32, at most 4096. Bounded by the same pixel ceiling as `width`. | `number` | No | `480` |
| `returnPack` | Return the scene pack in `scene`. The pack is 10 MB or more, and the world is live on the session without it. Turn it on to persist a world: save the bytes, then pass the file as `modelConfig.sceneSrc` to a later [`loadModel()`](/sdk/reference/api/loadModel) to walk the same world again. | `boolean` | No | `false` |

## Returns

### `WorldSceneResult`

| Field | Description | Type |
| --- | --- | --- |
| `requestId` | Identifies this scene creation, for [`cancel({ requestId })`](/sdk/reference/api/cancel). Scene creation cannot be interrupted: cancelling stops delivery, but the encode runs to completion. | `string` |
| `stats` | Resolves when the scene is created, with its statistics or `undefined`. The world is live on the session once it resolves. | `Promise<`[`WorldSceneStats`](#worldscenestats)` \| undefined>` |

Await `stats` before unloading the model.

### `WorldSceneResultWithPack`

The fields of [`WorldSceneResult`](#worldsceneresult), plus:

| Field | Description | Type |
| --- | --- | --- |
| `scene` | Resolves with the scene pack bytes. Rejects with `InvalidResponseError` when the worker completes without sending them. | `Promise<Uint8Array>` |

#### `WorldSceneStats`

Every field is optional.

| Field | Description | Type |
| --- | --- | --- |
| `sceneCreateMs` | Wall-clock time to build the scene pack, in milliseconds: loading the prompt and image encoders, encoding both, and writing the pack. | `number` |
| `width` | Scene width in pixels, baked into the pack. | `number` |
| `height` | Scene height in pixels, baked into the pack. | `number` |

## Throws

`RequestValidationFailedError` raised on the client is thrown by `worldCreateScene()` itself, before any request is sent. Every other error rejects `stats` and `scene`.

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | On the client: `prompt` is empty, `width` or `height` is not a positive multiple of 32 within the per-axis and total-pixel ceilings, or `image` exceeds 3 MB. |
| `PluginRequestValidationFailedError` | On the worker, before the session is touched: the first frame's header declares more than 8192×8192 pixels, or cannot be read. The class is not exported from `@qvac/sdk`; match it on the message. |
| `ModelOperationNotSupportedError` | The model was not loaded with `modelConfig.mode: "world"`. |
| `RequestRejectedByPolicyError` | A world job is already running on the model. World refuses rather than queues. |
| `InferenceCancelledError` | A `cancel({ requestId })` is accepted. The encode still runs to completion. |
| `StreamEndedError` | The RPC stream closes without a terminal `done` chunk. |

## Examples

```ts
import {
  loadModel,
  worldCreateScene,
  ABOT_WORLD_0_5B_Q8_0,
  ABOT_WORLD_0_5B_LF_TAEHV_VAE,
  ABOT_WORLD_0_5B_LF_WAN_VAE,
  UMT5_XXL_ENC_Q8_0,
} from "@qvac/sdk";
import fs from "fs";

const modelId = await loadModel({
  modelSrc: ABOT_WORLD_0_5B_Q8_0,
  modelType: "sdcpp-generation",
  modelConfig: {
    mode: "world",
    taehvModelSrc: ABOT_WORLD_0_5B_LF_TAEHV_VAE,
    t5XxlModelSrc: UMT5_XXL_ENC_Q8_0,
    vaeModelSrc: ABOT_WORLD_0_5B_LF_WAN_VAE,
    world: { kvCache: true },
  },
});

// Walk now: no pack crosses the wire.
const { stats } = worldCreateScene({
  modelId,
  prompt: "| unknown | A realistic outdoor world scene with a navigable path.",
  image: new Uint8Array(fs.readFileSync("first-frame.jpg")),
});
console.log(await stats);

// Keep the world, to walk it again after a reload with modelConfig.sceneSrc.
const creation = worldCreateScene({
  modelId,
  prompt: "| unknown | A realistic outdoor world scene with a navigable path.",
  image: new Uint8Array(fs.readFileSync("first-frame.jpg")),
  width: 448,
  height: 256,
  returnPack: true,
});
fs.writeFileSync("world.safetensors", await creation.scene);
```
