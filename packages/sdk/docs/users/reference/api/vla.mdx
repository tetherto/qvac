Runs a loaded VLA policy (SmolVLA, π₀.₅, or GR00T) on preprocessed camera frames, the robot state, and a tokenized instruction, and resolves with an action chunk: `chunkSize` timesteps of an `actionDim`-dimensional action vector, plus per-stage timings. Size every input from [`vlaHparams()`](/sdk/reference/api/vlaHparams) first; the helpers [`vlaPreprocessImage()`](/sdk/reference/api/vlaPreprocessImage) and [`vlaPadState()`](/sdk/reference/api/vlaPadState) prepare images and state. See [VLA](/sdk/ai-capabilities/vla).

## Signature

```ts
function vla(params: VlaClientRunParams): Promise<VlaClientRunResult>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model and the input tensors. | [`VlaClientRunParams`](#vlaclientrunparams) | Yes |

### `VlaClientRunParams`

`hparams` below is the result of [`vlaHparams()`](/sdk/reference/api/vlaHparams).

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelId` | ID of a model loaded with `modelType: "vla"` (`"ggml-vla"`). | `string` | Yes |
| `images` | One buffer per camera, `hparams.numCameras` in total. For pixel-input models (`hparams.imageInputMode` `"pixels"`: SmolVLA, π₀.₅), each is a CHW plane of length `3 * imgWidth * imgHeight` from `vlaPreprocessImage()`. For patch-input models (`"patches"`: GR00T), each is a pre-patchified buffer of length `hparams.imagePatchElems`. | `Float32Array[]` | Yes |
| `imgWidth` | Width of each preprocessed image, a positive integer equal to `hparams.visionImageSize`. Patch inputs ignore it, but it must still be a positive integer. | `number` | Yes |
| `imgHeight` | Height of each preprocessed image, a positive integer equal to `hparams.visionImageSize`. Patch inputs ignore it, but it must still be a positive integer. | `number` | Yes |
| `state` | Robot state. For continuous-state models (`hparams.stateInputMode` `"continuous"`: SmolVLA, GR00T), length `hparams.maxStateDim`; pad it with `vlaPadState()`. For discrete-state models (`"discrete"`: π₀.₅), the state is tokenized into the prompt and this buffer is ignored; pass `new Float32Array(0)`. | `Float32Array` | Yes |
| `tokens` | The tokenized instruction, of length `hparams.tokenizerMaxLength`. Tokenize it on your side with the model's tokenizer. Must not be empty. | `Int32Array` | Yes |
| `mask` | Token attention mask, matching `tokens`. | `Uint8Array` | Yes |
| `noise` | Noise prior of length `hparams.chunkSize * hparams.maxActionDim`. When omitted, the addon samples its own prior. π₀.₅ and GR00T require it. | `Float32Array` | No |

## Returns

A promise that resolves with a [`VlaClientRunResult`](#vlaclientrunresult).

### `VlaClientRunResult`

| Field | Description | Type |
| --- | --- | --- |
| `actions` | The action chunk, of length `chunkSize * actionDim`. | `Float32Array` |
| `actionDim` | Dimension of each action vector. | `number` |
| `chunkSize` | Number of timesteps in the chunk. | `number` |
| `stats` | Per-stage timings. Absent when the addon reports none. | [`VlaStats`](#vlastats) |

#### `VlaStats`

Every field is optional.

| Field | Description | Type |
| --- | --- | --- |
| `vision_ms` | Vision stage time, in milliseconds. | `number` |
| `prefill_compute_ms` | Prefill compute time, in milliseconds. | `number` |
| `prefill_total_ms` | Total prefill time, in milliseconds. | `number` |
| `smollm2_compute_ms` | Legacy SmolVLA-named alias of `prefill_compute_ms`. | `number` |
| `smollm2_total_ms` | Legacy SmolVLA-named alias of `prefill_total_ms`. | `number` |
| `ode_ms` | ODE stage time, in milliseconds. | `number` |
| `total_ms` | Total inference time, in milliseconds. | `number` |
| `backendDevice` | `0` for the CPU backend, `1` for a GPU backend (CUDA, ROCm, Vulkan, Metal, or OpenCL). | `number` |

## Examples

```ts
import {
  loadModel,
  vla,
  vlaHparams,
  vlaPadState,
  vlaPreprocessImage,
  SMOLVLA_LIBERO_VISION_Q8,
} from "@qvac/sdk";

const modelId = await loadModel({
  modelSrc: SMOLVLA_LIBERO_VISION_Q8,
  modelType: "ggml-vla",
});
const { hparams } = await vlaHparams({ modelId });

// SmolVLA: two pixel-input cameras and a continuous state.
const size = hparams.visionImageSize;
const front = vlaPreprocessImage(frontPixels, frontWidth, frontHeight, { size });
const wrist = vlaPreprocessImage(wristPixels, wristWidth, wristHeight, { size });
const state = vlaPadState(robotState, hparams.maxStateDim);

// Fill tokens and mask with the instruction, tokenized by the model's tokenizer.
const tokens = new Int32Array(hparams.tokenizerMaxLength);
const mask = new Uint8Array(hparams.tokenizerMaxLength);

const { actions, actionDim, chunkSize, stats } = await vla({
  modelId,
  images: [front, wrist],
  imgWidth: size,
  imgHeight: size,
  state,
  tokens,
  mask,
});
console.log(`${chunkSize} steps of dim ${actionDim}`, actions.subarray(0, actionDim));
console.log(stats?.total_ms);
```
