Resumes the SDK runtime after [`suspend()`](/sdk/reference/api/suspend): restores every suspended Hyperswarm and Corestore resource and releases the lifecycle gate, so all SDK operations are accepted again. P2P downloads that stalled during the suspend continue. Call it when the host app returns to the foreground. The call is idempotent and never blocked by the gate. See [Runtime lifecycle](/sdk/runtime/lifecycle).

## Signature

```ts
function resume(): Promise<void>;
```

## Returns

A promise that resolves with no value once the runtime is `"active"`. Called while a `suspend()` is in progress, it waits for the suspend to finish, then resumes.

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `LIFECYCLE_RESUME_FAILED` | One or more resources fail to resume. The runtime stays `"suspended"` and operations remain blocked, so `resume()` can be retried. |
| `InvalidResponseError` | The worker answers with an unexpected response type. |

## Examples

```ts
import { resume, state } from "@qvac/sdk";

// Foreground handler.
await resume();
console.log(await state()); // "active"
```
