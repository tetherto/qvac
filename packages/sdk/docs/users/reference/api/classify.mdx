Runs an image through a loaded `ggml-classification` (`classification`) model and resolves with its labels and confidence scores, sorted by confidence in descending order. The image is either an encoded JPEG or PNG buffer, or raw RGB bytes with their dimensions. See [Image classification](/sdk/ai-capabilities/image-classification).

## Signature

```ts
function classify(params: ClassifyClientParams): Promise<ClassificationResult[]>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model and the image to classify. | [`ClassifyClientParams`](#classifyclientparams) | Yes |

### `ClassifyClientParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a loaded classification model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes | — |
| `image` | The image: an encoded JPEG or PNG buffer, or raw RGB bytes. | `Uint8Array` | Yes | — |
| `topK` | Return only the K most confident classes. Overrides the load-time `modelConfig.topK` for this call. | `number` | No | Load-time `topK`, else all classes |
| `width` | Image width in pixels. Required for raw RGB bytes. | `number` | No | — |
| `height` | Image height in pixels. Required for raw RGB bytes. | `number` | No | — |
| `channels` | Channel count. Must be `3` for raw RGB bytes. | `3` | No | — |

## Returns

A promise that resolves with one `ClassificationResult` per returned class, sorted by confidence in descending order. The label set comes from the model's GGUF metadata.

| Field | Description | Type |
| --- | --- | --- |
| `label` | Class label. | `string` |
| `confidence` | Confidence score for the label. | `number` |

## Examples

```ts
import fs from "node:fs";
import { classify, loadModel, MOBILENETV3_3CLASS_V3_FP16 } from "@qvac/sdk";

const modelId = await loadModel({
  modelSrc: MOBILENETV3_3CLASS_V3_FP16,
  modelType: "ggml-classification",
});

// Encoded JPEG or PNG.
const results = await classify({ modelId, image: fs.readFileSync("photo.jpg") });
for (const { label, confidence } of results) {
  console.log(`${label}: ${(confidence * 100).toFixed(1)}%`);
}

// Raw RGB bytes, top class only.
const [best] = await classify({ modelId, image: rgbBytes, width: 224, height: 224, channels: 3, topK: 1 });
```
