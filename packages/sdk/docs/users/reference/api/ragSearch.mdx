description: Finds the documents in a RAG workspace most similar to a text query.

Embeds a query with a loaded embedding model, searches a built-in RAG workspace, and resolves with the best matches, most relevant first. A workspace that does not exist yields an empty array; an existing one is opened and stays open until [`ragCloseWorkspace()`](/sdk/reference/api/ragCloseWorkspace). Pass the results to [`completion()`](/sdk/reference/api/completion) as context to ground an answer. See [RAG](/sdk/ai-capabilities/rag).

<Callout type="warn">
**Prototype only:** the built-in RAG vector store is not production grade. For production, use an external vector DB, as shown in the [RAG guide](/sdk/ai-capabilities/rag).
</Callout>

## Signature

```ts
function ragSearch(params: RagSearchParams, options?: RPCOptions): Promise<RagSearchResult[]>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The query, the model, and the workspace to search. | [`RagSearchParams`](#ragsearchparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `RagSearchParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of the loaded embedding model that embeds the query, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. Use the model the documents were embedded with. While the workspace stays open, every `ragIngest()` and `ragSearch()` on it must use the model it was first used with. | `string` | Yes | — |
| `query` | Text to search for. Cannot be empty. | `string` | Yes | — |
| `workspace` | Name of the workspace to search. Must name a single child path: no `..`, null bytes, `%00`, or `%2e`. | `string` | No | `"default"` |
| `topK` | Maximum number of results. Must be positive. | `number` | No | `5` |
| `n` | Number of centroid buckets searched for candidates. Must be positive. Applies to HyperDB workspaces; TurboVec workspaces ignore it. | `number` | No | `3` |

### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. | [`PerCallProfiling`](#percallprofiling) | No |

#### `PerCallProfiling`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `enabled` | Profile this call only. When omitted, the global profiler configuration applies. | `boolean` | No |
| `includeServerBreakdown` | Include the server-side timing breakdown in the profiling payload. | `boolean` | No |
| `includeResourceGauges` | Attach one local CPU, memory, and GPU resource sample to the operation event. | `boolean` | No |
| `mode` | Detail level: `"summary"` keeps aggregates only, `"verbose"` keeps recent events. | `"summary" \| "verbose"` | No |

## Returns

A promise that resolves with at most `topK` `RagSearchResult` objects, sorted by descending `score`:

| Field | Description | Type |
| --- | --- | --- |
| `id` | ID of the matching document or chunk. | `string` |
| `content` | Text of the matching document or chunk. | `string` |
| `score` | Relevance: 70% the cosine similarity of the query and document vectors, 30% how well the query's words match the text. Higher is more relevant. | `number` |

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` fails validation, for example an empty `query` or a non-positive `topK`. |
| `RAG_WORKSPACE_MODEL_MISMATCH` | The workspace is open with a different embedding model than `modelId`. |
| `RAG_SEARCH_FAILED` | The worker reports that the search failed. |

## Examples

```ts
const results = await ragSearch({
  modelId,
  workspace: "articles",
  query: "Which moon has methane rain?",
  topK: 3,
});

for (const { score, content } of results) {
  console.log(score.toFixed(3), content);
}

// Ground a completion in the results.
const context = results.map((r) => r.content).join("\n\n");
const run = completion({
  modelId: llmId,
  history: [
    { role: "system", content: `Answer from this context:\n${context}` },
    { role: "user", content: "Which moon has methane rain?" },
  ],
});
console.log(await run.text);
```
