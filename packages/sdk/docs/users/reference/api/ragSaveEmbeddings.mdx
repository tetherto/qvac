Saves pre-embedded documents into a built-in RAG workspace and resolves with one result per document. It opens the workspace, creating it if it does not exist, and leaves it open until [`ragCloseWorkspace()`](/sdk/reference/api/ragCloseWorkspace). Use it as the last step of the segregated flow — [`ragChunk()`](/sdk/reference/api/ragChunk) → [`embed()`](/sdk/reference/api/embed) → `ragSaveEmbeddings()`. See [RAG](/sdk/ai-capabilities/rag).

<Callout type="warn">
**Prototype only:** the built-in RAG vector store is not production grade. For production, use an external vector DB, as shown in the [RAG guide](/sdk/ai-capabilities/rag).
</Callout>

A new workspace stores its vectors in HyperDB, or in a TurboVec index when [`ragTurbovec`](/sdk/configuration#options) is set in the configuration. The choice is fixed for the life of the workspace. The first save also fixes the workspace's embedding model ID and vector dimension; later saves with a different one fail.

Starting `ragIngest()`, `ragSaveEmbeddings()`, or `ragReindex()` on a workspace cancels the one of these already running on that workspace.

## Signature

```ts
function ragSaveEmbeddings(params: RagSaveEmbeddingsParams, options?: RPCOptions): Promise<RagSaveEmbeddingsResult[]> & { requestId: string };
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The documents and the target workspace. | [`RagSaveEmbeddingsParams`](#ragsaveembeddingsparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `RagSaveEmbeddingsParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `documents` | The documents to save. An empty array saves nothing and resolves with `[]`. | [`RagEmbeddedDoc`](#ragembeddeddoc)`[]` | Yes | — |
| `workspace` | Name of the workspace to save into. Must name a single child path: no `..`, null bytes, `%00`, or `%2e`. | `string` | No | `"default"` |
| `modelId` | Not used by this operation. | `string` | No | — |
| `progressInterval` | Number of documents prepared between two `preparing` progress updates. Must be positive. | `number` | No | `10` |
| `onProgress` | Called with each progress update. When set, the call streams its progress instead of resolving in one response. | `(stage: ` [`RagSaveStage`](#ragsavestage)`, current: number, total: number) => void` | No | — |

#### `RagEmbeddedDoc`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `id` | Document ID. [`ragSearch()`](/sdk/reference/api/ragSearch) returns it, and [`ragDeleteEmbeddings()`](/sdk/reference/api/ragDeleteEmbeddings) takes it. | `string` | Yes |
| `content` | Text of the document. A document whose content is already stored, or repeats an earlier document in the call, is rejected as a duplicate. | `string` | Yes |
| `embedding` | The document's vector, such as one returned by `embed()`. All documents in a call must have the same dimension. | `number[]` | Yes |
| `embeddingModelId` | ID of the model that produced `embedding`. All documents in a call must share it. | `string` | Yes |
| `metadata` | Arbitrary data stored with the document. | `Record<string, unknown>` | No |

#### `RagSaveStage`

The `stage` passed to `onProgress`, in order. `current` and `total` count documents.

| Stage | What runs |
| --- | --- |
| `"deduplicating"` | Duplicate documents are set aside. |
| `"preparing"` | Documents are prepared for writing. Reported every `progressInterval` documents. |
| `"writing"` | Documents are written to the workspace, batch by batch. |

## Returns

A promise that resolves with one `RagSaveEmbeddingsResult` per document:

| Field | Description | Type |
| --- | --- | --- |
| `status` | `"fulfilled"` when the document was saved, `"rejected"` when it was not. | `"fulfilled" \| "rejected"` |
| `id` | ID of the saved document. For a document rejected as a duplicate, the ID of the document that already holds the same content. | `string \| undefined` |
| `error` | Why the document was rejected, such as `"Duplicate document found in current batch"`. | `string \| undefined` |

The promise also carries `requestId`, available synchronously, so the save can be cancelled with [`cancel({ requestId })`](/sdk/reference/api/cancel) before it resolves. See [Cancellation](/sdk/runtime/cancellation).

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` fails validation, for example a document without `embeddingModelId` or an invalid `workspace` name. |
| `RAG_SAVE_FAILED` | The worker reports that the save failed. |
| `StreamEndedError` | The progress stream ends without a final result (only with `onProgress`). |

## Examples

```ts
const chunks = await ragChunk({ documents: articles });
const { embedding } = await embed({ modelId, text: chunks.map((c) => c.content) });

const results = await ragSaveEmbeddings({
  workspace: "articles",
  documents: chunks.map((chunk, i) => ({
    id: chunk.id,
    content: chunk.content,
    embedding: embedding[i],
    embeddingModelId: modelId,
    metadata: { source: "blog" },
  })),
  onProgress: (stage, current, total) => console.log(`${stage} ${current}/${total}`),
});

const saved = results.filter((r) => r.status === "fulfilled").length;
console.log(`Saved ${saved}/${results.length}`);
```
