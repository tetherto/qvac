Transcribes a whole audio input — a file path or an in-memory buffer — with a loaded Whisper, Parakeet, or MOSS transcription model. It resolves with the joined transcript, or with the transcript segments when `metadata` is `true`. The returned promise also carries a synchronous `requestId` and a `stats` promise. To feed audio as it arrives, use [`transcribeStream()`](/sdk/reference/api/transcribeStream). See [Transcription](/sdk/ai-capabilities/transcription).

## Signature

```ts
function transcribe(params: TranscribeClientParams & { metadata: true }, options?: RPCOptions): TranscribeCall<TranscribeSegment[]>;
function transcribe(params: TranscribeClientParams, options?: RPCOptions): TranscribeCall<string>;
```

`TranscribeCall<T>` is `Promise<T> & { requestId: string; stats: Promise<TranscribeStats | undefined> }`.

| Form | `params` | Resolves with |
| --- | --- | --- |
| Text | [`TranscribeClientParams`](#transcribeclientparams) | The transcript as one `string`. |
| Segments | [`TranscribeClientParams`](#transcribeclientparams) with `metadata: true` | An array of [`TranscribeSegment`](#transcribesegment). |

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | What to transcribe and how. | [`TranscribeClientParams`](#transcribeclientparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `TranscribeClientParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a loaded transcription model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. | `string` | Yes | — |
| `audioChunk` | The audio. A `string` is a file path read on the server: `.mp3`, `.m4a`, `.ogg`, `.flac`, `.aac`, and `.wav` files are decoded, any other file is read as raw PCM. A `Buffer` is sent as raw PCM bytes, unchanged. Raw PCM is read in the model's audio format: the Whisper `audio_format` (`"s16le"` when unset), `"s16le"` for the other engines. | `string \| Buffer` | Yes | — |
| `prompt` | Initial Whisper context, or a replacement MOSS transcription instruction. MOSS prompts cannot be combined with `hotwords`. Parakeet ignores it. | `string` | No | — |
| `metadata` | Resolve with segments, with timing and engine-specific detail, instead of joined text. Supported by Whisper, Parakeet, and MOSS models. | `boolean` | No | `false` |
| `hotwords` | MOSS only: names and domain terms. At most 64 entries, each non-empty and at most 64 UTF-8 bytes. | `string[]` | No | — |
| `maxNewTokens` | MOSS only: generated-token limit, an integer from `0` to `2147483647`. `0` uses the model default. | `number` | No | Model default |

### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. | [`PerCallProfiling`](/sdk/reference/api/loadModel#percallprofiling) | No |

## Returns

A promise that resolves when the engine sends its terminal frame. With `metadata: true` it resolves with the segments in arrival order; otherwise with the concatenated text. The promise carries two extra fields:

| Field | Description | Type |
| --- | --- | --- |
| `requestId` | ID of this call, available synchronously. Pass it to [`cancel({ requestId })`](/sdk/reference/api/cancel). A cancel also stops the other in-flight transcriptions on the same model; see [Cancellation](/sdk/runtime/cancellation). | `string` |
| `stats` | Engine statistics from the terminal frame. Resolves `undefined` when the engine reports none, and rejects when the call rejects. | `Promise<` [`TranscribeStats`](#transcribestats) ` \| undefined>` |

### `TranscribeSegment`

| Field | Description | Type |
| --- | --- | --- |
| `text` | Segment text. | `string` |
| `startMs` | Segment start, in milliseconds. | `number` |
| `endMs` | Segment end, in milliseconds. | `number` |
| `append` | Parakeet: the segment continues the previous one instead of replacing it. `false` when the engine does not report it. | `boolean` |
| `id` | Segment ID. `0` when the engine does not report one. | `number` |
| `speakerId` | Zero-based speaker ID for diarized transcription. | `number` |
| `speaker` | MOSS speaker label, such as `S01`. | `string` |
| `speakerSegments` | Offline Sortformer / Nemotron diarization turns, each `{ speakerId, startMs, endMs }` with a zero-based speaker ID and millisecond timestamps. Turns may overlap. | `{ speakerId: number; startMs: number; endMs: number }[]` |
| `isEndOfTurn` | Parakeet (EOU-capable checkpoints): the segment ends on a recognized end-of-utterance boundary. | `boolean` |
| `startsWord` | Parakeet: the segment begins a new SentencePiece word, for joining partial segments without splitting words. | `boolean` |
| `language` | Whisper: language the segment's window was decoded in, as an ISO 639-1 code such as `en`; the detected language under `language: 'auto'`. | `string` |
| `noSpeechProb` | Whisper: probability (0–1) that the segment's window holds no speech, the value `no_speech_thold` is compared against. | `number` |
| `speakerTurnNext` | Whisper, with `tdrz_enable` on a tinydiarize model: a speaker turn follows this segment. | `boolean` |
| `tokens` | Whisper, with `token_timestamps`: decoded text tokens, each `{ text, startMs, endMs, probability }`, with millisecond timing and a decoder probability from 0 to 1. Special tokens are left out. | `{ text: string; startMs: number; endMs: number; probability: number }[]` |

### `TranscribeStats`

Every field is optional; an engine reports only the ones it measures. Times are in milliseconds.

| Field | Description | Type |
| --- | --- | --- |
| `audioDuration` | Duration of the processed audio, in milliseconds. | `number` |
| `realTimeFactor` | Real-time factor of the run. | `number` |
| `tokensPerSecond` | Decoding throughput. | `number` |
| `totalTokens` | Tokens decoded. | `number` |
| `totalSegments` | Segments produced. | `number` |
| `whisperEncodeTime` | Whisper encoder time. | `number` |
| `whisperDecodeTime` | Whisper decoder time. | `number` |
| `encoderTime` | Parakeet encoder time, or the MOSS audio-encoder time. | `number` |
| `decoderTime` | Parakeet decoder time, or the MOSS decode time. | `number` |
| `melSpecTime` | Mel-spectrogram time. | `number` |
| `backendDevice` | Device selected at load: `0` CPU, `1` GPU. | `number` |
| `backendId` | GPU family selected at load: `0` CPU, `1` Metal, `2` CUDA, `3` Vulkan, `4` OpenCL, `99` other. The `ASR_BACKEND_IDS` export maps these names to codes. | `number` |
| `gpuUnsupported` | GPU-unsupported flag reported by the engine at load. | `number` |
| `gpuMemTotalMb` | Total GPU memory, in MB. `-1` when the backend exposes no accounting; absent on Parakeet. | `number` |
| `gpuMemFreeMb` | Free GPU memory, in MB. `-1` when the backend exposes no accounting; absent on Parakeet. | `number` |
| `totalTime` | Total native inference time for the run. | `number` |
| `totalWallMs` | Wall-clock time spent inside the native engine for the run. | `number` |
| `totalSamples` | Audio samples processed across the run. | `number` |
| `processCalls` | Native `process()` invocations made across the run. | `number` |
| `whisperSampleMs` | Whisper and BCI: sampling time. | `number` |
| `whisperBatchdMs` | Whisper and BCI: batched-decode time. | `number` |
| `whisperPromptMs` | Whisper and BCI: prompt-processing time. | `number` |
| `totalTranscriptions` | Parakeet: transcriptions produced across the session. | `number` |
| `modelLoadMs` | Parakeet: model load time. | `number` |
| `totalEncodedFrames` | Parakeet: encoder frames produced across the run. | `number` |
| `encoderOnCoreml` | Parakeet: `1` when a Core ML encoder sidecar loaded, `0` otherwise. | `number` |
| `encoderUsedCoreml` | Parakeet offline ASR: `1` when this run encoded on Core ML, `0` on fallback. | `number` |
| `aoscActive` | Parakeet Sortformer streaming: `1` when the v2.1 AOSC speaker cache was active, `0` otherwise. | `number` |
| `prefillTime` | MOSS: prompt prefill time. | `number` |
| `audioTokens` | MOSS: audio tokens fed to the decoder. | `number` |
| `promptTokens` | MOSS: prompt tokens prefilled before decoding. | `number` |
| `generatedTokens` | MOSS: tokens the decoder generated. | `number` |

## Throws

| Error | When |
| --- | --- |
| `TranscriptionFailedError` | `metadata` is `true` on a model whose engine does not support it. |
| `QvacErrorBase` | Transcription fails on the server; the message carries the details. |

## Examples

```ts
// Joined text from a file, with the run statistics.
const call = transcribe({ modelId, audioChunk: "/path/to/speech.wav" });
const text = await call;
const stats = await call.stats;
console.log(text, stats?.realTimeFactor);

// Segments with timing.
const segments = await transcribe({
  modelId,
  audioChunk: "/path/to/speech.wav",
  metadata: true,
});
for (const segment of segments) {
  console.log(`[${segment.startMs}–${segment.endMs} ms] ${segment.text}`);
}

// MOSS speaker-aware transcription with hotwords.
const mossId = await loadModel({ modelSrc: MOSS_TRANSCRIBE_DIARIZE_Q8_0 });
const turns = await transcribe({
  modelId: mossId,
  audioChunk: "meeting.wav",
  metadata: true,
  hotwords: ["QVAC"],
  maxNewTokens: 2048,
});

// Cancel before it resolves.
const pending = transcribe({ modelId, audioChunk: "/path/to/long.wav" });
await cancel({ requestId: pending.requestId });
```
