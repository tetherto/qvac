Suspends the SDK runtime: pauses every registered Hyperswarm and Corestore resource and engages the lifecycle gate, so operations other than `suspend()`, [`resume()`](/sdk/reference/api/resume), [`state()`](/sdk/reference/api/state), and a session's `close()` fail fast with `LIFECYCLE_OPERATION_BLOCKED` instead of hanging. Call it when the host app moves to the background. The call is idempotent and never blocked by the gate. See [Runtime lifecycle](/sdk/runtime/lifecycle).

Operations already running when `suspend()` is called continue as follows:

| Operation | During suspend | After `resume()` |
| --- | --- | --- |
| P2P / Hyperdrive download | Stalls | Continues |
| HTTP download | Keeps downloading | — |
| Local native inference, such as `completion()` | Runs to completion | — |

## Signature

```ts
function suspend(options?: RPCOptions): Promise<void>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. | [`PerCallProfiling`](#percallprofiling) | No |
| `sessionId` | Caller session to run this call as. `suspend()` is [owner-only](/sdk/runtime/sessions#owner-only-operations): a call that sets it fails, so leave it unset. Not empty. | `string` | No |

#### `PerCallProfiling`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `enabled` | Profile this call only. When omitted, the global profiler configuration applies. | `boolean` | No |
| `includeServerBreakdown` | Include the server-side timing breakdown in the profiling payload. | `boolean` | No |
| `includeResourceGauges` | Attach one local CPU, memory, and GPU resource sample to the operation event. | `boolean` | No |
| `mode` | Detail level: `"summary"` keeps aggregates only, `"verbose"` keeps recent events. | `"summary" \| "verbose"` | No |

## Returns

A promise that resolves with no value once the runtime is `"suspended"`. Called while a `resume()` is in progress, it waits for the resume to finish, then suspends.

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `LIFECYCLE_SUSPEND_FAILED` | One or more resources fail to suspend. The runtime still moves to `"suspended"`, so `resume()` can recover it. |
| `SessionNotOpenError` | `options.sessionId` names a session that is not open. |
| `OwnerOnlyError` | `options.sessionId` names an open session: only the runtime owner can call `suspend()`. See [Owner-only operations](/sdk/runtime/sessions#owner-only-operations). |
| `InvalidResponseError` | The worker answers with an unexpected response type. |

## Examples

```ts
import { state, suspend } from "@qvac/sdk";

// Background handler.
await suspend();
console.log(await state()); // "suspended"
```
