Cancels in-flight work. The targeted form stops one call by the `requestId` that long-running calls expose synchronously, such as `run.requestId` from [`completion()`](/sdk/reference/api/completion) or `op.requestId` on the promise from [`loadModel()`](/sdk/reference/api/loadModel) and [`downloadAsset()`](/sdk/reference/api/downloadAsset). The broad form stops every in-flight request on a model, optionally narrowed by kind, for model unload, app shutdown, or a call that exposes no `requestId`. The cancelled call rejects with `InferenceCancelledError`. Which calls each form covers, and whether it interrupts native work, depends on the operation: see [Cancellation](/sdk/runtime/cancellation).

## Signature

```ts
function cancel(params: CancelClientInput): Promise<void>;
```

The shape of `params` selects what is cancelled:

| Form | `params` | Use it when |
| --- | --- | --- |
| By request | [`{ requestId, clearCache? }`](#by-request) | You hold the `requestId` of the call to stop. Other calls on the same model keep running, except as noted in [Cancellation](/sdk/runtime/cancellation). |
| By request, explicit | `{ operation: "request", requestId, clearCache? }` | Same as above. |
| Broad | [`{ modelId, kind? }`](#broad) | You want to stop every in-flight request on a model, or of one kind on it. |
| Broad, explicit | `{ operation: "broad", modelId, kind? }` | Same as above. |
| Legacy | `{ operation: "inference", modelId }` or `{ operation: "embeddings", modelId }` | Existing code. Same as the broad form with `kind: "completion"` or `kind: "embeddings"`. |

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | What to cancel. One of the forms above. | See [forms](#signature) | Yes |

### By request

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `requestId` | Identifier of the in-flight request to cancel, as exposed by the long-running call. Not empty. | `string` | Yes | — |
| `clearCache` | Download only: delete the partial download file instead of keeping it for resume. Ignored for other kinds of request. | `boolean` | No | — |

A `requestId` that matches no in-flight request resolves without error. A cancel that arrives just before its request begins is still applied when the request begins.

### Broad

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelId` | ID of the loaded model whose in-flight requests to cancel. | `string` | Yes |
| `kind` | Cancel only requests of this kind. Omitting it cancels every in-flight request on the model. | [`CancelKind`](#cancelkind) | No |

A broad cancel does not reach an in-progress `loadModel()` or `downloadAsset()`: cancel those by `requestId`.

#### `CancelKind`

`"completion" | "batchCompletion" | "embeddings" | "decision" | "rerank" | "transcribe" | "translate" | "diffusion" | "world" | "audiogen" | "tts" | "ocr" | "vla" | "finetune" | "loadModel" | "downloadAsset" | "rpcServer" | "rpcDiscovery" | "rag"`

## Returns

A promise that resolves with no value once the cancel is signalled. It does not wait for the cancelled call to settle: await the original call to observe its end.

## Throws

| Error | When |
| --- | --- |
| `CancelFailedError` | The worker reports a failed cancel, such as a broad cancel for a `modelId` that is not loaded. The message carries the details. |
| `InvalidResponseError` | The worker answers with an unexpected response type. |

## Examples

```ts
import { cancel, completion, downloadAsset, InferenceCancelledError } from "@qvac/sdk";

// Targeted: stop one completion.
const run = completion({ modelId, history, stream: true });
await cancel({ requestId: run.requestId });

// Targeted: stop a download and delete its partial file.
const download = downloadAsset({ assetSrc: "https://example.com/model.gguf" });
await cancel({ requestId: download.requestId, clearCache: true });
try {
  await download;
} catch (error) {
  if (!(error instanceof InferenceCancelledError)) throw error;
}

// Broad: every in-flight request on a model, or only one kind.
await cancel({ modelId });
await cancel({ modelId, kind: "completion" });
```
