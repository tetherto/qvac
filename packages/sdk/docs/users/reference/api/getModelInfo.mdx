Looks up a model in QVAC's built-in catalog by name and returns its metadata, whether its files are in the local cache, and the instances of it currently loaded. Use it to decide whether a model must be downloaded before it is loaded. A registry model constant carries its catalog name, so it can be passed directly.

## Signature

```ts
function getModelInfo(params: GetModelInfoParams): Promise<ModelInfo>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model to look up. | [`GetModelInfoParams`](#getmodelinfoparams) | Yes |

### `GetModelInfoParams`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `name` | The model's name in QVAC's built-in catalog, such as `"WHISPER_TINY"`: the name of its model constant. | `string` | Yes |

## Returns

A promise that resolves with a `ModelInfo`:

| Field | Description | Type |
| --- | --- | --- |
| `name` | Catalog name of the model. | `string` |
| `modelId` | The model's file identifier in the catalog, such as `"ggml-tiny.bin"`. | `string` |
| `registryPath` | Registry-relative path of the model. | `string \| undefined` |
| `registrySource` | Registry source identifier, such as `hf`. | `string \| undefined` |
| `blobCoreKey` | Hyperdrive blob core key for the model file. | `string \| undefined` |
| `blobBlockOffset` | Starting block offset of the model file in the blob. | `number \| undefined` |
| `blobBlockLength` | Number of blocks occupied by the model file in the blob. | `number \| undefined` |
| `blobByteOffset` | Starting byte offset of the model file within its block. | `number \| undefined` |
| `engine` | Inference engine identifier, such as `llamacpp-completion`. | `string \| undefined` |
| `quantization` | Quantization identifier, such as `Q4_K_M`. | `string \| undefined` |
| `params` | Parameter-count label, such as `7B`. | `string \| undefined` |
| `expectedSize` | Expected total size of the model file, in bytes. | `number` |
| `sha256Checksum` | Expected SHA-256 checksum of the model file. | `string` |
| `addon` | Capability category the model belongs to. | `"llm" \| "whisper" \| "bci" \| "parakeet" \| "moss-transcribe" \| "embeddings" \| "nmt" \| "vad" \| "tts" \| "ocr" \| "diffusion" \| "audiogen" \| "vla" \| "classification" \| "other"` |
| `isCached` | Whether every file of the model is in the local cache with its expected size. | `boolean` |
| `isLoaded` | Whether at least one instance of the model is loaded. | `boolean` |
| `cacheFiles` | One entry per file that makes up the model: one for a single-file model, one per shard or companion file otherwise. | [`CacheFileInfo`](#cachefileinfo)`[]` |
| `actualSize` | Total size of the cached files on disk, in bytes. Present only when `isCached` is `true`. | `number \| undefined` |
| `cachedAt` | When the most recent file was cached. Present only when `isCached` is `true`. | `Date \| undefined` |
| `loadedInstances` | The loaded instances of the model, one per live load. Absent when none is loaded. | [`LoadedInstance`](#loadedinstance)`[] \| undefined` |

#### `CacheFileInfo`

| Field | Description | Type |
| --- | --- | --- |
| `filename` | Name of the file on disk. | `string` |
| `path` | Absolute path to the file in the cache. | `string` |
| `expectedSize` | Expected file size in bytes, from the model metadata. | `number` |
| `sha256Checksum` | Expected SHA-256 checksum of the file. | `string` |
| `isCached` | Whether the file is present with its expected size. | `boolean` |
| `actualSize` | Size of the file on disk, in bytes, when it exists. | `number \| undefined` |
| `cachedAt` | When the file was last written, when it exists. | `Date \| undefined` |

#### `LoadedInstance`

| Field | Description | Type |
| --- | --- | --- |
| `registryId` | ID of the loaded instance, as `loadModel()` returned it. | `string` |
| `loadedAt` | When the instance was loaded. | `Date` |
| `config` | The model-specific configuration the instance was loaded with. | `unknown` |

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `MODEL_NOT_FOUND` | `name` is not in the catalog. |
| `InvalidResponseError` | The worker answers with an unexpected response type. |

## Examples

```ts
import { downloadAsset, getModelInfo, WHISPER_TINY } from "@qvac/sdk";

const info = await getModelInfo(WHISPER_TINY); // or { name: "WHISPER_TINY" }

if (!info.isCached) {
  await downloadAsset({ assetSrc: WHISPER_TINY });
}

for (const instance of info.loadedInstances ?? []) {
  console.log(instance.registryId, instance.loadedAt.toLocaleString());
}
```
