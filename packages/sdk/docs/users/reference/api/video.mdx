Generates a video with a model loaded with `modelType: "diffusion"` and `modelConfig.mode: "video"`. `mode: "txt2vid"` generates from the prompt alone; `mode: "img2vid"` animates a first-frame image. The call returns immediately with a request ID, a progress stream, and promises for the AVI output and the run statistics. Which fields apply depends on the loaded model family (Wan 2.1, Wan 2.2, LTX-2, MiniMax-H3); see [Video generation](/sdk/ai-capabilities/video-generation).

## Signature

```ts
function video(params: VideoClientParams): VideoResult;
```

`mode` selects the shape of `params`:

| Form | `params` | Use it when |
| --- | --- | --- |
| Text-to-video | `mode: "txt2vid"` | You generate from the prompt alone. |
| Reference-conditioned text-to-video | `mode: "txt2vid"` with `reference_images`, `lora`, and `video_frames` | An LTX-2 model inherits a character or style from a reference sheet (IC-LoRA). |
| Image-to-video | `mode: "img2vid"` with `init_image` | You animate a first-frame image. |

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model, the mode, the prompt, and the generation settings. | [`VideoClientParams`](#videoclientparams) | Yes |

### `VideoClientParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of the loaded video model. | `string` | Yes | — |
| `mode` | Generation mode: `"txt2vid"` (no source frame) or `"img2vid"` (first-frame image). | `"txt2vid" \| "img2vid"` | Yes | — |
| `prompt` | Positive prompt describing the video to generate. | `string` | Yes | — |
| `negative_prompt` | What to avoid in the video. | `string` | No | — |
| `init_image` | First frame as PNG or JPEG bytes. `img2vid` only. | `Uint8Array` | `img2vid`: Yes | — |
| `strength` | img2vid denoise strength, from 0 to 1. `img2vid` only; MiniMax-H3 rejects it. | `number` | No | — |
| `width` | Video width in pixels: a positive multiple of 16. LTX-2, MiniMax-H3, and Wan 2.2 TI2V-5B require a multiple of 32. | `number` | No | — |
| `height` | Video height in pixels: a positive multiple of 16. LTX-2, MiniMax-H3, and Wan 2.2 TI2V-5B require a multiple of 32. | `number` | No | — |
| `video_frames` | Frame count, validated against the loaded model: Wan uses `4k + 1` (at least 5), LTX-2 uses `8k + 1` (9 to 257), MiniMax-H3 uses `17k + 5`. | `number` | Reference form: Yes | — |
| `fps` | Frame rate written to the AVI metadata, greater than 0 and at most 120. MiniMax-H3 requires `24`. | `number` | No | — |
| `seed` | Random seed, an integer. | `number` | No | Picked at random and returned in `stats.seed` |
| `steps` | Denoising step count of the low-noise or single expert, a positive integer. | `number` | No | — |
| `sampling_method` | Sampling algorithm of the low-noise path. | `"euler" \| "euler_a" \| "heun" \| "dpm2" \| "dpm++2m" \| "dpm++2mv2" \| "dpm++2s_a" \| "lcm" \| "ipndm" \| "ipndm_v" \| "ddim_trailing" \| "tcd" \| "res_multistep" \| "res_2s"` | No | — |
| `scheduler` | Noise schedule of the low-noise path. `"ltx2"` is LTX-2 only; MiniMax-H3 requires `"discrete"`. | `"discrete" \| "karras" \| "exponential" \| "ays" \| "gits" \| "sgm_uniform" \| "simple" \| "lcm" \| "smoothstep" \| "kl_optimal" \| "bong_tangent" \| "ltx2"` | No | — |
| `cfg_scale` | Classifier-free guidance scale. MiniMax-H3 requires `1`. | `number` | No | — |
| `flow_shift` | Flow-matching shift override for this request. | `number` | No | — |
| `high_noise_steps` | Wan 2.2 A14B only: step count of the high-noise expert. Omit it to let native routing derive the split from `moe_boundary`. | `number` | No | — |
| `high_noise_sampler` | Wan 2.2 A14B only: sampler of the high-noise expert. | `"euler" \| "euler_a" \| "heun" \| "dpm2" \| "dpm++2m" \| "dpm++2mv2" \| "dpm++2s_a" \| "lcm" \| "ipndm" \| "ipndm_v" \| "ddim_trailing" \| "tcd" \| "res_multistep" \| "res_2s"` | No | — |
| `high_noise_scheduler` | Wan 2.2 A14B only: scheduler of the high-noise expert. | `"discrete" \| "karras" \| "exponential" \| "ays" \| "gits" \| "sgm_uniform" \| "simple" \| "lcm" \| "smoothstep" \| "kl_optimal" \| "bong_tangent"` | No | — |
| `high_noise_cfg_scale` | Wan 2.2 A14B only: CFG scale of the high-noise expert. | `number` | No | — |
| `high_noise_flow_shift` | Wan 2.2 A14B only: flow-shift override of the high-noise expert. | `number` | No | — |
| `moe_boundary` | Wan 2.2 A14B only: mixture-of-experts boundary, from 0 to 1. | `number` | No | — |
| `control_frames` | Control-frame images, at least one. MiniMax-H3 rejects them. | `Uint8Array[]` | No | — |
| `vace_strength` | Control-frame guidance strength, from 0 to 1. MiniMax-H3 rejects it. | `number` | No | — |
| `vae_tiling` | Enable VAE tiling for large videos on constrained VRAM. | `boolean` | No | — |
| `vae_tile_size` | VAE tile size override. | `number \| string` | No | — |
| `vae_tile_overlap` | VAE tile overlap override. | `number` | No | — |
| `temporal_tiling` | LTX-2 only: tile the video VAE decode along the time axis to cap peak VRAM on HD or long clips. No effect on Wan. | `boolean` | No | — |
| `cache_mode` | Step-caching algorithm. | `"disabled" \| "easycache" \| "ucache" \| "dbcache" \| "taylorseer" \| "cache-dit"` | No | — |
| `cache_preset` | Name of a cached sampler preset to reuse. | `string` | No | — |
| `cache_threshold` | Direct cache-reuse threshold override. | `number` | No | — |

| `lora_strength` | LTX-2 only: LoRA multiplier, from 0 to 10. Requires `lora`. | `number` | No | — |
| `stg_scale` | LTX-2 only: spatiotemporal guidance scale, from 0 to 10. | `number` | No | — |
| `stg_block` | LTX-2 only: transformer block skipped for spatiotemporal guidance, a non-negative integer. | `number` | No | — |
| `reference_images` | LTX-2 `txt2vid` only: exactly one composite reference sheet. Requires `lora`, and `video_frames` set to at least 121. | `readonly [Uint8Array]` | Reference form: Yes | — |
| `reference_attention_strength` | LTX-2 `txt2vid` only: reference denoise-mask strength, from 0 to 1. Requires `reference_images`. | `number` | No | — |
| `reference_downscale_factor` | LTX-2 `txt2vid` only: reference-image spatial factor. Requires `reference_images`. | `1` | No | — |

The Wan 2.2 A14B fields require a model loaded with `modelConfig.highNoiseDiffusionModelSrc`; single-expert layouts (Wan 2.1, Wan 2.2 TI2V-5B, LTX-2) reject them.

## Returns

An object, returned synchronously. Generation starts when `video()` is called; consuming `progressStream` is optional.

| Field | Description | Type |
| --- | --- | --- |
| `requestId` | Identifies this generation. | `string` |
| `progressStream` | Yields a progress tick each time the worker reports one. Ends when the generation finishes; throws the run's error when it fails. | `AsyncGenerator<`[`VideoProgressTick`](#videoprogresstick)`>` |
| `outputs` | Resolves with the generated videos as AVI buffers, typically one, when the generation completes. | `Promise<Uint8Array[]>` |
| `stats` | Resolves with the run statistics when the generation completes, or `undefined` when the engine reports none. | `Promise<`[`VideoStats`](#videostats)` \| undefined>` |

#### `VideoProgressTick`

| Field | Description | Type |
| --- | --- | --- |
| `step` | Current sampling step. | `number` |
| `totalSteps` | Total sampling steps of the run. | `number` |
| `elapsedMs` | Time elapsed in the run, in milliseconds. | `number` |

#### `VideoStats`

Every field is optional. The fields of [`DiffusionStats`](/sdk/reference/api/diffusion#diffusionstats), plus:

| Field | Description | Type |
| --- | --- | --- |
| `totalVideos` | Total number of videos produced. | `number` |
| `totalVideoFrames` | Total number of video frames produced. | `number` |
| `videoFrames` | Frame count of the most recent video. | `number` |
| `fps` | Frame-rate metadata of the most recent video. | `number` |
| `hasAudio` | `true` when the AVI carries a muxed audio track: MiniMax-H3 or LTX-2 loaded with `audioVaeModelSrc`. | `boolean` |
| `audioSampleRate` | Sample rate of the muxed audio track, in Hz; `0` when there is no audio. | `number` |

## Throws

`video()` does not throw. Errors reject `outputs` and `stats`, and are thrown by `progressStream`.

| Error | When |
| --- | --- |
| `ModelOperationNotSupportedError` | The model was not loaded with `modelConfig.mode: "video"`. |
| `PluginRequestValidationFailedError` | The request breaks a rule of the loaded model family: a size or frame count off its grid, an LTX-2-only or Wan 2.2 A14B-only field, or a relative `lora` path. The class is not exported from `@qvac/sdk`; match it on the message. |
| `RequestRejectedByPolicyError` | Another image or video generation already owns the model. |

## Examples

```ts
import {
  loadModel,
  video,
  UMT5_XXL_FP16,
  WAN2_1_T2V_1_3B_FP16,
  WAN_2_1_COMFYUI_REPACKAGED_VAE,
} from "@qvac/sdk";
import fs from "fs";

const modelId = await loadModel({
  modelSrc: WAN2_1_T2V_1_3B_FP16,
  modelType: "sdcpp-generation",
  modelConfig: {
    mode: "video",
    t5XxlModelSrc: UMT5_XXL_FP16,
    vaeModelSrc: WAN_2_1_COMFYUI_REPACKAGED_VAE,
  },
});

// Text-to-video with Wan 2.1: frames follow 4k + 1.
const { progressStream, outputs, stats } = video({
  modelId,
  mode: "txt2vid",
  prompt: "a colorful bird flapping its wings",
  width: 480,
  height: 832,
  video_frames: 33,
  fps: 16,
  flow_shift: 3.0,
  seed: 42,
});
for await (const { step, totalSteps } of progressStream) {
  console.log(`step ${step}/${totalSteps}`);
}
const [avi] = await outputs;
fs.writeFileSync("bird.avi", avi!);
console.log(await stats);
```

```ts
// Image-to-video, on a Wan 2.1 I2V model loaded with clipVisionModelSrc.
const { outputs } = video({
  modelId,
  mode: "img2vid",
  prompt: "the subject slowly turns and smiles, soft natural lighting",
  init_image: new Uint8Array(fs.readFileSync("portrait.png")),
  strength: 0.85,
  video_frames: 33,
});
```
