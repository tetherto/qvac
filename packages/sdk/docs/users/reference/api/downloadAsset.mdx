Downloads a model file, or any other asset, into the cache without loading it into memory. Use it to provision a model ahead of time, such as a catalog model an application must later load offline. A later [`loadModel()`](/sdk/reference/api/loadModel) with the same source reads the cached files. Downloads are resumable: a cancelled download keeps its partial file and continues on the next call. See [Download lifecycle](/sdk/models/download-lifecycle).

## Signature

```ts
function downloadAsset(options: DownloadAssetOptions, rpcOptions?: RPCOptions): Promise<string> & { requestId: string };
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `options` | What to download and how. | [`DownloadAssetOptions`](#downloadassetoptions) | Yes |
| `rpcOptions` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `DownloadAssetOptions`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `assetSrc` | The asset to download and cache: a registry model constant, or a local file path, an HTTP(S) URL, or a `registry://` / `pear://` URI. | `string \| ` [`ModelDescriptor`](/sdk/reference/api/loadModel#modeldescriptor) | Yes | — |
| `seed` | Keep sharing the downloaded asset with peers over P2P after the download. Applies to `pear://` sources; an HTTP or local source fails the download, and registry sources ignore it. | `boolean` | No | `false` |
| `requireHttpChecksum` | Reject a Hugging Face download that exposes no usable SHA-256 instead of downloading it unverified. Overrides [`requireHttpChecksum`](/sdk/configuration#options) in the configuration for this call. | `boolean` | No | Configuration value (`false`) |
| `requireSecureTransport` | Reject plaintext `http://` and HTTPS→HTTP downgrades for every HTTP source on this call (loopback exempt). When unset, only Hugging Face transport is hardened. Overrides the configuration for this call. | `boolean` | No | Configuration value (`false`) |
| `onProgress` | Called with each download progress update. When set, the download streams its progress instead of resolving in one response. | `(progress: ` [`ModelProgressUpdate`](/sdk/reference/api/loadModel#modelprogressupdate)`) => void` | No | — |

### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. | [`PerCallProfiling`](#percallprofiling) | No |

#### `PerCallProfiling`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `enabled` | Profile this call only. When omitted, the global profiler configuration applies. | `boolean` | No |
| `includeServerBreakdown` | Include the server-side timing breakdown in the profiling payload. | `boolean` | No |
| `includeResourceGauges` | Attach one local CPU, memory, and GPU resource sample to the operation event. | `boolean` | No |
| `mode` | Detail level: `"summary"` keeps aggregates only, `"verbose"` keeps recent events. | `"summary" \| "verbose"` | No |

## Returns

A promise that resolves with the asset's source as a `string`: `assetSrc` itself, or the `src` of a descriptor. The promise also carries `requestId`, available synchronously, so the download can be cancelled with [`cancel({ requestId })`](/sdk/reference/api/cancel) before it resolves. Pass `clearCache: true` to `cancel()` to delete the partial file instead of keeping it for resume.

When two calls request the same asset, they share one underlying transfer. Cancelling one call rejects only that call's promise; the transfer stops when the last caller leaves.

## Throws

| Error | When |
| --- | --- |
| `DownloadAssetFailedError` | The download fails, including `seed: true` on a non-`pear://` source; the message carries the details. |
| `InferenceCancelledError` | The download is cancelled with [`cancel()`](/sdk/reference/api/cancel). |
| `StreamEndedError` | The progress stream ends without a final response (only with `onProgress`). |
| `InvalidResponseError` | The worker answers with an unexpected response type. |

## Examples

```ts
import { cancel, downloadAsset, loadModel, QWEN3_4B_INST_Q4_K_M } from "@qvac/sdk";

// Provision a catalog model now, load it later.
await downloadAsset({ assetSrc: QWEN3_4B_INST_Q4_K_M });
const modelId = await loadModel({ modelSrc: QWEN3_4B_INST_Q4_K_M });

// Track progress.
await downloadAsset({
  assetSrc: QWEN3_4B_INST_Q4_K_M,
  onProgress: (progress) => console.log(`${progress.percentage.toFixed(0)}%`),
});

// Pause or discard a download. requestId is available before the promise resolves.
const download = downloadAsset({ assetSrc: "https://example.com/model.gguf" });
// Pause: the partial file is kept, and the next call with the same source resumes it.
stopButton.onclick = () => cancel({ requestId: download.requestId });
// Discard: the partial file is deleted.
clearButton.onclick = () => cancel({ requestId: download.requestId, clearCache: true });
await download; // rejects with InferenceCancelledError when cancelled
```
