Closes an open built-in RAG workspace, releasing the memory and file locks it holds, and resolves with no value. The data stays on disk unless `deleteOnClose` is `true`. Workspaces open implicitly — [`ragIngest()`](/sdk/reference/api/ragIngest), [`ragSaveEmbeddings()`](/sdk/reference/api/ragSaveEmbeddings), and the other workspace calls open them — and stay open until this call. To delete a workspace that is not open, use [`ragDeleteWorkspace()`](/sdk/reference/api/ragDeleteWorkspace). See [RAG](/sdk/ai-capabilities/rag).

<Callout type="warn">
**Prototype only:** the built-in RAG vector store is not production grade. For production, use an external vector DB, as shown in the [RAG guide](/sdk/ai-capabilities/rag).
</Callout>

## Signature

```ts
function ragCloseWorkspace(params?: RagCloseWorkspaceParams, options?: RPCOptions): Promise<void>;
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The workspace to close. Omit it to close the default workspace. | [`RagCloseWorkspaceParams`](#ragcloseworkspaceparams) | No |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `RagCloseWorkspaceParams`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `workspace` | Name of the workspace to close. Must name a single child path: no `..`, null bytes, `%00`, or `%2e`. | `string` | No | `"default"` |
| `deleteOnClose` | When `true`, delete the workspace and all its data after closing it. | `boolean` | No | — |

### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. | [`PerCallProfiling`](#percallprofiling) | No |

#### `PerCallProfiling`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `enabled` | Profile this call only. When omitted, the global profiler configuration applies. | `boolean` | No |
| `includeServerBreakdown` | Include the server-side timing breakdown in the profiling payload. | `boolean` | No |
| `includeResourceGauges` | Attach one local CPU, memory, and GPU resource sample to the operation event. | `boolean` | No |
| `mode` | Detail level: `"summary"` keeps aggregates only, `"verbose"` keeps recent events. | `"summary" \| "verbose"` | No |

## Returns

A promise that resolves with no value once the workspace is closed, and deleted when `deleteOnClose` is `true`.

## Throws

An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` fails validation, for example an invalid `workspace` name. |
| `RAG_WORKSPACE_NOT_OPEN` | The workspace is not open. Nothing is deleted, even with `deleteOnClose`. |
| `RAG_WORKSPACE_CLOSE_FAILED` | The worker reports that closing failed. |

## Examples

```ts
// Release the workspace, keeping its data.
await ragCloseWorkspace({ workspace: "articles" });

// Close and delete a scratch workspace.
await ragCloseWorkspace({ workspace: "scratch", deleteOnClose: true });

// Close the default workspace.
await ragCloseWorkspace();
```
