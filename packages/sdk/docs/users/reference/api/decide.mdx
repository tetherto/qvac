title: decide

description: Answers typed decision questions (choice, score, statement probability) about one state or a batch of states.

Asks a loaded `llamacpp-decision` model typed questions about a state — text, a number, a boolean, structured JSON, or a conversation array — and resolves with one answer per question, with probabilities and confidence. Pass `state` for one result, or `states` for one result per state, in input order. It returns one aggregate result, without a token stream. Use it for routing and evaluation. See [Decisions](/sdk/ai-capabilities/decisions).

## Signature

```ts
function decide(params: Extract<DecideParams, { state: unknown }>, options?: RPCOptions): Promise<DecisionResult> & { requestId: string };
function decide(params: Extract<DecideParams, { states: unknown }>, options?: RPCOptions): Promise<DecisionResult[]> & { requestId: string };
function decide(params: DecideParams, options?: RPCOptions): Promise<DecisionResponse> & { requestId: string };
```

| Form | `params` | Resolves with |
| --- | --- | --- |
| Single state | `DecideParams` with `state` | One [`DecisionResult`](#decisionresult) |
| Batch | `DecideParams` with `states` | One [`DecisionResult`](#decisionresult) per state, in input order |

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The model, the state or states, and the questions. | [`DecideParams`](#decideparams) | Yes |
| `options` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `DecideParams`

Pass exactly one of `state` and `states`.

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelId` | ID of a loaded decision model, as [`loadModel()`](/sdk/reference/api/loadModel) returned it. Non-empty. | `string` | Yes | — |
| `state` | The state to decide about. | [`DecisionState`](#decisionstate) | One of `state`, `states` | — |
| `states` | Several states, answered in one request. | [`DecisionState`](#decisionstate)`[]` | One of `state`, `states` | — |
| `questions` | Question ID to question. Each question is answered independently, and its answer is keyed by the same ID. | `Record<string,` [`DecisionQuestion`](#decisionquestion)`>` | Yes | — |
| `maxLen` | Token budget per sequence. Positive integer. | `number` | No | The checkpoint's budget |
| `headMaxLen` | Token budget for each question and its options. Positive integer. | `number` | No | The checkpoint's budget |

#### `DecisionState`

`string | number | boolean | Record<string, unknown> | unknown[]`: text, a number, a boolean, a structured object, or a conversation as an array of turns, newest last. Nested values must be JSON (finite numbers, plain objects, no cycles). Top-level `null` is rejected. A conversation too long for the budget keeps its newest turns.

#### `DecisionQuestion`

Every question has a `type`, `instructions`, and an optional `optionOrder`:

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `type` | The question type; selects the `criteria` shape and the answer. | `"choice" \| "score" \| "noul"` | Yes |
| `instructions` | The question the model answers about the state. Must not be empty. | `DecisionState` | Yes |
| `optionOrder` | A permutation of the option indices: slot `s` shows option `optionOrder[s]` to the model. Answers still use the original order. | `number[]` | No |
| `criteria` | The options. Shape depends on `type`, below. | See below | Yes for `choice` and `score` |
| `labels` | `noul` only: the option labels shown to the model. | `{ false: string; true: string }` | No |

| `type` | `criteria` | Answer |
| --- | --- | --- |
| `"choice"` | Labels, `(string \| number \| boolean)[]`, or label → description, `Record<string, DecisionState \| null>`. A `null` description shows the label alone. | Picks one label. |
| `"score"` | Level descriptions, lowest first: `DecisionState[]`. | The expected ordinal level. |
| `"noul"` | Optional `{ true?, false? }` descriptions of the two options; `null` keeps the default. | The probability that the statement in `instructions` holds. |

#### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. See [Profiler](/sdk/runtime/profiler). | `PerCallProfiling` | No |

## Returns

A promise that resolves with a `DecisionResult` for `state`, or a `DecisionResult[]` for `states`. The promise also carries `requestId`, available synchronously, so the call can be cancelled with [`cancel({ requestId })`](/sdk/reference/api/cancel) before it resolves.

### `DecisionResult`

| Field | Description | Type |
| --- | --- | --- |
| `model` | The model that answered. | `string` |
| `answers` | One answer per question, keyed by question ID. | `Record<string,` [`DecisionAnswer`](#decisionanswer)`>` |
| `usage` | Token counts and truncation information. | [`DecisionUsage`](#decisionusage) |

#### `DecisionAnswer`

Every answer has these fields:

| Field | Description | Type |
| --- | --- | --- |
| `type` | The question's type. | `"choice" \| "score" \| "noul"` |
| `answerConfidence` | Probability of the reported answer. | `number` |
| `confidence` | For `choice` and `score`: 1 − the normalized entropy of the option distribution. For `noul`: the probability of the more likely side. Not calibrated for `laya-multilingual`. | `number` |
| `action.actProbability` | Currently carries no usable signal. Do not use it to trigger actions. | `number` |

Plus the fields of its type:

| `type` | Field | Description | Type |
| --- | --- | --- | --- |
| `"choice"` | `choice` | The selected label. | `string \| number \| boolean` |
| `"choice"` | `probabilities` | Probability per label. | `Record<string, number>` |
| `"score"` | `score` | The expected level, Σ i·p(i). | `number` |
| `"score"` | `probabilities` | Probability per level. | `Record<string, number>` |
| `"score"` | `legend` | Level to description. | `Record<string, string>` |
| `"noul"` | `noul` | Probability that the statement holds. | `number` |

#### `DecisionUsage`

| Field | Description | Type |
| --- | --- | --- |
| `inputTokens` | Input tokens. | `number` |
| `outputTokens` | Output tokens. | `number` |
| `stateTokens` | Tokens of the state. | `number` |
| `stateTokensDropped` | State tokens dropped to fit the budget. | `number` |
| `truncated` | Whether any input was truncated to fit the budget. | `boolean` |
| `truncatedQuestions` | IDs of the questions that were truncated. | `string[]` |
| `options` | Present for questions whose options collapsed to fewer distinct ones under the token budget, keyed by question ID: the option count (`total`), the distinct options left (`distinct`), and `tokensPerOption`. | `Record<string, { total: number; distinct: number; tokensPerOption: number \| null }>` |

## Throws

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `params` is invalid, checked on the client before the request is sent. |
| `InferenceCancelledError` | The request is cancelled, while running or queued. |
| `RequestRejectedByPolicyError` | The model's decision queue is full: 64 waiting requests. Active and queued requests are unaffected. |
| `InvalidResponseError` | The worker returns a malformed result, or a result count that does not match the request. |

## Examples

```ts
import { decide, loadModel, LAYA_MULTILINGUAL_322M_Q8_0 } from "@qvac/sdk";

const modelId = await loadModel({
  modelSrc: LAYA_MULTILINGUAL_322M_Q8_0,
  modelType: "llamacpp-decision",
  modelConfig: { device: "cpu" },
});

// One state.
const result = await decide({
  modelId,
  state: "My payment failed twice and I was charged both times. Please refund the duplicate.",
  questions: {
    department: { type: "choice", instructions: "Which team should handle this ticket?", criteria: ["billing", "technical"] },
    urgency: { type: "score", instructions: "How urgent is this?", criteria: ["not urgent", "somewhat urgent", "very urgent"] },
    refund: { type: "noul", instructions: "The customer asks for a refund." },
  },
});
const department = result.answers.department;
if (department?.type === "choice") console.log(department.choice, department.answerConfidence);

// Several states in one request: one result per state, in order.
const results = await decide({
  modelId,
  states: ["The app crashes on startup.", { customer: "Ana", message: "I was double charged." }],
  questions: { refund: { type: "noul", instructions: "The customer asks for a refund." } },
});

// Cancel before it resolves.
const pending = decide({ modelId, state: "Where is my order?", questions: { refund: { type: "noul", instructions: "The customer asks for a refund." } } });
await cancel({ requestId: pending.requestId });
```
