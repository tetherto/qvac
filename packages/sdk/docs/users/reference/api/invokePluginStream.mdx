Sends `params` to a named streaming handler of the plugin that serves a loaded model, and returns an async generator that yields each chunk the handler produces. Custom plugin packages call it from their client wrappers; see [Write a custom plugin](/sdk/configuration/plugins/write-custom-plugin). For a reply handler, use [`invokePlugin`](/sdk/reference/api/invokePlugin).

## Signature

```ts
function invokePluginStream<TResponse = unknown, TParams = unknown>(options: InvokePluginOptions<TParams>, rpcOptions?: RPCOptions): AsyncGenerator<TResponse>;
```

`TParams` types `params` and `TResponse` types each chunk. Both are compile-time annotations only: the worker validates the payloads against the handler's own schemas.

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `options` | The model, the handler, and its payload. | [`InvokePluginOptions`](#invokepluginoptions) | Yes |
| `rpcOptions` | Transport options for this call only. | [`RPCOptions`](#rpcoptions) | No |

### `InvokePluginOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `modelId` | ID of the loaded model, as [`loadModel`](/sdk/reference/api/loadModel) returned it. Its model type selects the plugin. | `string` | Yes |
| `handler` | Name of the handler, as declared in the plugin's `handlers`. Must be a streaming handler. | `string` | Yes |
| `params` | The handler's request payload. Sent as JSON and validated in the worker against the handler's `requestSchema`. | `TParams` | Yes |

### `RPCOptions`

| Option | Description | Type | Required |
| --- | --- | --- | --- |
| `timeout` | Per-call RPC timeout in milliseconds; overrides the default for this request only. Minimum `100`. | `number` | No |
| `healthCheckTimeout` | Timeout in milliseconds for the health-check probe that precedes the call. Minimum `100`. | `number` | No |
| `forceNewConnection` | When `true`, skip any cached RPC connection and open a fresh one for this call. | `boolean` | No |
| `profiling` | Profiler settings for this call; override the global profiler settings. | [`PerCallProfiling`](#percallprofiling) | No |

#### `PerCallProfiling`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `enabled` | Profile this call only. When omitted, the global profiler configuration applies. | `boolean` | No |
| `includeServerBreakdown` | Include the server-side timing breakdown in the profiling payload. | `boolean` | No |
| `includeResourceGauges` | Attach one local CPU, memory, and GPU resource sample to the operation event. | `boolean` | No |
| `mode` | Detail level: `"summary"` keeps aggregates only, `"verbose"` keeps recent events. | `"summary" \| "verbose"` | No |

## Returns

An `AsyncGenerator<TResponse>` that yields each chunk of the handler's output, in order. The worker validates every chunk against the handler's `responseSchema` before sending it. The generator ends when the handler finishes; the worker's end-of-stream marker is not yielded.

## Throws

The generator throws while you iterate it. An error written as a code, such as `MODEL_NOT_FOUND`, is not exported as a class: it reaches the caller as an `Error` whose `name` is that code.

| Error | When |
| --- | --- |
| `MODEL_NOT_FOUND` | No model with `modelId` is loaded. |
| `PLUGIN_NOT_FOUND` | No plugin is registered for the model's type. |
| `PLUGIN_HANDLER_NOT_FOUND` | The plugin has no handler named `handler`. The message lists the available handlers. |
| `PLUGIN_HANDLER_TYPE_MISMATCH` | The handler is a reply handler. Call it with [`invokePlugin`](/sdk/reference/api/invokePlugin). |
| `PLUGIN_REQUEST_VALIDATION_FAILED` | `params` does not match the handler's `requestSchema`. |
| `PLUGIN_RESPONSE_VALIDATION_FAILED` | A chunk does not match the handler's `responseSchema`. |
| `QvacErrorBase` | A response has the wrong type, or the RPC layer fails. |

## Examples

```ts
import { invokePluginStream } from "@qvac/sdk";

// Client wrapper for the "echoStream" streaming handler of a custom plugin.
export async function* echoStream(options: { modelId: string; message: string }) {
  for await (const chunk of invokePluginStream<{ char: string | null; done: boolean }>({
    modelId: options.modelId,
    handler: "echoStream",
    params: { message: options.message },
  })) {
    if (!chunk.done && chunk.char) {
      yield chunk.char;
    }
  }
}

for await (const char of echoStream({ modelId, message: "Streaming test!" })) {
  process.stdout.write(char);
}
```
