Searches a shared discovery topic for RPC servers advertised with [`startRpcServer`](/sdk/reference/api/startRpcServer), probes each one for its device inventory, and resolves with the candidates when the search budget elapses. Choose and order the endpoints, map their devices with `getRpcDeviceMap`, then pass the same endpoints, in the same order, to [`loadModel`](/sdk/reference/api/loadModel). See [RPC servers](/sdk/p2p-capabilities/rpc-servers).

<Callout type="warn">
A discovery topic does not authenticate peers. Use discovery only with trusted private-network participants.
</Callout>

## Signature

```ts
function discoverRpcServers(options: DiscoverRpcServersOptions): Promise<RpcServerCandidate[]> & { requestId: string };
```

## Parameters

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `options` | The topic to search and the search budget. | [`DiscoverRpcServersOptions`](#discoverrpcserversoptions) | Yes |

### `DiscoverRpcServersOptions`

| Option | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `topic` | Shared discovery topic, as the servers set it in `discoveryTopic`. Trimmed; 1 to 256 characters. | `string` | Yes | — |
| `timeoutMs` | Search budget in milliseconds, including TCP probes. An integer from `100` to `30000`. The call resolves when it elapses. | `number` | No | `5000` |

## Returns

A promise that resolves with an array of [`RpcServerCandidate`](#rpcservercandidate), one per endpoint. An endpoint is listed only when it is a private IPv4 address, announced itself within the last 3 seconds of the search, and answered the inventory probe with at least one device. Servers on an RPC protocol other than `113.0.x` are left out, and the worker logs a warning with the received and supported versions. Nothing is cached between calls.

The promise also carries `requestId`, available synchronously, so a pending search can be cancelled with [`cancel({ requestId })`](/sdk/reference/api/cancel). See [Cancellation](/sdk/runtime/cancellation).

### `RpcServerCandidate`

| Field | Description | Type |
| --- | --- | --- |
| `url` | The server's endpoint, as `<host>:<port>`. | `string` |
| `rdmaAvailable` | Whether the server advertised RDMA availability for this endpoint at discovery time. The actual transport depends on client support and negotiation. | `boolean` |
| `devices` | Native served devices, in endpoint enumeration order. | [`RpcDevice[]`](#rpcdevice) |

#### `RpcDevice`

| Field | Description | Type |
| --- | --- | --- |
| `index` | Zero-based device index within this endpoint. | `number` |
| `freeMemory` | Available device memory in bytes at discovery time. | `number` |
| `totalMemory` | Total device memory in bytes. | `number` |

## Throws

| Error | When |
| --- | --- |
| `RequestValidationFailedError` | `topic` is empty or longer than 256 characters, or `timeoutMs` is out of range. |
| `InferenceCancelledError` | The search was cancelled with [`cancel({ requestId })`](/sdk/reference/api/cancel). |
| `RpcServerOperationError` | The search fails in the worker. The `details` field carries the reason. |
| `QvacErrorBase` | The worker answers with an invalid response type. |

## Examples

```ts
import { discoverRpcServers, getRpcDeviceMap, loadModel, cancel, LLAMA_3_2_1B_INST_Q4_0 } from "@qvac/sdk";

// Prefer servers that offer RDMA, then take two.
const selected = (await discoverRpcServers({ topic: "my-private-rpc-group", timeoutMs: 5000 }))
  .sort((a, b) => Number(b.rdmaAvailable) - Number(a.rdmaAvailable) || a.url.localeCompare(b.url))
  .slice(0, 2);

// Map device aliases in the same endpoint order passed to rpc-servers.
const devices = getRpcDeviceMap(selected);
const modelId = await loadModel({
  modelSrc: LLAMA_3_2_1B_INST_Q4_0,
  modelConfig: {
    device: "gpu",
    "rpc-servers": selected.map((server) => server.url).join(","),
    devices: devices.map((device) => device.alias).join(","),
    "split-mode": "layer",
  },
});

// Cancel a search before it resolves.
const search = discoverRpcServers({ topic: "my-private-rpc-group" });
await cancel({ requestId: search.requestId });
```
