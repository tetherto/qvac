# QVAC ASR GGML Addon v0.1.0 Release Notes

`@qvac/asr-ggml` is the merge of `@qvac/transcription-whispercpp` (final release `0.12.1`) and `@qvac/transcription-parakeet` (final release `0.10.1`) into one npm package, one native prebuild (`BARE_MODULE qvac_asr_ggml`), and one public class, `ASRGgml`. Version numbering restarts at `0.1.0`.

Both engines — Whisper (whisper.cpp) and NVIDIA Parakeet / Sortformer (parakeet-cpp) — are reachable through the same verbs. Configuration vocabularies stay engine-scoped: `config.whisperConfig` for whisper, `config.parakeetConfig` for parakeet, with no third merged namespace.

## Changes

### One class, engine-scoped configuration

`ASRGgml` replaces `TranscriptionWhispercpp` and `TranscriptionParakeet`. `load`, `run`, `runStreaming`, `reload`, `cancel`, `status`, `unload` and `destroy` have one signature and one meaning regardless of engine; each engine's config keys are validated only by that engine's driver, and an unknown key throws instead of being silently ignored. Internally the class is an orchestrator over a per-engine `AsrDriver` seam — see `docs/engines.md`.

### Explicit engine selection

The engine is resolved once, in the constructor: `config.engine` wins (a `config` without `engine`, or with an unrecognized value, throws `INVALID_ENGINE`), then the top-level `engine` alias, then best-effort model-file magic-byte sniffing (`GGUF` ⇒ parakeet, otherwise whisper). Sniffing is a convenience for scripts — it cannot distinguish a GGUF whisper build from a GGUF parakeet build, so library and SDK callers should always pass `config.engine`.

### Unified error table across two ranges

Shared verbs are canonical in whisper's `6xxx` range, extended with `NOT_SUPPORTED` (6019), `STREAMING_SESSION_ACTIVE` (6020) and `INVALID_ENGINE` (6021). Parakeet-only names keep their historical `24xxx` numbers, and shared verbs raised by the parakeet engine also stay in `24xxx`. Every number from both pre-merge tables is registered, so existing numeric codes still resolve.

### Whisper `Float32Array` input fix

A `Float32Array` chunk was previously reinterpreted as `s16le` bytes unless `audio_format: 'f32le'` was set, silently producing garbage transcripts. A chunk's class now decides its interpretation, and `audio_format` only describes how raw `Uint8Array` bytes are decoded.

### Build hardening carried across to the whisper half

The Linux `symbols.map` version script and the Apple compiler-rt `-Wl,-force_load` step — previously parakeet-only — now apply to the merged module.

## Backward Compatibility

This release is **not** drop-in for either parent. The full list is in `CHANGELOG.md` under `0.1.0`; the changes most likely to bite:

- **Import and class name.** `require('@qvac/asr-ggml')` returns `ASRGgml`. Errors are `QvacErrorAddonASRGgml`; `QvacErrorAddonWhisper` and `QvacErrorAddonParakeet` are gone. Match on `err.code`.
- **Dropped subpath exports.** `./parakeet`, `./parakeet.js` and `./transcription-addon` are removed; drive both engines through `ASRGgml`.
- **`stop()` is removed.** Use `cancel()`, `unload()` or `destroy()`.
- **`pause()` / `unpause()` always reject** with `NOT_SUPPORTED` (6019).
- **`enableStats` moved** from inside the config object to a top-level constructor option, defaulting to `true` for both engines.
- **Parakeet `exclusiveRun` now serializes `run()` to completion**, where it previously released the queue slot as soon as the response was returned. Pass `exclusiveRun: false` to keep overlapping runs.
- **Parakeet's constructor now throws** `MODEL_NOT_FOUND` (24009) on a missing model file instead of warning and deferring to `load()`.
- **Whisper `runStreaming()` no longer holds the exclusive-run slot** for the whole session; a concurrent call while a session is open is rejected with `STREAMING_SESSION_ACTIVE` (6020).
- **Native error text changed** for the whisper half: `makeStatus` now emits the real code name instead of a constant `"WhisperError"`. Consumers scraping the native error string will see different values.
- **Whisper prebuild symbols are now local.** Out-of-tree code `dlsym`-ing whisper.cpp or ggml symbols out of the prebuild will no longer find them.
