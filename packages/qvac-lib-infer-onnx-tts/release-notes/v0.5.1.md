# QVAC TTS ONNX Addon v0.5.1 Release Notes

This release adds multilingual support to the Chatterbox TTS engine, enabling speech synthesis in languages beyond English. It also includes the Supertonic TTS engine as a new alternative, architecture documentation, and third-party attribution notices.

## Features

### Multilingual Chatterbox TTS

The Chatterbox engine now supports multilingual text-to-speech synthesis. To use it, point the model paths at the `chatterbox-multilingual` model directory and set the `language` configuration parameter to one of the supported language codes (e.g. `es`, `it`, `fr`, `de`, `pt`, `pl`, `zh`, `ja`, `ko`, `hi`):

```js
const model = new ONNXTTS({
  tokenizerPath: 'chatterbox-multilingual/tokenizer.json',
  speechEncoderPath: 'chatterbox-multilingual/speech_encoder.onnx',
  embedTokensPath: 'chatterbox-multilingual/embed_tokens.onnx',
  conditionalDecoderPath: 'chatterbox-multilingual/conditional_decoder.onnx',
  languageModelPath: 'chatterbox-multilingual/language_model.onnx',
  referenceAudio: audioFloat32Array
}, { language: 'es' })

await model.load()
const response = await model.run({
  input: 'Hola mundo! Esta es una prueba.',
  type: 'text'
})
```

The engine automatically handles language-specific tokenization, position ID computation, and model configuration differences between English and non-English languages. You can switch languages at runtime by reloading the model with a new language parameter.

The example script `examples/example-chatterbox-tts.js` now accepts an `english` or `multilingual` argument to demonstrate both modes.

### Supertonic TTS Engine

A second TTS engine, Supertonic, is now available alongside Chatterbox. Engine selection is automatic based on the arguments provided. If you pass `modelDir` and `voiceName`, or any of the Supertonic-specific paths (`textEncoderPath`, `latentDenoiserPath`, `voiceDecoderPath`, `voicesDir`), the addon uses the Supertonic engine; otherwise it defaults to Chatterbox.

```js
const model = new ONNXTTS({
  modelDir: path.join(__dirname, 'models', 'supertonic'),
  voiceName: 'F1',
  speed: 1,
  numInferenceSteps: 5
}, { language: 'es' })
```

## Bug Fixes

### Improved Sentence Splitting

Text chunking now enforces a minimum piece size of 25 characters before splitting on sentence-ending punctuation (`.`, `!`, `?`). This prevents the engine from producing very short audio fragments that degrade synthesis quality.

## Other

- Added architecture documentation describing the TTS addon's internal design, data flows, and engine abstraction layer.
- Added NOTICE file with third-party dependency attributions and license information.
