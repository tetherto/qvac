# QVAC TTS ONNX Addon v0.5.6 Release Notes

This release fixes critical CMake configuration errors that were preventing the TTS addon from building after updating the vcpkg registry baseline.

## Bug Fixes

### CMake Configuration Errors

Fixed build failures caused by incorrect onnxruntime target configuration in CMakeLists.txt. The build was failing with "target not found" errors due to three issues:

First, there was a duplicate `find_package(onnxruntime)` call that caused the `safeint_interface` target to be defined twice, resulting in a conflict. This duplicate call has been removed.

Second, the code was attempting to create an ALIAS for a non-existent `onnxruntime::onnxruntime_static` target. This ALIAS definition has been removed as it was unnecessary.

Third, the `target_link_libraries` was referencing the incorrect target name `onnxruntime::onnxruntime_static` instead of the actual exported target `onnxruntime::onnxruntime`. The target name has been corrected to match what the onnxruntime package actually provides.

These fixes ensure that the TTS addon builds successfully with the updated vcpkg dependencies.

### Vcpkg Registry Baseline Update

Updated the vcpkg registry baseline to the latest version, enabling compatibility with newer dependency versions and improvements in the package ecosystem.
