# QVAC TTS ONNX Addon v0.5.4 Release Notes

This release adds lazy ONNX session loading on iOS to reduce peak memory usage during synthesis, preventing out-of-memory kills on memory-constrained devices.

## Features

### Lazy ONNX session loading for iOS

On iOS, the Chatterbox engine no longer loads all four ONNX sessions (embed_tokens, speech_encoder, language_model, conditional_decoder) at once during `load()`. Instead, sessions are created on demand during `synthesize()` and released as soon as they are no longer needed:

- `speech_encoder` is released immediately after its single use in the first iteration.
- `embed_tokens` and `language_model` are released after the token generation loop.
- `conditional_decoder` is loaded only after the other sessions are released, so it is never co-resident in memory with them.

This behavior is controlled by a `lazySessionLoading_` flag, currently enabled on iOS via `TARGET_OS_IPHONE`. All other platforms retain the existing eager loading behavior with no functional changes.
