# QVAC ONNX TTS Addon v0.6.0 Release Notes

This release migrates the ONNX TTS addon to the `qvac-lib-inference-addon-cpp` 1.x runtime architecture and fixes an exclusive-run deadlock in lifecycle paths. Because the package moved off the removed legacy templated addon API, this is released as a backward-incompatible minor bump.

## Changes

### Migrate native addon to addon-cpp 1.x

The addon now uses `IModel` with `AddonJs`/`AddonCpp` and a `createInstance`/`runJob` execution flow. Legacy templated addon and js-interface files were removed as part of the migration.

### Update JS/native runtime plumbing

The JS wrapper and binding exports were adapted to the addon-cpp 1.x model while maintaining package-level behavior for standard consumers.

### Fix exclusiveRun deadlock paths

Nested `_withExclusiveRun` locking in ONNXTTS runtime lifecycle paths was removed to prevent hangs in `run()`, `reload()`, and `unload()` when `exclusiveRun: true`.

## Backward Compatibility

The high-level ONNX TTS package API remains compatible for standard JavaScript consumers.

Direct consumers of removed legacy native addon internals must migrate to the addon-cpp 1.x runtime model introduced in this release.
