# QVAC TTS ONNX Addon v0.5.5 Release Notes

This release adds support for fp16-quantized Chatterbox ONNX models in the C++ inference path, refactors the synthesis pipeline for maintainability and testability, and improves CI with C++ coverage reporting and PR comments.

## Features

### Fp16 quantization support for Chatterbox models

The C++ addon now supports both fp32 and fp16 Chatterbox ONNX models (English and multilingual). A new `Fp16Utils` module handles fp16↔fp32 conversion and type-aware tensor read/write, so fp16 models run without memory violations. You can use `CHATTERBOX_VARIANT=fp16` when running integration tests or loading fp16 models from Hugging Face.

### Refactored ChatterboxEngine synthesis pipeline

`ChatterboxEngine::synthesize()` has been split into smaller, testable helpers (e.g. token sanitization, position IDs, embedding extraction, speech encoder outputs, next-token selection, KV cache updates, token generation). An `IOnnxInferSession` interface and `OrtTypes.hpp` improve dependency boundaries and allow injecting a session factory in tests.

### C++ test coverage and CI reporting

New unit tests cover `Fp16Utils`, ChatterboxEngine helper methods, `OnnxInferSessionMock`, and factory injection. Integration tests run against real ONNX models (with optional download via `ensure-chatterbox-models.js`). Coverage excludes test and mock files. The GitHub workflow now publishes C++ test results to the Checks tab and posts a coverage summary as a comment on the PR.

## Other

- LLVM coverage symlinks are configured in the TTS C++ coverage workflow so `llvm-cov`/`llvm-profdata` resolve correctly in CI.
- `release-notes/` directory is introduced for this package; add a `release-notes/vX.Y.Z.md` file when bumping the version so the automated GitHub release can use it.
