# QVAC NMT Addon v0.6.3 Release Notes

This release deprecates Opus as a supported model type, removing `ModelTypes.Opus` from the public API and consolidating European language translation on Bergamot.

## Breaking Changes

### Deprecate ModelTypes.Opus

`TranslationNmtcpp.ModelTypes.Opus` has been removed. Passing `modelType: 'Opus'` to the constructor now throws a deprecation error directing users to `ModelTypes.Bergamot`.

The GGML C++ backend is retained for IndicTrans. Only the Opus JS surface is removed.

**Migration:** Replace `ModelTypes.Opus` with `ModelTypes.Bergamot`. For non-English pairs (e.g., de-fr), use Bergamot pivot translation via `PivotTranslationModel`.

## Other Changes

- Removed `ggml-opus.test.js` integration test
- Removed `runGgmlOpus` from mobile integration runner
- Updated `quickstart.js` to Bergamot-only example
- Updated website translation docs to reference Bergamot streaming example
- Added unit test for deprecation guard
