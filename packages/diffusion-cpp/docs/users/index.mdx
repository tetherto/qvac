## Overview

[Bare module](https://bare.pears.com) for text-to-image generation and reference image editing in QVAC, using [`qvac-ext-stable-diffusion.cpp`](https://github.com/tetherto/qvac-ext-stable-diffusion.cpp) as the inference engine.

Most applications use this package through the [QVAC SDK](/sdk/ai-capabilities/image-generation), which is the canonical way to run image generation with QVAC: it loads models, manages the worker, and exposes one API across languages. Use the package directly to embed the engine in a Bare application without the SDK.

## Models

Supports Qwen-Image-2.1, FLUX.2-klein, SD1.x, SD2.x, SDXL, and SD3 model families.

### Qwen-Image-2.1

Three separate components are required for text-to-image:

- **Diffusion model** (`qwen_image_2.1-Q4_K.gguf`) - the main image transformer.
- **Text encoder** (`Qwen3VL-8B-Instruct-Q4_K_M.gguf`) - the matching Qwen3-VL encoder.
- **VAE** (`qwen_image_2.1_vae_bf16.safetensors`) - the 2.1 VAE; earlier Qwen Image and Wan VAEs are incompatible.

Reference editing also requires the **vision projector** (`mmproj-Qwen3VL-8B-Instruct-F16.gguf`) as `files.llmVision`, separate from the video API's `clipVision`.

### FLUX.2-klein

Three separate components are required:
- **Diffusion model** (`flux-2-klein-4b-Q8_0.gguf`) — the main image transformer.
- **Text encoder** (`Qwen3-4B-Q4_K_M.gguf`) — Qwen3 4B in standard GGML Q4_K_M format.
- **VAE** (`flux2-vae.safetensors`) — standard safetensors format, compatible as-is.

### Stable Diffusion

- **Stable Diffusion 1.x / 2.x** — all-in-one checkpoint as a single `*.gguf` file
- **Stable Diffusion XL** — all-in-one `*.gguf` or split CLIP encoders
- **Stable Diffusion 3** — safetensors with separate CLIP encoders
