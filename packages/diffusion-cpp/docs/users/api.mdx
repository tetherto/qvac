`@qvac/diffusion-cpp` exports three model classes: `ImgStableDiffusion` for image generation (the default export), `VideoStableDiffusion` for video generation, and `EsrganUpscaler` for standalone upscaling. It also exports the `assessFit` memory projection, a FLUX.2 sizing helper, and the types of their arguments and results. Most applications use it through the [QVAC SDK](/sdk); for a walkthrough of direct use, see [Usage](/ecosystem/packages/diffusion-cpp/usage).

```js
const ImgStableDiffusion = require('@qvac/diffusion-cpp')
const { EsrganUpscaler, VideoStableDiffusion, assessFit } = require('@qvac/diffusion-cpp')
```

## Classes

### `ImgStableDiffusion`

Text-to-image and image-to-image generation through stable-diffusion.cpp, including multi-reference editing and optional ESRGAN upscaling of the output. Supports SD1.x, SD2.x, SDXL, SD3, FLUX.2 [klein], and Ideogram 4. An instance runs one job at a time.

```ts
constructor({ files, config, logger, opts }: ImgStableDiffusionArgs);
```

| Parameter | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `files` | Paths of the model files. Every path must be absolute. | [`DiffusionFiles`](#diffusionfiles) | Yes | — |
| `config` | Engine configuration, applied at `load()`. | [`SdConfig`](#sdconfig) | No | `{}` |
| `logger` | Receives the wrapper's log lines. | `QvacLogger \| Console \| null` | No | `null` |
| `opts` | `stats: true` emits [`RuntimeStats`](#runtimestats) on each response before it ends. | `{ stats?: boolean }` | No | `{}` |

The constructor throws a `TypeError` when `files` is not an object, or when `files.model` or any other path it holds is not an absolute path string.

| Property | Description | Type |
| --- | --- | --- |
| `addon` | The native instance. `null` until `load()` succeeds and after `unload()`. | [`Addon`](#addon) `\| null` |
| `opts` | The `opts` passed to the constructor. | `{ stats?: boolean }` |
| `logger` | The logger wrapping the `logger` passed to the constructor. | `QvacLogger` |
| `state` | `configLoaded` is `true` while the model is loaded. | `{ configLoaded: boolean }` |

#### `load()`

Creates the native instance and loads the model files. Does nothing when the model is already loaded. When loading fails, it releases the native instance and rejects with the load error.

```ts
load(): Promise<void>;
```

Returns a promise that resolves once the model is loaded.

#### `run()`

Starts a generation job. The job is image-to-image when `init_image` or `init_images` is set, and text-to-image otherwise. The promise resolves with the job's response as soon as the job is accepted, not when the images are ready.

```ts
run(params: GenerationParams): Promise<QvacResponse>;
```

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The prompt, the output size, the sampling settings, and the reference images. | [`GenerationParams`](#generationparams) | Yes |

Returns a promise that resolves with a [`QvacResponse`](#qvacresponse). Its outputs are:

| Output | Type | When |
| --- | --- | --- |
| Progress update | `string`: JSON such as `{"step":1,"total":20,"elapsed_ms":...}` | During the job. Each sampler sequence, and each VAE tile pass when `vae_tiling` is on, restarts at `step: 0` with its own `total`. |
| Image | `Uint8Array` of PNG bytes | Once per generated image. |
| `stats` event | [`RuntimeStats`](#runtimestats) | Before the response ends, when the instance was created with `opts.stats: true`. |

| Error | When |
| --- | --- |
| `Error` | `width` or `height` is not a positive multiple of 8. |
| `TypeError` | `prompt` is missing or empty. |
| `TypeError` | `init_image` is not image bytes, `init_images` is not an array, or one of its entries is empty or not image bytes. |
| `Error` | `init_image` and `init_images` are both set, or `init_images` is empty. |
| `Error` | `increase_ref_index` is set without `init_images`, `auto_resize_ref_image` is set without a reference image, or either is not a boolean. |
| `TypeError` | `lora` is not a non-empty absolute path. |
| `Error` | `upscale` is requested and `files.esrgan` was not provided. |
| `Error` | The model is not loaded: `Addon not initialized. Call load() first.` |
| `Error` | A previous job's response is still active: `Cannot set new job: a job is already set or being processed`. |

Failures inside the engine, such as `init_images` on a model without reference editing, reject the response's `await()` instead of `run()`.

#### `cancel()`

Cancels the running job. The active response rejects, and a cancelled job delivers no partial image. Does nothing when the model is not loaded.

```ts
cancel(): Promise<void>;
```

Returns a promise that resolves once the cancel request is sent.

#### `unload()`

Cancels any running job, fails its response with `Model was unloaded`, and releases the native instance. The instance can be loaded again.

```ts
unload(): Promise<void>;
```

Returns a promise that resolves once the native instance is released.

#### `getState()`

```ts
getState(): { configLoaded: boolean };
```

Returns the instance's `state` object.

#### `run()`

Starts a video generation job. The promise resolves with the job's response as soon as the job is accepted, not when the video is ready.

```ts
run(params: VideoGenerationParams): Promise<QvacResponse>;
```

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The mode, the prompt, the size and frame count, and the conditioning inputs. | [`VideoGenerationParams`](#videogenerationparams) | Yes |

Returns a promise that resolves with a [`QvacResponse`](#qvacresponse). Its outputs are:

| Output | Type | When |
| --- | --- | --- |
| Progress update | `string`: JSON such as `{"step":1,"total":30,"elapsed_ms":...}` | During the job, as for images. |
| Video | `Uint8Array` of MJPG AVI bytes | Once, at the end. For LTX-2 and MiniMax-H3 models loaded with `files.audioVae`, the AVI also carries an IEEE-float PCM audio stream: 48 kHz for LTX-2, 32 kHz for H3. |
| `stats` event | [`VideoRuntimeStats`](#videoruntimestats) | Before the response ends, when the instance was created with `opts.stats: true`. |

The checks below use the context's spatial grid: 32 pixels when `files.embeddingsConnectors` (LTX) or `files.llm` is set, 16 pixels otherwise.

| Error | When |
| --- | --- |
| `TypeError` | `params` is not an object, or `prompt` is missing or empty. |
| `Error` | `mode` is not `"txt2vid"` or `"img2vid"`. |
| `Error` | `width` or `height` is not a positive multiple of the grid. |
| `Error` | `width` and `height` are omitted and `init_image` or a control frame has dimensions that are not multiples of the grid. |
| `Error` | `video_frames` is not a positive integer. |
| `RangeError` | `fps` is outside `(0, 120]`, `moe_boundary` outside `[0, 1]`, `reference_attention_strength` outside `[0, 1]`, `lora_strength` or `stg_scale` outside `[0, 10]`, `reference_downscale_factor` is not `1`, or `stg_block` is not a non-negative integer. |
| `RangeError` | The decoded input images together exceed `config.max_job_pixels`. |
| `Error` | `txt2vid` with `init_image`, `img2vid` without it, `init_image` is empty, or `init_images` is passed. |
| `TypeError` | `img2vid` on a Wan model and `files.clipVision` was not provided. |
| `TypeError` / `Error` | `control_frames` is not an array, is empty, or holds an empty entry or one that is not image bytes. |
| `Error` | `reference_images`, `reference_attention_strength`, or `reference_downscale_factor` on a model that is not LTX; `reference_images` without `lora`, with `img2vid`, with `config.vae_decode_only: true`, or with other than exactly one image; the other two without `reference_images`. |
| `TypeError` | `vae_extra_tiling_args` is not a string. |
| `Error` | A Wan 2.2 high-noise setting (`high_noise_*`, `moe_boundary`) without `files.highNoiseDiffusionModel`. |
| `Error` / `TypeError` | `lora`, `stg_scale`, or `stg_block` on a model that is not LTX; `lora_strength` without `lora`; `lora` is not a non-empty absolute path. |
| `Error` | The model is not loaded: `Addon not initialized. Call load() first.` |
| `Error` | A previous job's response is still active: `Cannot set new job: a job is already set or being processed`. |

The engine validates the model-specific frame counts and grid against the loaded model; its errors reject the response's `await()`.

## Functions

### `assessFit`

Projects a load against the memory free right now. It reads model metadata and never weight data, so the files can be the registry's header-only GGUF or safetensors copies and the projection can run before the weights are downloaded. Nothing is loaded to call it. Concurrent calls run one at a time within the addon.

The projection runs in the calling process and shares its engine state: GPU backend modules load once per process, so the first `config.backendsDir` any call supplies is the one every later load uses.

```ts
function assessFit(request: DiffusionFitRequest | EsrganFitRequest | WorldFitRequest): Promise<DiffusionFitResult>;
```

The request's `mode` selects what is projected:

| Form | `request` | Use it when |
| --- | --- | --- |
| Diffusion | [`DiffusionFitRequest`](#diffusionfitrequest) | `mode` is omitted or `"diffusion"`: an image or video model, with or without post-generation ESRGAN upscaling. |
| Upscale | [`EsrganFitRequest`](#esrganfitrequest) | `mode` is `"upscale"`: a standalone ESRGAN model, as `EsrganUpscaler` loads it. |
| World | [`WorldFitRequest`](#worldfitrequest) | `mode` is `"world"`: an ABot-World walk session. |

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `request` | The files, configuration, and workload to project. One of the three forms above. | See [forms](#assessfit) | Yes |

Returns a promise that resolves with a [`DiffusionFitResult`](#diffusionfitresult).

| Error | When |
| --- | --- |
| `TypeError` | `mode` is not `"diffusion"`, `"upscale"`, or `"world"`. |
| `TypeError` | A file path is not an absolute path string. |
| `Error` | The installed prebuild does not expose `assessFit`. |
| Rejection | The request is malformed, the engine cannot read the model, or an ESRGAN output exceeds the pixel limit. |

### `applyFluxImg2ImgDimDefaults`

Fills in the output size of a FLUX.2 image-to-image job. When `prediction` is `"flux2_flow"` and `width` or `height` is omitted, it returns a copy of `params` with the omitted dimension set to `1024`. Otherwise it returns `params` unchanged. `ImgStableDiffusion.run()` applies it itself to jobs with reference images when a prediction type is configured.

```ts
function applyFluxImg2ImgDimDefaults(params: GenerationParams, prediction: string, hasInitImages: boolean): GenerationParams;
```

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `params` | The generation parameters. | [`GenerationParams`](#generationparams) | Yes |
| `prediction` | The prediction type. Only `"flux2_flow"` changes `params`. | `string` | Yes |
| `hasInitImages` | Not used. | `boolean` | Yes |

Returns the generation parameters, with `width` and `height` filled in when they apply.

## Interfaces and types

### `ImgStableDiffusionArgs`

The object the [`ImgStableDiffusion`](#imgstablediffusion) constructor takes. Its fields are listed with the constructor.

### `DiffusionFiles`

Paths of an image model's files. Every path must be absolute. Passing any separate text encoder (`llm`, `t5Xxl`, `clipL`, or `clipG`) marks a split layout, where `model` holds the diffusion model only.

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `model` | The main model: an all-in-one checkpoint for SD1.x, SD2.x, SDXL, or SD3, or the diffusion model of a split layout. | `string` | Yes |
| `clipL` | CLIP-L text encoder, for SD3 and split layouts. | `string` | No |
| `clipG` | CLIP-G text encoder, for SDXL and SD3. | `string` | No |
| `t5Xxl` | T5-XXL text encoder, for SD3. | `string` | No |
| `llm` | LLM text encoder, such as Qwen3 for FLUX.2 [klein] or Qwen3-VL for Qwen-Image-2.1. | `string` | No |
| `llmVision` | Vision projector of the LLM text encoder. Required for Qwen-Image-2.1 reference editing. | `string` | No |
| `tokenizer` | External `tokenizer.json`, required by MOSS-Image's Qwen3.5 encoder. | `string` | No |
| `vae` | Separate VAE. | `string` | No |
| `esrgan` | ESRGAN model for post-generation upscaling. Required by the `upscale` generation parameter. | `string` | No |
| `highNoiseDiffusionModel` | Wan 2.2 high-noise expert. Normally used by `VideoStableDiffusion`. | `string` | No |
| `uncondModel` | Ideogram 4 unconditional diffusion model, loaded alongside `model` for classifier-free guidance. | `string` | No |

### `SdConfig`

Engine configuration of `ImgStableDiffusion` and `VideoStableDiffusion`. Values are passed to the engine as strings, and keys the engine does not know are ignored.

| Field | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `threads` | CPU threads. `-1` uses the number of physical cores. | [`NumericLike`](#numericlike) | No | `-1` |
| `device` | `"gpu"` prefers GPU backends; `"cpu"` forces the CPU. | `"gpu" \| "cpu"` | No | `"gpu"` |
| `main-gpu` | GPU to pin: a device index, or `"integrated"` / `"dedicated"`. A request that cannot be satisfied falls back to the CPU instead of another GPU. Rejected on mobile. An explicit `backend` takes precedence. | `number \| "integrated" \| "dedicated"` | No | — |
| `type` | Weight type override. `"auto"` keeps the file's types. | [`WeightType`](#weighttype) | No | `"auto"` |
| `rng` | Context RNG. `"cuda"` is the Philox RNG and is not GPU-specific. | [`RngType`](#rngtype) | No | `"cuda"` |
| `sampler_rng` | Sampler RNG override. | [`RngType`](#rngtype) | No | Automatic |
| `vae_auto_cpu_fallback` | Check oversized VAE GPU graphs before running them and fall back to the CPU. | `boolean` | No | `false` |
| `vae_auto_cpu_fallback_memory_ratio` | Memory ratio the VAE fallback check uses. Must be in `(0, 1]`. | `number` | No | `0.9` |
| `vae_decode_only` | Reject jobs that need the VAE encoder, such as LTX reference conditioning. The engine keeps the encoder weights either way, so it saves no memory. | `boolean` | No | `false` |
| `vae_tiling` | Not read at load. Set `vae_tiling` per job in [`GenerationParams`](#generationparams) or [`VideoGenerationParams`](#videogenerationparams). | `boolean` | No | — |
| `flash_attn` | Flash attention for the whole model. Also accepted as `fa`. | `boolean` | No | `false` |
| `diffusion_fa` | Flash attention in the diffusion model only. Important for FLUX and LTX memory use. | `boolean` | No | `true` |
| `mmap` | Memory-map the model files. | `boolean` | No | `false` |
| `offload_to_cpu` | Keep parameters in CPU RAM: supplies a `*=cpu` default for `params_backend`. A `module=backend` entry in `params_backend` overrides it for that module only. | `boolean` | No | `false` |
| `control_net_cpu`, `clip_on_cpu`, `vae_on_cpu` | Removed. The load rejects them; use `backend` or `params_backend` assignments such as `"te=cpu"` or `"vae=cpu"` instead. | `never` | No | — |
| `backend` | Where graphs run: one backend for all modules, such as `"cuda0"` or `"vulkan0"`, or per-module assignments such as `"diffusion=cuda0,te=cpu"`. It is not an ordered fallback list, and an explicit backend that is unavailable fails the load. | `string` | No | Automatic |
| `params_backend` | Where weights stay between uses: a backend, CPU RAM, or disk, for all modules or per module, such as `"diffusion=cpu"`. A module on `disk` is reloaded from the model file on every job. | `string` | No | The runtime backend |
| `max_vram` | VRAM budget in GiB for graph-cut segmented execution. A positive value caps the budget; a negative value uses the detected free VRAM minus its absolute value as headroom; `0` disables graph cutting. Per-device form: `"cuda0=6,vulkan0=4"`. | `number \| string` | No | `0` |
| `stream_layers` | Prefetch and evict diffusion layers from CPU RAM. Takes effect only when graph cutting is active and the diffusion parameters are on the CPU. | `boolean` | No | `false` |
| `prediction` | Prediction type override. `"flux2_flow"` keeps the package's FLUX.2 reference handling: the 1024 size default and the `@imageN` prompt warnings. Leave it automatic for Qwen-Image-2.1. | [`PredictionType`](#predictiontype) | No | `"auto"` |
| `flow_shift` | Flow-matching noise schedule shift. | `number` | No | The model's embedded value |
| `diffusion_conv_direct` | Direct convolution in the diffusion model. | `boolean` | No | `true` |
| `vae_conv_direct` | Direct convolution in the VAE. `false` uses the im2col path, which decodes faster at the cost of graph memory. | `boolean` | No | `true` |
| `force_sdxl_vae_conv_scale` | Force the SDXL VAE convolution scale, a compatibility fix. | `boolean` | No | `false` |
| `backendsDir` | Directory of the ggml backend modules, scanned as given. | `string` | No | Beside the loaded module |
| `tensor_type_rules` | Per-tensor weight type rules, such as `"^vae.=f16,model.=q8_0"`. | `string` | No | — |
| `lora_apply_mode` | When LoRA weights are applied. | [`LoraApplyMode`](#loraapplymode) | No | `"auto"` |
| `upscaler_tile_size` | ESRGAN tile size. A positive integer. | [`NumericLike`](#numericlike) | No | `128` |
| `upscaler_direct` | Direct convolution in the ESRGAN upscaler. | `boolean` | No | `false` |
| `upscaler_offload_params_to_cpu` | Keep the ESRGAN parameters in CPU RAM. | `boolean` | No | `false` |
| `upscaler_threads` | CPU threads for ESRGAN. `-1` detects them. | [`NumericLike`](#numericlike) | No | `-1` |
| `max_image_pixels` | Maximum decoded pixels of one input image or ESRGAN output. A positive integer, at most 16384 × 16384. | [`NumericLike`](#numericlike) | No | `67108864` (64 Mi) |
| `max_job_pixels` | Maximum decoded input pixels a multi-image or video job retains. A positive integer. | [`NumericLike`](#numericlike) | No | `134217728` (128 Mi) |
| `verbosity` | Native log level: `0` error, `1` warn, `2` info, `3` debug. | [`NumericLike`](#numericlike) | No | `0` |

### `GenerationParams`

| Field | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `prompt` | The prompt. Must not be empty. | `string` | Yes | — |
| `negative_prompt` | What the image should not contain. | `string` | No | — |
| `width` | Output width. A positive multiple of 8. | `number` | No | `512`; `1024` for FLUX.2 image-to-image with `prediction: "flux2_flow"` |
| `height` | Output height. A positive multiple of 8. | `number` | No | `512`; `1024` for FLUX.2 image-to-image with `prediction: "flux2_flow"` |
| `steps` | Diffusion steps. A positive integer. | `number` | No | `20` |
| `cfg_scale` | Text classifier-free guidance scale. | `number` | No | `7` |
| `guidance` | Distilled guidance of FLUX.2, separate from `cfg_scale`. | `number` | No | `3.5` |
| `sampling_method` | Sampler. `sampler` is an alias. Do not force `"euler_a"` for FLUX.2. | [`SamplerMethod`](#samplermethod) | No | Per model family |
| `sampler` | Alias of `sampling_method`. | [`SamplerMethod`](#samplermethod) | No | Per model family |
| `scheduler` | Noise scheduler. | [`ScheduleType`](#scheduletype) | No | Per model family |

| `lora` | Absolute path of a LoRA adapter. | `string` | No | — |
