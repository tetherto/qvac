`@qvac/translation-nmtcpp` exports one class, `TranslationNmtcpp`, as its CommonJS default export. The class translates text with IndicTrans2 or Bergamot models and offers a static `assessFit` memory check. The package also exports the types of the class's arguments and results. Most applications use it through the [QVAC SDK](/sdk); for a walkthrough of direct use, see [Usage](/ecosystem/packages/translation-nmtcpp/usage).

```js
const TranslationNmtcpp = require('@qvac/translation-nmtcpp')
```

## Classes

### `TranslationNmtcpp`

Translation with IndicTrans2 models, through the GGML engine, or Bergamot (Firefox Translations) models. Bergamot can chain two models through a pivot language. `run()` and `runBatch()` share one queue: each job starts only after the previous one has settled.

```ts
new (args: TranslationNmtcppArgs): TranslationNmtcpp;
```

| Parameter | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `files` | Paths of the model and vocabulary files. | [`TranslationNmtcppFiles`](#translationnmtcppfiles) | Yes | — |
| `params` | Source and target languages. | [`TranslationNmtcppParams`](#translationnmtcppparams) | Yes | — |
| `config` | Model type, generation settings, and compute backend settings. `modelType` is required in practice. | [`TranslationNmtcppConfig`](#translationnmtcppconfig) | No | `{}` |
| `logger` | An object with `info`, `warn`, `error`, and `debug` methods. Receives the package's log lines. | `unknown` | No | `null` |
| `opts` | `stats: true` populates `response.stats` with [`RuntimeStats`](#runtimestats) after each run. | `{ stats?: boolean }` | No | `{}` |

The constructor throws an `Error` when `config.modelType` is `"Opus"`: that model type was removed in favor of `"Bergamot"`.

#### `TranslationNmtcpp.ModelTypes`

The model type values for `config.modelType`. Static and read-only.

```ts
static readonly ModelTypes: TranslationNmtcppModelTypes;
```

Its value is `{ IndicTrans: "IndicTrans", Bergamot: "Bergamot" }`. See [`TranslationNmtcppModelTypes`](#translationnmtcppmodeltypes-1).

#### `TranslationNmtcpp.assessFit()`

Static. Estimates, before any instance is created, whether a model's weights can load with the memory free right now. No model instance or weights are loaded. Concurrent calls run one at a time within the addon. The estimate budgets four times the model file size plus 512 MiB for copies, tokenizers, and inference buffers. It is a point-in-time estimate: another load can consume memory before `load()` runs.

```ts
assessFit(request: TranslationNmtcpp.FitRequest): Promise<TranslationNmtcpp.FitResult>;
```

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `request` | The files and configuration a load would take, and the memory to keep free. | [`FitRequest`](#fitrequest) | Yes |

Returns a promise that resolves with a [`FitResult`](#fitresult). An IndicTrans request with `main-gpu` or `main_gpu` resolves with `status: "unknown"` without consulting the engine.

| Error | When |
| --- | --- |
| `TypeError` | `files.model` is not an absolute path, or `files.pivotModel` is set and is not one. |
| `TypeError` | `config.modelType` is not `"IndicTrans"` or `"Bergamot"`. |
| `Error` | The installed prebuild does not expose `assessFit`. |
| `InvalidArgument` rejection | The model or a vocabulary cannot be read, a requested GPU is unavailable, or the request is malformed. |
| `InternalError` rejection | A CPU load on a host with no CPU device. |

#### `load()`

Loads the model: both stages for a pivot setup. When the model is already loaded, it unloads it first. When activation fails, it releases the native instance and rejects. The backend and GPU settings are read here; to change them, call `unload()` and `load()` again.

```ts
load(): Promise<void>;
```

Returns a promise that resolves once the model is loaded.

| Error | When |
| --- | --- |
| `Error` | `destroy()` was called: `Model has been destroyed. Create a new instance to load again.` |
| `TypeError` | `main-gpu` and `main_gpu` are both set; the value is not a 32-bit integer, `"dedicated"`, or `"integrated"`; or it is combined with `gpu_backend`, `gpu_device`, or their aliases. |
| `QvacErrorAddonMarian` | Native activation fails (code 8006, `FAILED_TO_ACTIVATE`), for example a Bergamot model without its vocabulary files. Exported from `@qvac/translation-nmtcpp/lib/error`. |

#### `run()`

Translates one text. The promise resolves with the job's response once the job has started; the translated text arrives through the response. The next `run()` or `runBatch()` starts only after this response has settled: finished, failed, or cancelled.

```ts
run(input: string): Promise<TranslationResponse>;
```

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `input` | The text to translate. | `string` | Yes |

Returns a promise that resolves with a [`TranslationResponse`](#translationresponse). Read the translation with `onUpdate()`: it is the callback that applies the package's output post-processing for both model types. IndicTrans2 output is also post-processed through `iterate()`.

| Error | When |
| --- | --- |
| `Error` | The model is not loaded: `Model not loaded. Call load() first.` |
| `QvacErrorAddonMarian` | Submitting the job to the native runner fails (code 8003, `FAILED_TO_APPEND`). |

#### `runBatch()`

Translates several texts in one native batch, which is faster than calling `run()` for each. Shares the queue with `run()`. For a pivot setup, the whole batch is translated to the pivot language, then to the target. It offers no cancellation handle.

```ts
runBatch(texts: string[]): Promise<string[]>;
```

| Parameter | Description | Type | Required |
| --- | --- | --- | --- |
| `texts` | The texts to translate. | `string[]` | Yes |

Returns a promise that resolves with the translations, in the order of `texts`.

| Error | When |
| --- | --- |
| `Error` | The model is not loaded: `Model not loaded. Call load() first.` |
| `Error` | `texts` is not an array: `Input must be an array of strings`. |
| Rejection | The native batch fails. |

#### `unload()`

Releases the native instance and frees its memory. The model can be loaded again.

```ts
unload(): Promise<void>;
```

Returns a promise that resolves once the native instance is released.

#### `destroy()`

Unloads the model and marks the instance destroyed. A later `load()` rejects; create a new instance instead.

```ts
destroy(): Promise<void>;
```

Returns a promise that resolves once the model is unloaded.

#### `getState()`

```ts
getState(): InferenceClientState;
```

Returns the instance's lifecycle flags: [`InferenceClientState`](#inferenceclientstate).

#### `getActiveBackendName()`

Reports the compute backend `load()` selected. The engine falls back to the CPU silently when no usable GPU is registered; this call is the way to detect it.

```ts
getActiveBackendName(): "Unloaded" | "Bergamot-CPU" | "CPU" | (string & {});
```

Returns a device name such as `"Vulkan0"`, `"OpenCL"`, or `"Metal"`, or one of these values:

| Value | Meaning |
| --- | --- |
| `"Unloaded"` | The model is not loaded. |
| `"Bergamot-CPU"` | A Bergamot model, which runs on the CPU whatever `use_gpu` says. |
| `"CPU"` | An IndicTrans2 model with only the CPU backend registered. |

#### `getActiveBackendDescription()`

```ts
getActiveBackendDescription(): string;
```

Returns the human-readable description of the active GPU device, such as `"NVIDIA GeForce RTX 5070"`, or `""` when no GPU backend is loaded or the model is unloaded.

## Interfaces and types

### `TranslationNmtcppArgs`

The object the [`TranslationNmtcpp`](#translationnmtcpp) constructor takes. Its fields are listed with the constructor.

### `TranslationNmtcppFiles`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `model` | The model weights: a GGML `*.bin` file for IndicTrans2, a `model.*.intgemm.alphas.bin` file for Bergamot. For a pivot setup, the source-to-pivot model. | `string` | Yes |
| `srcVocab` | Source vocabulary (`*.spm`). Required for Bergamot. | `string` | No |
| `dstVocab` | Target vocabulary (`*.spm`). Required for Bergamot. Most pairs share one vocabulary file for both. | `string` | No |
| `pivotModel` | Bergamot only: the pivot-to-target model. When omitted, the instance translates with `model` alone. | `string` | No |
| `pivotSrcVocab` | Source vocabulary of the pivot model. | `string` | No |
| `pivotDstVocab` | Target vocabulary of the pivot model. | `string` | No |

### `TranslationNmtcppParams`

| Field | Description | Type | Required |
| --- | --- | --- | --- |
| `srcLang` | Source language: an ISO 639-1 code for Bergamot, such as `"en"`; a language code with an ISO 15924 script suffix for IndicTrans2, such as `"eng_Latn"`. | `string` | Yes |
| `dstLang` | Target language, in the same form as `srcLang`. | `string` | Yes |

### `TranslationNmtcppConfig`

Model type, generation settings, and compute backend settings. Each GPU key has a camelCase alias; when both forms are set, the snake_case key wins.

| Field | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `modelType` | The model family. | `"IndicTrans" \| "Bergamot"` | Yes | — |
| `pivotConfig` | Bergamot pivot setups: settings of the pivot-to-target stage, such as `{ beamsize: 4 }`. The other keys configure the source-to-pivot stage. | `Record<string, unknown>` | No | `{}` |
| `beamsize` | Beam search width. `1` disables beam search. Supported by both model types. | `number` | No | IndicTrans2: `4`; Bergamot: `1` |
| `lengthpenalty` | IndicTrans2: length normalization strength, at least `0`. | `number` | No | `1` |
| `maxlength` | IndicTrans2: maximum generated tokens, from `0` to `512`. | `number` | No | `512` |
| `repetitionpenalty` | IndicTrans2: penalty on previously generated tokens, from `0` to `2`. `1` disables it. | `number` | No | `1` |
| `norepeatngramsize` | IndicTrans2: forbid repeating n-grams of this size, from `0` to `10`. `0` disables it. | `number` | No | `0` |
| `temperature` | IndicTrans2: sampling temperature, from `0` to `2`. | `number` | No | `1` |
| `topk` | IndicTrans2: keep the top K logits, from `0` to the vocabulary size. `0` disables it. | `number` | No | `0` |
| `topp` | IndicTrans2: nucleus sampling threshold, from `0` to `1`. `1` disables it. | `number` | No | `1` |
| `use_gpu` | Enable an eligible Vulkan, Metal, OpenCL, or CUDA compute backend. No effect on Bergamot, which is CPU-only. Alias: `useGPU`. | `boolean` | No | `false` |
| `gpu_backend` | Case-insensitive substring matched against eligible device names, such as `"vulkan"`, `"vulkan0"`, `"opencl"`, or `"metal"`. Replaces the default selection with one explicit pass. A selector that resolves to OpenCL bypasses the build-time `USE_OPENCL` guard. Alias: `gpuBackend`. | `string` | No | Default selection |
| `gpu_device` | Ordinal within the matching devices, dedicated GPUs first. For example, `{ gpu_backend: "vulkan", gpu_device: 1 }` selects the second Vulkan adapter. Alias: `gpuDevice`. | `number` | No | `0` |
| `main-gpu` | Raw ggml registry index, or `"dedicated"` / `"integrated"`. Requires `use_gpu`. Unsupported devices fall back to the CPU; out-of-range indices warn and auto-select. Cannot be combined with `gpu_backend` or `gpu_device`. | `number \| string` | No | — |
| `main_gpu` | Alias of `main-gpu`. Setting both is rejected. | `number \| string` | No | — |
| `backendsDir` | Absolute path of the directory holding the backend shared libraries, such as `libqvac-ggml-vulkan.so`. A path with `..` segments or an unresolvable symlink is rejected with a warning, and the default applies. | `string` | No | The backends `@qvac/fabric` ships |
| `openclCacheDir` | Android only: an app-writable directory for the OpenCL kernel cache, forwarded as `GGML_OPENCL_CACHE_DIR`. Always set it when using OpenCL on Android. | `string` | No | — |

### `TranslationNmtcppModelTypes`

The type of [`TranslationNmtcpp.ModelTypes`](#translationnmtcppmodeltypes).

| Value | Meaning |
| --- | --- |
| `"IndicTrans"` | IndicTrans2 model, run by the GGML engine: English and Indic languages. |
| `"Bergamot"` | Bergamot (Firefox Translations) model: European and other pairs, mostly to or from English. CPU-only. |

### `TranslationResponse`

What [`run()`](#run) resolves with: a `QvacResponse<string>` from `@qvac/infer-base`, plus typed access to `stats`.

| Member | Description |
| --- | --- |
| `onUpdate(callback)` | Calls `callback` with each translated text chunk, post-processed. |
| `onFinish(callback)` | Calls `callback` with the terminal result when the job ends. |
| `onError(callback)` | Calls `callback` with the error when the job fails. |
| `onCancel(callback)` | Calls `callback` when the response is cancelled. |
| `await()` | Returns a promise that settles when the job ends. |
| `iterate()` | Async iterator over the output chunks. |
| `cancel()` | Asks the native runner to stop the job and fires the `onCancel` callbacks. Depending on timing, `await()` then rejects or resolves with the output produced so far. The model stays loaded. |
| `stats` | [`RuntimeStats`](#runtimestats) once the job ends, when the instance was created with `opts.stats: true`; `{}` otherwise. Narrow it with `'TPS' in response.stats`. |

### `RuntimeStats`

Statistics on `response.stats`. `totalTime`, `decodeTime`, `encodeTime`, and `TTFT` accumulate over the life of the loaded model, and restart at zero on `unload()` / `load()` and on `cancel()`. For per-run figures, take the difference of consecutive readings. Pivot translations may emit keys prefixed with the model name, such as `"BERGAMOT : ->TPS"`; this type models the non-pivot shape.

| Field | Description | Type |
| --- | --- | --- |
| `totalTokens` | Token count. Accumulates on Bergamot and on IndicTrans2 greedy decoding (`beamsize: 1`); IndicTrans2 beam search reports the run's own count. | `number` |
| `totalTime` | Total time, in seconds. | `number` |
| `decodeTime` | Decoding time, in seconds. | `number` |
| `TPS` | Tokens per second, computed from the readings above. | `number` |
| `encodeTime` | Encoding time, in seconds. IndicTrans2 only. | `number` |
| `TTFT` | Time to first token, in milliseconds. IndicTrans2 only. | `number` |

### `InferenceClientState`

| Field | Description | Type |
| --- | --- | --- |
| `configLoaded` | `true` after a successful `load()`, `false` after `unload()`. | `boolean` |
| `weightsLoaded` | `true` after a successful `load()`, `false` after `unload()`. | `boolean` |
| `destroyed` | `true` after `destroy()`. | `boolean` |

### `FitRequest`

The request of [`assessFit()`](#translationnmtcppassessfit).

| Field | Description | Type | Required | Default |
| --- | --- | --- | --- | --- |
| `files` | The files a load would take. `model` must be an absolute path. | [`TranslationNmtcppFiles`](#translationnmtcppfiles) | Yes | — |
| `config` | The configuration a load would take. | [`TranslationNmtcppConfig`](#translationnmtcppconfig) | Yes | — |
| `marginBytes` | Additional free memory to reserve, in bytes. | `number` | No | — |

### `FitResult`

| Field | Description | Type |
| --- | --- | --- |
| `status` | The verdict. | [`FitStatus`](#fitstatus) |
| `devices` | The selected GPU, then the host CPU, which stages a discrete GPU's source bytes; a GPU that shares host memory has a host row carrying `0`. One CPU row for a load on the CPU, which every Bergamot load is. None for `"unknown"`. | [`FitDevice`](#fitdevice)`[]` |
| `stats` | Always an empty object. | [`FitStats`](#fitstats) |

### `FitDevice`

| Field | Description | Type |
| --- | --- | --- |
| `id` | The PCI bus ID when the backend reports one, the device name otherwise. | `string` |
| `name` | Device name. | `string` |
| `unified` | Memory the host owns: the host CPU, and a GPU that shares the host's memory. On an iOS device, a unified row's free memory is capped at the app's own memory limit. | `boolean` |
| `usedBytes` | The weight-load allowance on the selected device; the staged source bytes on the host. | `number` |
| `freeBytes` | Free memory. | `number` |
| `totalBytes` | Total memory. | `number` |

### `FitStatus`

| Value | Meaning |
| --- | --- |
| `"fits"` | Every row's charge fits with `marginBytes` left free. |
| `"does-not-fit"` | A CPU load whose source bytes alone do not fit. |
| `"unknown"` | No reliable verdict: a `main-gpu` selection, memory that cannot be read, no CPU device for the host row, or a load between the allowance and the source bytes. |

### `FitStats`

`Record<string, never>`: an empty object.
