# QVAC Transcription Parakeet Addon v0.2.0 Release Notes

This release migrates the Parakeet addon to the `qvac-lib-inference-addon-cpp` 1.x runtime architecture and hardens cancellation/lifecycle behavior in real runtime paths. Because the package moved off the removed legacy templated addon API, this is released as a backward-incompatible minor bump.

## Changes

### Migrate native addon to addon-cpp 1.x

The addon now uses the `IModel`/`IModelCancel` runtime with `AddonJs`/`AddonCpp` factories and `createInstance`/`runJob` execution flow. Legacy templated addon and js-interface code was removed.

### Improve runtime lifecycle and cancel behavior

Cancellation, reload, and job-state transitions were hardened for the addon-cpp 1.x runtime path, with additional integration and C++ coverage for parity-sensitive behavior.

### Expand parity-focused test coverage

The migration adds dedicated `AddonCpp` coverage and strengthens JS integration checks around output, cancellation, and job completion lifecycle semantics.

## Backward Compatibility

The high-level `TranscriptionParakeet` JavaScript API remains compatible for standard package consumers.

Direct consumers of removed legacy native addon internals must migrate to the addon-cpp 1.x runtime model introduced in this release.
