# QVAC Transcription Parakeet Addon v0.2.3 Release Notes

This release updates Parakeet desktop prebuild packaging so each platform ships a single `.bare` addon artifact while preserving Linux runtime loading in CI and downstream environments.

## Changes

### Ship static desktop prebuilds

Desktop builds now link Parakeet against the static ONNX Runtime target instead of copying ONNX shared libraries into `prebuilds/`. This keeps the published artifact layout aligned with the other native addons that ship only a `.bare` file and its exports file per platform.

### Restore Linux runtime loading

Linux builds now use the same static standard-library linkage pattern as the other successful native addons in this repository. This prevents the `libc++.so.1` runtime loader failure that appeared after removing the bundled ONNX shared libraries from the package.

## Backward Compatibility

No public JavaScript API changes. Existing callers continue to use the same package entrypoints and model configuration, while packaged desktop artifacts become simpler and more consistent across platforms.
