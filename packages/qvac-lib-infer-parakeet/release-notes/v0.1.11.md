# QVAC Transcription Parakeet Addon v0.1.11 Release Notes

This release adds automated Real-Time Factor (RTF) benchmarking that collects inference performance metrics across all CI devices during integration test runs.

## Changes

### Add RTF benchmark collection on CI devices

- New `rtf-benchmark.test.js` integration test captures RTF and 12 other timing metrics (encoder, decoder, mel-spec, tokens/s, etc.) from the C++ addon's `runtimeStats` emitted on `JobEnded`
- Runs 5 benchmark iterations after warmup, computes aggregate statistics (mean, min, max, stddev, p50, p95)
- Writes structured JSON reports uploaded as CI artifacts for cross-device comparison
- Integrated into the existing integration test workflow as a non-blocking step on all 6 CI runners
- Standalone `rtf-benchmark-qvac-lib-infer-parakeet.yml` workflow available for on-demand benchmarking

## Backward Compatibility

No runtime behavioral changes. The RTF benchmark is a test-only addition that does not modify the addon's public API or behavior.
